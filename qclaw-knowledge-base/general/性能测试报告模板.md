## 一、测试概述

### 1.1 测试目的

本报告旨在记录XX项目性能测试的执行过程与结果，评估系统在预期负载及峰值负载下的响应时间、吞吐量、资源利用率等关键性能指标是否满足预设的非功能性需求，为系统上线决策提供数据支撑。

### 1.2 术语定义

| 术语 | 定义 |
|------|------|
| 响应时间（Response Time） | 从发起请求到接收到完整响应所经历的时间，单位：毫秒（ms） |
| 平均响应时间（Avg Response Time） | 多次请求响应时间的算术平均值 |
| 90%响应时间（90th Percentile） | 90%请求的响应时间不超过此值 |
| 吞吐量（Throughput） | 单位时间内系统处理的请求数量，单位：TPS（Transactions Per Second） |
| 并发用户数（Concurrent Users） | 同时向系统发起请求的用户数量 |
| 峰值TPS（Peak TPS） | 测试过程中记录到的最大吞吐量 |
| CPU利用率（CPU Utilization） | CPU处理时间占总时间的百分比 |
| 内存利用率（Memory Utilization） | 内存使用量占可用内存的百分比 |
| 错误率（Error Rate） | 失败请求数占总请求数的比例 |
| 稳定性测试（Stability Test） | 在一定负载下持续运行，验证系统长时间运行的稳定性 |
| 压力测试（Stress Test） | 逐步增加负载直至超过设计极限，测试系统的极限承载能力 |
