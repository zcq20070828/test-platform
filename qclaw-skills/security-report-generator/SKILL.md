# 安全测试报告生成 Skill

当 security-sentinel 进入 **report（报告）** 阶段时调用本 Skill，生成结构化安全评估报告。

## 必须遵循的【安全测试报告】模板结构（基于通用知识库「安全测试报告模板」）

**报告标题**：XXXX项目VX.X.X版本-安全评估报告（智能测试版）

- **1. 概述**：报告生成时间/项目版本/AI执行时长
- **2. 术语、定义和缩略语**：AI安全测试/智能渗透测试/AI-DAST/AI质量审核
- **3. 测试依据**：OWASP TOP10 / OWASP Testing Guide v4 / PTES / OSSTMM3 / 测试中台知识库
- **4. 测试环境与工具**：扫描器/会话调试/浏览器/测试环境地址
- **5. 测试总体情况**：
  - 5.1 组件漏洞扫描（高危{{n}}/中危{{n}}/低危{{n}}）
  - 5.2 AWVS扫描情况
  - 5.3 渗透测试情况（高危/中危/低危 + AI模拟攻击场景）
- **6. 安全风险分析及测试结论**：
  - 6.1 风险分析表：

| 风险等级 | 数量 | 详情 |
|---------|------|------|
| 高危及以上 | (n) | (详情/影响) |
| 中危 | (n) | (详情/影响) |
| 低危 | (n) | (详情/影响) |

  - 6.2 测试结论：AI评分/质量审核(pass≥95)/人工审核/最终结论
- **7. AI智能体执行记录**：调度流程/知识库使用/质量审核详情
- **8. 附件**：扫描结果/渗透问题列表/执行日志/质量审核报告

### CVSS v3.1 评分与风险矩阵（报告阶段必附）
| 漏洞 | CVSS基础分 | 风险等级 | 修复优先级 | 修复建议 |
|------|-----------|---------|-----------|---------|
| (漏洞名) | (0.0-10.0) | 危急/高/中/低 | P0/P1/P2/P3 | (建议) |

## 输出要求
- 严格按 8 章结构输出报告
- 每个漏洞附 CVSS v3.1 评分与修复优先级
- 手工渗透发现的漏洞标题前加【手工渗透】标记
- 总体结论需给出明确准出/不准出判定

> 说明：security-sentinel 当前以 findings JSON 落库（后端解析写 security_reports），本 Skill 提供报告阶段的方法论与格式参考，整体架构保持不变。
