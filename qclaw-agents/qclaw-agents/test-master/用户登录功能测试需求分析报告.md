## 1. 功能需求拆解

### 1.1 登录方式

| 登录方式 | 说明 | 核心验证点 |
|----------|------|-----------|
| 账号密码登录 | 用户输入用户名/邮箱/手机号 + 密码进行登录 | 凭证校验、密码加密传输、会话创建 |
| 手机验证码登录 | 用户输入手机号，获取并输入短信验证码 | 验证码发送/有效期/校验、手机号格式验证 |
| 第三方OAuth登录 | 微信/支付宝/QQ/Google/GitHub等第三方授权登录 | OAuth回调处理、用户绑定/自动注册、Token安全 |
| 扫码登录 | 用户使用App扫描二维码登录 | 二维码生成/过期、扫码状态轮询、确认登录 |
| 生物识别登录 | 指纹/Face ID登录（移动端） | 生物特征采集、本地安全存储、降级方案 |

### 1.2 用户输入验证

#### 1.2.1 用户名校验

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 非空校验 | 用户名不能为空 | "请输入用户名" |
| 格式校验 | 字母开头，4-20位字母/数字/下划线 | "用户名格式不正确" |
| 特殊字符过滤 | 禁止HTML/SQL特殊字符 | "用户名包含非法字符" |
| 长度校验 | 最短4字符，最长20字符 | "用户名长度需在4-20位之间" |
| 前后空格处理 | 自动trim或提示去除 | — |

#### 1.2.2 密码校验

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 非空校验 | 密码不能为空 | "请输入密码" |
| 长度校验 | 8-20位 | "密码长度需在8-20位之间" |
| 复杂度校验 | 含大小写字母+数字+特殊字符（至少3种） | "密码复杂度不足" |
| 明文显示切换 | 密码可切换明文/密文显示 | — |
| 粘贴限制 | 是否允许粘贴（安全策略） | — |

#### 1.2.3 手机号校验

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 非空校验 | 手机号不能为空 | "请输入手机号" |
| 格式校验 | 11位数字，符合号段规则 | "手机号格式不正确" |
| 国际区号 | 海外用户+区号格式 | "请输入正确的手机号" |

#### 1.2.4 验证码校验

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 非空校验 | 验证码不能为空 | "请输入验证码" |
| 格式校验 | 4-6位数字 | "验证码格式不正确" |
| 有效期 | 5分钟内有效 | "验证码已过期" |
| 错误次数 | 同一验证码最多输错3次 | "验证码错误次数过多，请重新获取" |

### 1.3 错误处理

| 错误场景 | 处理方式 | 提示信息 | 优先级 |
|----------|---------|---------|--------|
| 用户名为空 | 前端拦截+提示 | "请输入用户名" | P1 |
| 密码为空 | 前端拦截+提示 | "请输入密码" | P1 |
| 用户名不存在 | 后端返回错误 | "用户名或密码错误"（不透露具体原因） | P0 |
| 密码错误 | 后端返回错误 | "用户名或密码错误" | P0 |
| 账号被锁定 | 后端返回锁定状态 | "账号已锁定，请30分钟后重试或联系客服" | P0 |
| 账号被禁用/注销 | 后端返回禁用状态 | "该账号已被禁用，请联系管理员" | P0 |
| 验证码错误 | 后端校验失败 | "验证码错误，请重新输入" | P1 |
| 验证码过期 | 后端校验失败 | "验证码已过期，请重新获取" | P1 |
| 验证码频繁获取 | 前端倒计时+后端限频 | "操作过于频繁，请1分钟后重试" | P2 |
| 网络异常 | 前端超时处理 | "网络异常，请检查网络后重试" | P1 |
| 服务器异常 | 后端5xx | "系统繁忙，请稍后重试" | P1 |
| 第三方授权失败 | OAuth回调错误 | "第三方登录失败，请重试" | P2 |
| 第三方账号未绑定 | OAuth成功但无关联账号 | 引导绑定或注册 | P2 |

### 1.4 安全机制

| 安全机制 | 说明 | 实现要点 |
|----------|------|---------|
| 防暴力破解 | 登录失败次数限制 | 同一账号5次失败后锁定30分钟；同一IP 10分钟内最多20次请求 |
| 图形验证码 | 登录失败3次后触发 | 服务端生成、一次性使用、60秒过期 |
| 滑动/点选验证 | 人机识别 | 极验/腾讯防水墙等第三方服务集成 |
| 密码加密传输 | HTTPS + 非明文传输 | RSA加密/SM2加密传输，后端解密校验 |
| 密码存储安全 | 后端不可逆存储 | bcrypt/scrypt/Argon2哈希+盐值 |
| 会话管理 | Token/Session安全 | JWT签名、HttpOnly Cookie、CSRF Token |
| 登录设备管理 | 异地登录提醒 | 新设备/新IP登录短信/邮件通知 |
| 会话过期 | 自动超时退出 | 短会话30分钟，长会话7天（勾选记住我） |
| 单点登录/互踢 | 同账号仅允许一个活跃会话 | 新登录踢掉旧会话，或提示已在线 |
| 防撞库 | 黑产账号检测 | 异常IP/设备指纹识别、风控规则引擎 |
| 敏感信息脱敏 | 日志/界面不暴露 | 用户名部分隐藏、密码永远掩码 |

## 3. 风险评估

### 3.1 高风险场景 🔴

| 编号 | 风险场景 | 风险描述 | 影响范围 | 缓解措施 |
|------|---------|---------|---------|---------|
| R-001 | 暴力破解攻击 | 攻击者自动化尝试大量密码组合 | 用户账号安全、系统资源 | 失败锁定+验证码+IP限频+风控规则 |
| R-002 | SQL注入 | 登录接口未做参数化查询，可被注入 | 全库数据泄露 | 参数化查询+输入过滤+WAF |
| R-003 | 撞库攻击 | 利用泄露的账号密码批量尝试 | 大量用户账号被盗 | 异常登录检测+二次验证+设备指纹 |
| R-004 | 验证码短信轰炸 | 攻击者恶意消耗短信资源 | 经济损失、正常用户收不到验证码 | 发送频率限制+图形验证码前置+每日上限 |
| R-005 | 会话劫持/固定 | 攻击者窃取或固定Session ID | 用户身份被冒用 | 登录后重置Session+HttpOnly+Secure Cookie+绑定IP/设备 |
| R-006 | 密码明文泄露 | 传输或存储过程中密码暴露 | 用户密码泄露 | HTTPS+非对称加密传输+bcrypt存储 |
| R-007 | 越权访问 | 未登录直接访问受保护资源 | 数据泄露 | 所有接口强制鉴权+网关层校验 |

### 3.2 中风险场景 🟡

| 编号 | 风险场景 | 风险描述 | 影响范围 | 缓解措施 |
|------|---------|---------|---------|---------|
| R-008 | 并发登录冲突 | 同一账号多设备同时登录导致状态不一致 | 用户体验异常 | 明确单点/多点登录策略+互踢机制 |
| R-009 | 第三方服务不可用 | OAuth服务商宕机导致无法登录 | 部分用户无法登录 | 降级提示+多登录方式备选 |
| R-010 | 验证码到达延迟 | 短信网关拥堵导致验证码延迟 | 用户等待体验差 | 超时重发+语音验证码备选 |
| R-011 | 浏览器兼容性问题 | 特定浏览器下登录功能异常 | 部分用户无法使用 | 主流浏览器全覆盖测试+Polyfill |
| R-012 | 弱密码策略 | 允许过于简单的密码 | 账号易被猜解 | 强制复杂度+常见弱密码黑名单 |
| R-013 | 登录接口性能瓶颈 | 高并发下登录响应缓慢或失败 | 大面积用户无法登录 | 性能测试+缓存+限流+弹性扩容 |

### 3.3 低风险场景 🟢

| 编号 | 风险场景 | 风险描述 | 影响范围 | 缓解措施 |
|------|---------|---------|---------|---------|
| R-014 | 密码显示/隐藏切换异常 | 明文切换按钮不生效 | 小范围体验问题 | UI组件测试 |
| R-015 | 登录页样式兼容 | 特殊分辨率下布局错位 | 视觉体验 | 响应式设计+多分辨率测试 |
| R-016 | "记住我"功能偶发失效 | Cookie未正确持久化 | 少数用户需重新登录 | Cookie属性检查+跨域配置 |
| R-017 | 登录页国际化问题 | 多语言环境下文案截断/乱码 | 海外用户体验 | i18n完整测试 |
| R-018 | 登录页SEO/无障碍 | 搜索引擎/屏幕阅读器无法正确识别 | 可访问性 | ARIA标签+语义化HTML |
