## 九、测试执行建议

### 9.1 执行顺序

**第一轮：P0级用例（阻塞级）**
- 功能测试：正常登录、密码错误、账号锁定、退出登录
- 安全测试：SQL注入、XSS、CSRF、暴力破解、Token安全
- 接口测试：正常登录接口、参数异常

**第二轮：P1级用例（高级）**
- 功能测试：Token过期、忘记密码、验证码校验
- 安全测试：OAuth安全、越权访问
- 接口测试：退出、刷新Token、忘记密码接口
- 性能测试：500并发

**第三轮：P2/P3级用例（中级/低级）**
- 功能测试：多点登录、边界值
- 兼容性测试：多浏览器、多分辨率
- 性能测试：1000并发、长时间稳定性

### 9.2 自动化建议

**适合自动化的用例**：
- 接口测试用例（API-001 ~ API-030）：使用 Postman/OpenAPI 自动化

- 安全测试基础项（SECURITY-001 ~ SECURITY-010）：使用 OWASP ZAP 自动化

**适合手工测试的用例**：
- UI交互测试：兼容性测试、用户体验评估
- 复杂场景测试：忘记密码→重置→登录完整流程
- 探索性测试：非常规操作、边界探索

- 正常激活账号：5个（test@example.com, test1~test4@example.com）
