## 功能概述与技术选型

### 1.1 支持的登录方式

| 登录方式 | 描述 | 技术实现 |
|----------|------|----------|
| 密码登录 | 用户名+密码 | Session-based认证 |
| 短信验证码登录 | 手机号+6位验证码 | 60秒倒计时，10分钟有效 |
| 第三方OAuth登录 | QQ/微信/Apple | OAuth 2.0 + PKCE |
| 记住登录 | 30天免登录 | 安全Cookie + Token轮换 |
| 生物识别登录 | 指纹/面容（移动端） | 本地生物特征匹配 |

### 1.2 技术架构决策

**选定方案：Session-based认证**

| 维度 | 分析 | 决策 |
|------|------|------|
| 安全性 | Session存储服务端，可随时撤销 | ✅ 适合安全敏感场景 |
| 扩展性 | 需要分布式Session存储（Redis） | ✅ 可水平扩展 |
| CSRF防护 | 基于SameSite Cookie天然防护 | ✅ 比JWT更安全 |
| 移动端适配 | 可结合Token实现无感知刷新 | ✅ 适合移动端 |
| 复杂度和维护 | 需管理Session生命周期 | ⚠️ 中等复杂度 |

**不选JWT的原因**：JWT一旦泄露难以撤销，不适合本次安全要求较高的场景。

### 1.3 Session生命周期

```
登录成功 → 创建Session(TTL=30min) → 设置HttpOnly+Secure+SameSite=Strict Cookie
活跃访问 → 自动续期（每次有效请求+15min）
登出/超时 → 销毁Session，清理Cookie
```

### 1.4 OAuth 2.0 实现细节

| 参数 | 要求 |
|------|------|
| Authorization Code Flow | 必须使用授权码模式 |
| PKCE | 必须启用（移动端/SPA） |
| state参数 | 必须验证，防CSRF |
| redirect_uri | 必须白名单匹配 |
| token存储 | 服务端Session，不返回客户端 |
| scope | 最小权限原则 |

## 需求规格说明

### 2.1 功能需求

#### 2.1.1 密码登录（FR-01）

| 需求ID | 描述 | 验收标准 |
|--------|------|----------|
| FR-01-01 | 用户名格式验证 | 支持邮箱/手机号/昵称，3-32字符 |
| FR-01-02 | 密码格式验证 | 8-20字符，含大小写字母和数字 |
| FR-01-03 | 错误次数限制 | 连续5次错误后锁定15分钟 |
| FR-01-04 | 密码展示控制 | 默认隐藏，可切换显示 |
| FR-01-05 | 登录成功跳转 | 跳转至原始请求页或首页 |

#### 2.1.2 短信验证码登录（FR-02）

| 需求ID | 描述 | 验收标准 |
|--------|------|----------|
| FR-02-01 | 手机号格式验证 | +86开头，11位数字 |
| FR-02-02 | 发送频率限制 | 同IP 1分钟1次，同手机号1小时5次 |
| FR-02-03 | 验证码有效期 | 10分钟内有效 |
| FR-02-04 | 验证码格式 | 6位数字 |
| FR-02-05 | 验证码错误限制 | 连续3次错误验证码失效 |
| FR-02-06 | 图形验证码前置 | 同一IP触发3次后需图形验证 |

#### 2.1.3 OAuth第三方登录（FR-03）

| 需求ID | 描述 | 验收标准 |
|--------|------|----------|
| FR-03-01 | 支持平台 | QQ、微信、Apple |
| FR-03-02 | OAuth state验证 | 必填，防CSRF攻击 |
| FR-03-03 | PKCE验证 | 移动端/SPA必须启用 |
| FR-03-04 | redirect_uri白名单 | 仅允许配置的域名 |
| FR-03-05 | 新用户自动注册 | 可配置开关 |
| FR-03-06 | 账号绑定/解绑 | 同一平台互斥绑定 |

#### 2.1.4 记住登录（FR-04）

| 需求ID | 描述 | 验收标准 |
|--------|------|----------|
| FR-04-01 | 记住登录有效期 | 30天 |
| FR-04-02 | Token安全存储 | HttpOnly+Secure Cookie |
| FR-04-03 | Token自动续期 | 每次活跃访问自动续期 |
| FR-04-04 | 多设备管理 | 支持查看/撤销其他设备 |

#### 2.1.5 登出（FR-05）

| 需求ID | 描述 | 验收标准 |
|--------|------|----------|
| FR-05-01 | 清除Session | 服务端Session销毁 |
| FR-05-02 | 清除Cookie | remember_token清除 |
| FR-05-03 | 跨设备登出 | 可选清除所有设备 |
| FR-05-04 | 登出跳转 | 跳转至首页或登录页 |

### 2.2 非功能需求

#### 2.2.1 性能要求（NFR-01）

| 登录方式 | SLA指标 | 说明 |
|----------|---------|------|
| 密码登录 | P95 ≤ 2s | 从提交到跳转完成 |
| 短信验证码登录 | P95 ≤ 3s（不含发送延迟） | 验证操作P95 |
| OAuth登录 | P95 ≤ 3s | OAuth回调完成 |
| 记住登录 | P95 ≤ 1s | 无感知验证 |
| 并发能力 | 支持5000 QPS | 登录接口 |

#### 2.2.2 安全要求（NFR-02）

| 需求ID | 描述 | 标准 |
|--------|------|------|
| NFR-02-01 | HTTPS强制 | 全站HTTPS，HSTS 31536000s |
| NFR-02-02 | 密码加密存储 | bcrypt，cost factor ≥ 12 |
| NFR-02-03 | SQL注入防护 | 参数化查询 |
| NFR-02-04 | XSS防护 | 输出编码，Content-Type指定 |
| NFR-02-05 | CSRF防护 | SameSite Cookie + 验证码 |
| NFR-02-06 | 暴力破解防护 | 速率限制 + 账号锁定 |
| NFR-02-07 | 敏感信息脱敏 | 日志中密码/Token脱敏 |
| NFR-02-08 | 安全Header | X-Frame-Options, CSP等 |

#### 2.2.3 移动端安全需求（NFR-03）

| 需求ID | 描述 | 实现要求 |
|--------|------|----------|
| NFR-03-01 | 证书锁定(SSL Pinning) | 绑定服务端证书公钥 | 
| NFR-03-02 | Token安全存储 | iOS Keychain / Android Keystore |
| NFR-03-03 | 生物识别认证 | LocalAuthentication框架 |
| NFR-03-04 | Root/越狱检测 | 检测后提示安全风险 |
| NFR-03-05 | 屏幕截图防护 | 敏感页面禁止截图 |
| NFR-03-06 | App加固 | 代码混淆 + 反调试 |

#### 2.2.4 合规要求（NFR-04）

| 需求ID | 描述 |
|--------|------|
| NFR-04-01 | 隐私政策展示 | 首次登录前展示 |
| NFR-04-02 | 第三方SDK披露 | OAuth登录需披露 |
| NFR-04-03 | 数据本地化 | 用户数据存储境内 |
