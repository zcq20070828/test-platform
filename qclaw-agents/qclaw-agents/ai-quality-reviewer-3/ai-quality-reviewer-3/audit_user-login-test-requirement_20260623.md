   - 组合8：三者均✗ → HTTP 401，提示"用户名或密码错误"
   
2. **补充 OAuth 安全项**（L1）：在 2.4 安全测试策略第三方登录部分补充：
   - OAuth state 参数存在性及校验测试
   - PKCE 支持性检查（如适用）
   - Redirect URI 白名单校验测试

3. **新增安全测试项**（S3）：在 2.4 中新增以下行：
   - 水平越权：使用 A 用户 Token 访问 B 用户数据
   - 垂直越权：低权限 Token 访问高权限接口
   - 密码重置 Token 枚举/暴力破解测试
   - 重置链接一次性使用验证

### 建议修改（中优先级）

4. **修正登录响应时间标准**（F1）：将 2.3 接口测试策略中的 < 200ms 修改为 < 2s（或根据实际业务 SLA 调整）。

5. **在性能测试策略中明确 SLA 指标**（L2）：在 2.5 性能测试中补充："目标：500 并发时登录成功率 ≥ 99.9%，P99 响应时间 < 3s"。

6. **补充 Token 安全详细检查项**（S2）：在 Token 安全测试维度补充：
   - Token exp claim 过期时间合理性检查
   - httpOnly / secure Cookie 属性验证
   - 刷新 Token 撤销机制测试

7. **新增移动端安全测试章节**（S6）：在 2.4 或新增 2.6 章节中补充：
