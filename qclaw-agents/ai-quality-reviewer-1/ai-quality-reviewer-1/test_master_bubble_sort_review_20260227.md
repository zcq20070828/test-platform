## 评估对象内容

```python
def bubble_sort(arr):
    """冒泡排序"""
    n = len(arr)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr


# 测试
print(bubble_sort([64, 34, 25, 12, 22, 11, 90]))
# 输出: [11, 12, 22, 25, 34, 64, 90]
```

**说明：**
- 外层循环控制遍历轮数
- 内层循环比较相邻元素，大的冒泡到右侧
- `swapped` 标记用于提前终止优化（已有序时跳过）
- 时间复杂度：平均/最坏 O(n²)，最好 O(n)
