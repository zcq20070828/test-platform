> **文档版本：** v1.0

## 1. 用例设计原则

### 1.1 等价类划分

| 输入域 | 有效等价类 | 无效等价类 |
|--------|------------|------------|
| 用户名 | 4-32位字母/数字/下划线 | <4字符、>32字符、空、含特殊字符 |
| 密码 | 6-20位任意字符 | <6字符、>20字符、空 |
| 验证码 | 4位字母/数字 | 错误验证码、空、过期 |

### 1.2 边界值分析

- 用户名长度：3, 4, 32, 33 字符
- 密码长度：5, 6, 20, 21 字符
- 验证码有效期：4分钟（过期边界）、5分钟（过期后）

### 1.3 优先级定义

| 级别 | 说明 | 通过率要求 |
|------|------|------------|
| P0 | 冒烟测试，阻塞发布 | 100% |
| P1 | 核心功能，重要缺陷 | ≥95% |
| P2 | 常规功能，轻微缺陷 | ≥90% |
