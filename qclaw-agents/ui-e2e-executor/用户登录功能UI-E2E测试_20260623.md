## 1. 概述

### 1.1 文档目的

本文档定义了用户登录功能的 UI 自动化测试和端到端（E2E）测试的完整设计方案，旨在：
- 建立可维护的自动化测试框架
- 覆盖所有 P0/P1 级关键用例
- 实现快速回归测试能力
- 提供详细的测试执行报告

### 1.2 测试背景

用户登录是系统的核心安全入口，涉及多种认证方式：
- **账号密码登录**（手机号/邮箱）
- **短信验证码登录**
- **第三方登录**（微信/Google/Apple）

### 1.3 技术栈选型

| 类别 | 选型 | 理由 |
|------|------|------|
| **测试框架** | Playwright | 支持多浏览器、内置API、强大定位能力 |
| **语言** | TypeScript | 类型安全、IDE支持、便于维护 |
| **报告** | Allure + HTML | 丰富的可视化报告、截图集成 |
| **CI集成** | GitHub Actions | 成熟生态、易于集成 |

**Playwright vs Cypress vs Selenium 对比：**

| 特性 | Playwright ✅ | Cypress | Selenium |
|------|------------|---------|---------|
| 多浏览器支持 | Chromium/Firefox/Safari | 仅Chromium(桌面) | 全浏览器 |
| 移动端测试 | ✅ 模拟设备 | ⚠️ 有限 | ⚠️ 需Appium |
| 内置API请求 | ✅ | ✅ | ❌ |
| 自动等待 | ✅ 智能等待 | ✅ | ❌ 需手动 |
| 并行执行 | ✅ | ⚠️ | ✅ |
| 社区活跃度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |

## 7. UI自动化测试设计

### 7.1 页面对象模型（Page Object Model）

```
┌─────────────────────────────────────────────────────────┐
│                   Page Object Pattern                   │
│                                                         │
│  ┌─────────────┐       ┌─────────────┐                │
│  │ Test Scripts│       │ Page Objects│                │
│  │             │ ─────▶│             │                │
│  │ login.spec  │       │ LoginPage   │                │
│  │ logout.spec │       │ HomePage    │                │
│  └─────────────┘       └──────┬──────┘                │
│                               │                        │
│                               ▼                        │
│                        ┌─────────────┐                │
│                        │ Playwright  │                │
│                        │   Browser   │                │
│                        └─────────────┘                │
└─────────────────────────────────────────────────────────┘
```

**核心优势：**
1. **封装性**：元素定位器集中在 Page Object 中，UI 变化时只需修改一处
2. **可维护性**：测试代码与定位器解耦
3. **可读性**：业务方法名替代技术细节
4. **复用性**：多个测试共享同一 Page Object

### 7.2 登录页面对象核心方法

```typescript
// page-objects/LoginPage.ts 核心接口
class LoginPage {
  // === 导航 ===
  navigate(): Promise<void>
  waitForPageReady(): Promise<void>

  // === 输入操作 ===
  enterAccount(account: string): this
  enterPassword(password: string): this
  enterSmsCode(code: string): this
  clearAccount(): this
  clearPassword(): this

  // === 交互操作 ===
  clickLoginButton(): this
  clickGetSmsCode(): this
  togglePasswordVisibility(): this
  toggleRememberMe(checked?: boolean): this

  // === 登录方式 ===
  loginWithPassword(credentials: LoginCredentials): this
  loginWithSmsCode(phone: string, code: string): this
  switchToSmsLogin(): this
  switchToPasswordLogin(): this

  // === 状态检查 ===
  isLoginButtonEnabled(): Promise<boolean>
  isLoading(): Promise<boolean>
  getGlobalErrorMessage(): Promise<string | null>

  // === 断言辅助 ===
  expectErrorType(errorType: ErrorType): Promise<void>
}
```
