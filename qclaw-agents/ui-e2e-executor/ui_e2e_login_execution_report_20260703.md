## ❌ 失败的测试 (34个) + 根因分析

### 分类1: LoginPage 页面对象 baseURL 未配置 (20个测试)

**影响范围**: 响应式布局(6)、账号锁定(6)、错误密码(6)、安全性(2个被未运行)

**根因**: `LoginPage` 页面对象的 `baseURL` 为空字符串(默认值)，调用 `navigate('/login')` 时生成无效 URL `http://localhost:3000/login`，而 Mock 服务器实际路径为 `/mock-login.html`。

**受影响测试**:
| 测试文件 | 失败测试数 | 严重等级 |
|----------|-----------|---------|
| responsive-layout.spec.ts | 6 | ⚠️ P2 |
| account-lockout.spec.ts | 6 | 🔴 P0 |
| invalid-password.spec.ts | 6 | 🟡 P1 |
| security.spec.ts | 2 | 🟡 P1 |

**修复建议**: 修正 LoginPage 构造函数中的 baseURL 默认值为 `http://localhost:3000` 或更新 navigate 方法中默认 path 为 `/mock-login.html`。

### 分类2: Logout 测试表单定位器超时 (6个测试)

**影响范围**: 登出功能全部测试

**根因**: `LoginPage.waitForPageReady()` 中使用 `form[action*="login"], .login-form, [data-testid="login-form"]` 选择器等待，但成功登出后 Mock 页面未包含该选择器匹配的登录表单。等待 10 秒超时。

**受影响测试**:
| 用例 | 名称 |
|------|------|
| TC-SMOKE-LOGOUT-001 | 点击退出应成功登出并跳转登录页 |
| TC-SMOKE-LOGOUT-002 | 退出后再次访问受保护页面应被重定向 |
| TC-SMOKE-LOGOUT-003 | 取消退出登录应保持登录状态 |
| TC-SMOKE-LOGOUT-004 | 重复点击退出应幂等执行 |
| TC-SMOKE-LOGOUT-005 | 退出后应能重新登录 |
| TC-SMOKE-LOGOUT-006 | 退出后所有认证Cookie应被清除 |

**修复建议**: 
1. 修复登出后模拟跳转逻辑，确保登录页面能被重新加载
2. 在 LogoutPage 中统一使用 `page.goto('http://localhost:3000/mock-login.html')` 而非依赖 LoginPage 的 navigator

### 分类3: 特殊字符输入验证失败 (1个测试)

**测试**: TC_BOUNDARY_003 — 验证账号输入特殊字符

**根因**: 输入特殊用户名后，Mock 返回空字符串错误消息 (`""`)，测试期望 `errorMsg` 为 truthy，实际为 falsy。

**详细信息**: Mock 仅预设了 3 个用户的密码映射，无特殊字符处理逻辑，返回空错误。

### 分类4: Valid-Login 测试超时 (7个测试，含6个未运行)

**根因**: 同样因 LoginPage baseURL 问题，TC-SMOKE-001 超时，其余 6 个因前序失败而未运行。
