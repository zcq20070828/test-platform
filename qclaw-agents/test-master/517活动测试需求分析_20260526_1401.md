## 1. 需求拆解

### 1.1 旧活动处理（3项）

| 模块 | 测试要点 |
|------|---------|
| 去掉登录APP自动激活奖品逻辑 | 验证推广前一天晚上去掉该逻辑；用户端外领奖后需手动激活 |
| 页面增加时间判断+强制弹窗逻辑 | 配置时间前正常展示；配置时间后未激活用户强制弹窗引导去新活动，弹窗不可关闭 |
| 修改鸿蒙系统弹窗文案 | 弹窗文案改为"为给您更好体验，活动正加急适配鸿蒙系统，敬请期待开放参与" |

### 1.2 登录功能

| 测试要点 | 说明 |
|---------|------|
| 多种登录方式 | 4G登录、单点登录、cookie登录、一键登录、手机验证码登录 |
| 登录优先级 | 单点(1) > cookie(2) > 一键(3) > 4G(4) > 验证码(5) |
| 未注册用户处理 | 4G取号失败触发验证码登录 |
| 登录失败处理 | 单点/4G失败点击除"规则"、"消息条"外按钮触发验证码登录弹窗 |
| 手机号掩码显示 | 登录后右上角显示"135****1234"格式 |
| 登录校验 | 未填手机号/toast提示；未填验证码/toast提示；账号密码错误/toast提示 |

### 1.3 模块一：升级礼/免费领权益

| 测试要点 | 说明 |
|---------|------|
| 新老用户判断口径 | 白名单/首次活跃表/当月APP首次活跃ES数据组合判断 |
| 新用户奖品 | 移动云盘白银会员季卡（有效期92天） |
| 老用户奖品 | 100G云空间年卡（有效期366天） |
| 领取限制 | 每用户限领1次；仅端内V13.0及以上版本可领取 |
| 纯鸿蒙系统 | 弹窗提示适配中 |
| 物联网卡号 | 弹窗提示不符合参与条件 |
| 端外访问 | 弹窗引导前往APP参与 |
| 版本低于V13.0 | 弹窗引导更新APP |
| 库存不足 | 总库存/今日库存无剩余时的弹窗提示 |
| 短验+风控校验 | 验证码校验通过后进行风控校验 |
| 领奖状态流转 | 一键领取→已激活→立即激活（失败重试） |

### 1.4 模块二：新人礼/新用户专属

| 测试要点 | 说明 |
|---------|------|
| 模块解锁条件 | 新用户领取激活模块一奖品后解锁 |
| 任务类型 | 开启手机备份（50云朵）、开启APP通知（200云朵） |
| 限时奖励 | 激活模块一后7天内完成2项任务，可三选一奖励 |
| 奖励领取有效期 | 选择奖品后7天内有效，次日0-24点可领第二份奖励 |
| 三选一奖品组合 | 组合一：5元支付宝红包（3+2）；组合二：3元支付宝红包（2+1）；组合三：500云朵（300+200） |
| 鸿蒙系统限制 | 点击任一按钮提示适配中 |
| 未激活模块一 | 任务锁定，引导前往模块一领取 |
| 7天后未完成 | 不显示限时加赠奖品，仅展示任务模块 |
| 自动弹窗 | 完成任务后7天内每日弹三选一弹窗；次日有待领取奖品时每日弹领取弹窗 |

### 1.5 模块三：用户回馈礼

| 测试要点 | 说明 |
|---------|------|
| 配置化 | 广告位可配置，点击跳转对应链接 |
| 无配置时的展示 | 无配置信息返回时，整个模块不展示（包括左侧导航） |

### 1.6 模块四：更多精彩活动

| 测试要点 | 说明 |
|---------|------|
| 配置化 | 支持后台自定义配置（模块标题、图片、跳转链接等） |
| 轮播支持 | 支持可轮播 |

### 1.7 风控

| 测试要点 | 说明 |
|---------|------|
| 自有风控 | 链路ID：1541，模块一领取接口、模块二选择奖励派奖接口接入 |
| idaas风控 | 接入登录事件(eventId:login)和领取事件(eventId:coupon) |
| 风控并行逻辑 | 两个风控逻辑并行，有一个未通过则表示未通过 |
| 风控不通过提示 | toast提示"哎呀~领取失败，晚点再试试吧"或"当前参与人数较多，请稍候再试～" |

### 1.8 短信/通知

| 测试要点 | 说明 |
|---------|------|
| 短信模板 | 本网/异网不同模板 |
| 短信下发场景 | 10个场景（见需求文档序号1-10） |
| 短信变量 | 支持变量配置（${code}等） |
| 权益到账通知 | 领取成功后下发权益到账短信 |

### 1.9 异常容灾

| 测试要点 | 说明 |
|---------|------|
| 网络异常 | 弹窗提示"网络异常，请稍后再试！" |
| 系统繁忙 | 弹窗提示"系统繁忙，请稍后再试！" |
| 活动下线 | 弹窗提示"很抱歉，活动已结束，请参与其它活动吧~"，不可关闭 |

## 3. 边界条件与特殊场景

### 3.1 新老用户口径边界（OR逻辑全组合）

新用户判断口径（满足任一即为新用户）：
1. 白名单号码
2. 非白名单号码 AND 历史首次活跃表无原生APP数据 AND 当月APP首次活跃ES无数据
3. 非白名单号码 AND 历史首次活跃表无原生APP数据 AND 当月APP首次活跃ES有"活跃时间>2026-05-20 且 与今天相差<=7天"的数据
4. 非白名单号码 AND 历史首次活跃表有原生APP数据 AND "活跃时间>=2026-05-20 且 与当天相差<=7天"

**测试边界场景**：
- 白名单用户在老用户数据中：优先识别为新用户
- 临界时间2026-05-20 00:00:00和2026-05-27 23:59:59（假设当天是2026-05-20，7天后为2026-05-27）
- 历史首次活跃表有数据但活跃时间刚好等于2026-05-20
- 当月APP首次活跃ES有数据但活跃时间刚好与今天相差7天

### 3.2 时间敏感逻辑（7天倒计时嵌套）

**时间节点梳理**：
1. 激活模块一后7天内完成2项任务 → 解锁三选一奖励
2. 解锁奖励后7天内选择奖品 → 选择当日获得第一份奖励
3. 选择奖品后次日0-24点内 → 领取第二份奖励，逾期失效
4. 完成任务后7天内未选择奖励 → 已失效

**边界场景**：
- 激活模块一后第7天23:59:59完成2项任务 → 有效
- 激活模块一后第8天00:00:00完成2项任务 → 无效，不显示限时加赠奖品
- 选择奖品后第7天23:59:59领取 → 有效
- 选择奖品后第8天00:00:00领取 → 失效
- 次日00:00:00 - 23:59:59领取第二份奖励 → 有效
- 次日24:00:00（即第三日00:00:00）领取 → 失效

### 3.3 库存边界

- 总库存为0 → 所有用户提示"奖品已领光"
- 总库存>0但今日库存为0 → 提示"今日奖品已领光"
- 总库存>0且今日库存>0 → 正常领取
- 库存扣减时机：生成中奖记录时扣减库存
- 领奖失败（立即激活状态）时不返还库存（需确认）

### 3.4 终端环境与版本限制

**支持的终端环境**：
- APP端：支持
- 小程序端：支持
- 浏览器环境：支持
- 微信环境：支持
- 短信小程序端：不支持
- 第三方客户端：不支持
- 第三方小程序端：不支持

**版本限制**：
- 仅安卓/IOS端内V13.0及以上版本可领取模块一奖品
- 端外访问统一拉端打开活动页

**边界场景**：
- 安卓V13.0.0 端内 → 可领取
- 安卓V12.9.9 端内 → 不可领取，引导更新
- IOS V13.0.0 端内 → 可领取
- 微信环境 → 不可领取，引导前往APP

### 3.5 奖品状态流转

**模块一奖品状态流转**：
1. 一键领取（未生成中奖记录）
2. → 已激活（已生成领奖专区中奖记录且已领奖）
3. → 立即激活（生成中奖记录后领奖失败，即有领奖专区中奖记录但未领奖）

**模块二奖品状态流转**：
1. 待解锁（未激活模块一）
2. → 立即解锁（已激活模块一但未完成2项任务）
3. → 立即领取（已完成2项任务但未选择奖励，7天内）
4. → 已失效（完成任务后7天内未选择奖励）
5. → 已解锁XXX新人礼（已选择奖励，展示所选奖品组的子奖品领取状态）
6. → 待领取（选择奖励后，当日/次日奖品待领取）
7. → 已领取（奖品已领取）
