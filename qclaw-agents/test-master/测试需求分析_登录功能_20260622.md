# 测试需求分析：用户登录功能 - 账号密码登录模块

**分析日期：** 2026-06-22

## 产品需求
1. 支持用户名/手机号作为登录账号
2. 密码长度6-20位，必须包含数字和字母
3. 连续输错5次密码，账号锁定30分钟
4. 登录成功后跳转到首页

---

## 功能点提取

| 编号 | 功能点 | 来源需求 |
|------|--------|----------|
| F1 | 登录账号输入 | 需求1 |
| F2 | 密码输入与校验 | 需求2 |
| F3 | 错误计数与账号锁定 | 需求3 |
| F4 | 登录成功跳转 | 需求4 |

## 测试条件

### F1：登录账号输入
- F1-01: 合法用户名登录 → 正常进入密码校验
- F1-02: 合法手机号登录 → 正常进入密码校验
- F1-03: 用户名为空 → 提示"请输入账号"
- F1-04: 非法格式（邮箱、特殊字符） → 提示"账号格式错误"
- F1-05: 不存在的用户名 → 提示"账号不存在"
- F1-06: 不存在的手机号 → 提示"账号不存在"
- F1-07: 用户名前后含空格 → 自动去除或提示格式错误

### F2：密码输入与校验
- F2-01: 6位合规密码（含数字+字母） → 校验通过
- F2-02: 20位合规密码（含数字+字母） → 校验通过
- F2-03: 5位密码 → 提示"密码长度不足"
- F2-04: 21位密码 → 提示"密码超出长度限制"
- F2-05: 纯数字密码 → 提示"密码必须包含字母"
- F2-06: 纯字母密码 → 提示"密码必须包含数字"
- F2-07: 包含特殊字符的合规密码 → 视业务规则
- F2-08: 密码为空 → 提示"请输入密码"
- F2-09: 正确密码 → 登录成功
- F2-10: 错误密码 → 提示"密码错误"

### F3：错误计数与账号锁定
- F3-01: 连续输错1-4次 → 提示密码错误及剩余次数
- F3-02: 连续输错第5次 → 账号锁定，提示锁定信息
- F3-03: 锁定期间尝试登录 → 提示"账号已锁定，请X分钟后重试"
- F3-04: 锁定30分钟后尝试 → 可正常登录
- F3-05: 锁定29分59秒尝试 → 仍提示锁定
- F3-06: 第4次错误后输入正确密码 → 登录成功，错误计数清零
- F3-07: 非连续错误（间隔成功登录） → 错误计数清零，不累积
- F3-08: 锁定时间倒计时 → 准确显示剩余锁定时间

### F4：登录成功跳转
- F4-01: 正确账号密码登录 → 跳转到首页
- F4-02: 首页加载 → 正常展示首页内容
- F4-03: 登录后刷新页面 → 保持登录态，停留在首页
- F4-04: 登录后回退 → 不应回到登录页

## 边界值与异常场景
- E-01: SQL注入（`' OR 1=1 --`）
- E-02: XSS攻击（`<script>` 标签）
- E-03: 同一账号并发登录
- E-04: 网络异常/超时
- E-05: 密码明文传输校验（HTTPS）
- E-06: 快速重复提交（防重）
- E-07: 手机号格式边界（11位，首位1，第二位3-9）

## 待确认项（隐含需求）
1. 错误计数是按账号维度还是IP维度？
2. 锁定时间是否精确到秒级？
3. 密码是否允许特殊字符？
4. 是否有验证码机制？
5. 是否支持"记住我"功能？
6. 锁定状态是否持久化（重启服务后是否保留）？
