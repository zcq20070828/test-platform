#### ❌ TC-051：HTTP请求自动重定向到HTTPS

| 项目 | 内容 |
|------|------|
| **用例编号** | TC-051 |
| **测试标题** | HTTP请求自动重定向到HTTPS |
| **优先级** | P0 |
| **对应TP编号** | TP-140 |
| **执行时间** | 2026-07-02 14:53:41 |
| **执行结果** | ❌ 失败 |
| **测试步骤** | 在浏览器地址栏输入 http:// 协议的登录页面URL，观察是否自动重定向到 https:// |
| **预期结果** | HTTP请求自动重定向到HTTPS |
| **实际结果** | HTTP请求未自动重定向到HTTPS，部分HTTP请求可能泄露敏感数据 |
| **失败原因** | Web服务器（如Nginx/Apache）未配置强制HTTPS重定向，导致HTTP协议可被直接访问，存在协议降级（SSL Stripping）攻击风险 |
| **严重程度** | 🔴 高（安全漏洞） |
| **修复建议** | 在Web服务器配置中添加HTTP到HTTPS的强制重定向规则（Nginx: return 301 https://$host$request_uri; 或 Apache: Redirect permanent / https://domain.com/） |
