# 云盘焕新权益免费领（517新人活动）— 测试需求分析报告

> 需求文档版本：V2.0.0 | 分析日期：2026-05-26

---

## 一、需求拆解（按模块）

### 模块0：旧活动处理
- **功能描述**：对现有旧活动进行改造，包括去掉自动激活逻辑、增加引导弹窗、修改鸿蒙弹窗文案
- **涉及角色**：新/老活动用户
- **关联需求点**：旧活动登录自动激活去掉（0-1）、配置时间判断引导弹窗（0-2）、鸿蒙弹窗文案修改（0-3）

### 模块1：活动基础能力
- **功能描述**：活动H5页面的通用基础能力，包括登录（5种方式）、规则展示、奖品入口、主副标题（配置化图片）、消息条公告、分享、目标用户过滤、异常处理、环境兼容
- **涉及角色**：所有活动用户
- **关联需求点**：登录（1-1）、规则（1-2）、奖品按钮（1-3）、主副标题（1-4）、消息条（1-5）、异常处理（1-6）、环境兼容（1-7）、分享（1-8）、目标用户（1-9）

### 模块2：模块一 — 升级礼/免费领权益
- **功能描述**：新用户领取白银会员季卡、老用户领取100G云空间年卡，涉及新老用户判断、端内外拉端、版本校验、鸿蒙/物联卡拦截、库存判断、短验+风控、领奖状态管理
- **涉及角色**：新用户（领季卡）、老用户（领100G）
- **关联需求点**：去掉旧权益（2-1a）、新老用户判断（2-1b）、领取交互（2-1c）、领奖状态（2-2）、7种场景弹窗（2-2a~2-2g）、库存（2-3）、活动时间（2-4）、运营平台上下线（2-5）

### 模块3：模块二 — 新人礼/新用户专属
- **功能描述**：新用户专属任务模块，包含单任务奖励（云朵）和限时三选一组合奖励，含多状态流转
- **涉及角色**：新用户（仅已激活模块一的新用户可见）
- **关联需求点**：任务列表（3-1）、单任务云朵（3-2）、7天限时第一层（3-3）、三选一选择（3-4）、当日/次日奖励（3-5）、7天限时第二层（3-6）、状态流转（3-7）、弹窗逻辑（3-8）、去掉智能相册（3-9）、备份开关数据源（3-10）

### 模块4：模块三 — 用户回馈礼
- **功能描述**：可配置广告位，点击跳转对应链接；无配置时整个模块不展示
- **涉及角色**：所有用户
- **关联需求点**：配置读取（4-1）、跳转逻辑（4-2）、无配置隐藏（4-3）

### 模块5：模块四 — 更多精彩活动
- **功能描述**：复用原活动轮播配置逻辑，支持后台自定义配置
- **涉及角色**：所有用户
- **关联需求点**：轮播配置（5-1）

### 模块6：短信通知
- **功能描述**：9条短信模板（含本网/异网），覆盖领取短验、到账通知、到期提醒等场景
- **涉及角色**：新/老用户
- **关联需求点**：短信模板1~9（6-1~6-9）、变量替换（6-10）、下发时机（6-11）

### 模块7：风控
- **功能描述**：自有风控（链路ID:1541）+ idaas风控双通道并行，登录事件和领取事件两处接入
- **涉及角色**：所有领奖用户
- **关联需求点**：自有风控（7-1）、idaas登录事件（7-2）、idaas领取事件（7-3）

### 3.2 时间敏感逻辑

#### 7天×2嵌套
```
第一层7天：激活模块一后7天内完成2项任务 → 解锁三选一
第二层7天：完成任务后7天内领取三选一 → 逾期失效

最大窗口：激活后第1天完成 → 领奖截止第14天
最小窗口：激活后第7天完成 → 领奖截止第14天
```

**边界测试点：**
- 激活第7天23:59:59完成任务 → 应解锁（第一层踩线）
- 激活第8天00:00:00完成任务 → 不解锁
- 解锁第7天23:59:59领取 → 成功
- 解锁第8天00:00:00领取 → 失效

#### 次日0点边界
- 当日23:59领取 → 次日00:00弹窗提醒
- 次日00:00~24:00可领 → 23:59:59后失效

#### 活动边界
- 2026-05-17 00:00:00 开始
- 2026-12-31 23:59:59 结束
- ⭐待确认：活动结束后进行中的限时奖励如何处理？

### 3.3 库存边界

| 场景 | 预期行为 |
|------|---------|
| 总库存=0 | "奖品已领光"→云朵中心 |
| 日库存=0但总>0 | "今日奖品已领光" |
| 总=1，2人并发 | 仅1人成功 |
| 日=1，2人并发 | 仅1人成功 |
| 总<日 | 以总库存为准 |

### 3.5 奖品状态完整流转图

#### 模块一状态流转
```
[一键领取] → 短验+风控
  ├─ 不通过 → toast失败 → [一键领取]
  ├─ 中奖+领奖成功 → [已激活]
  └─ 中奖+领奖失败 → [立即激活] → 点击 → [已激活]

```
[未激活模块一] → 激活 → [模块二开启]

  ├─ 7天内完成 → [解锁三选一]
  │   ├─ 7天内未领 → [已失效]
  │   └─ 领取三选一

  │           ├─ 次日0-24点领 → 完成
  │           └─ 次日24点后 → 次日奖励失效
  └─ 7天后完成 → [仅任务云朵]

#### 模块二单任务云朵状态

[未开启] → [已开启待领取] → [已领取]
