## 1. 测试概述

### 1.1 测试背景与目标

本次测试针对系统的**用户登录功能**进行全维度测试。登录功能是用户访问系统的核心入口，负责验证用户身份并授权访问系统资源，其质量直接关系到系统安全性与用户体验。

**测试目标**：
1. 验证账号密码、手机验证码、第三方授权等登录方式的功能正确性
2. 验证安全防护机制的有效性（暴力破解防护、SQL注入/XSS防护、账号枚举防护）
3. 验证异常场景的容错能力（网络异常、账号状态异常、并发操作）
4. 验证用户体验细节的完整性（记住密码、自动登录、密码显示切换等）
5. 识别并记录所有缺陷，为修复决策提供依据

### 3.2 缺陷明细

---

#### 🔴 P0-001 | LOGIN-006：账号枚举漏洞

| 属性 | 内容 |
|------|------|
| **优先级** | 🔴 **P0（致命）** |
| **模块** | 安全验证 - 账号枚举防护 |
| **状态** | ❌ 待修复 |
| **发现时间** | 2026-07-02 |
| **发现阶段** | UI自动化测试 |

**缺陷描述**：
当使用系统中不存在的账号登录时，系统明确提示「**账号不存在**」，而不是提示「账号或密码错误」。攻击者可以通过此提示信息枚举系统中已注册的有效账号，为后续的暴力破解攻击提供目标清单。

**复现步骤**：
1. 打开登录页面
2. 输入不存在的账号（如 `notexist@test.com`）
3. 输入任意密码
4. 点击登录
5. 观察错误提示

**实际结果**：提示「账号不存在」
**预期结果**：提示「账号或密码错误」（不区分账号是否存在）

**修复建议**：
将后端返回的错误信息统一为「**账号或密码错误**」，无论是对应账号不存在还是密码错误，均返回同一提示。

**风险等级**：极高 — ⭐ **可直接导致用户信息泄露**，配合暴力破解可批量攻破账号。

---

#### 🟡 P1-001 | LOGIN-018：忘记密码入口缺失

| 属性 | 内容 |
|------|------|
| **优先级** | 🟡 **P1（重要）** |
| **模块** | 关联功能 - 忘记密码 |
| **状态** | ❌ 待修复 |
| **发现时间** | 2026-07-02 |
| **发现阶段** | UI自动化测试 |

**缺陷描述**：
登录页面上未找到「忘记密码」链接或按钮。用户忘记密码后将无法自主找回密码，需依赖其他渠道（如联系客服），严重影响用户体验。

**修复建议**：
在登录表单下方添加「**忘记密码**」入口链接，点击后跳转至密码重置流程页面。

**风险等级**：高 — 用户无法自助恢复账号访问。

---

#### 🟡 P1-002 | LOGIN-019：注册入口缺失

| 属性 | 内容 |
|------|------|
| **优先级** | 🟡 **P1（重要）** |
| **模块** | 关联功能 - 注册 |
| **状态** | ❌ 待修复 |
| **发现时间** | 2026-07-02 |
| **发现阶段** | UI自动化测试 |

**缺陷描述**：
登录页面上未找到「注册新账号」入口。新用户无法通过登录页进入注册流程，系统无法获取新增用户。

**修复建议**：
在登录表单下方添加「**注册新账号**」入口链接，点击后跳转至注册页面。注册成功后可自动跳转登录或直接登录。

**风险等级**：高 — ⭐ **阻塞新用户获取，影响用户增长**。

---

#### 🟢 P2-001 | LOGIN-034：密码显示/隐藏功能缺失

| 属性 | 内容 |
|------|------|
| **优先级** | 🟢 **P2（一般）** |
| **模块** | 用户体验 - 密码显示切换 |
| **状态** | ❌ 待修复 |
| **发现时间** | 2026-07-02 |
| **发现阶段** | UI自动化测试 |

**缺陷描述**：
密码输入框右侧的「眼睛」图标在点击后，密码输入框的类型未从 `password` 切换为 `text`，即密码始终处于掩码状态，无法查看已输入的密码内容。

**修复建议**：
检查密码显示切换按钮的事件绑定逻辑，确保点击后 `input` 标签的 `type` 属性在 `password` 和 `text` 之间正确切换，同时图标状态同步切换。

**风险等级**：低 — 仅影响用户体验细节，不阻塞功能使用。
