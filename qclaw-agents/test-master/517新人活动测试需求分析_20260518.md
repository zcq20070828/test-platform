# 中国移动云盘"517新人活动"测试需求分析报告

**文档版本**：V2.0  
**编写日期**：2026-05-18  
**活动周期**：2026-05-17 ~ 2026-12-31  
**分析依据**：中国移动云盘"517新人活动"开发需求文档_V2.0.0（完整版）

---

## 一、测试范围与目标

### 1.1 测试范围

| 维度 | 范围说明 |
|------|---------|
| **活动模块** | 旧活动处理 + 模块一（免费领权益/升级礼）+ 模块二（新人礼/新用户专属）+ 模块三（用户回馈礼）+ 模块四（更多精彩活动） |
| **终端覆盖** | APP端（Android/iOS）、小程序端、浏览器环境、微信环境 |
| **系统适配** | Android、iOS、鸿蒙系统（专项） |
| **版本限制** | APP V13.0及以上版本（Android+iOS） |
| **用户类型** | 新用户（4种判断口径）、老用户、不可参与用户（虚拟号/物联网卡/港澳台） |
| **奖品类型** | 白银会员季卡、100G云空间年卡、支付宝红包（3元/2元/1元）、云朵（300/200/50） |
| **关联系统** | 自有风控（链路ID:1541）、IDaaS风控、短信通知系统（10种模板）、会员权益系统、存储空间系统、支付宝红包系统 |
| **登录方式** | 4G登录(优先级4)、单点登录(1)、cookie登录(2)、一键登录(3)、手机验证码登录(5) |
| **活动周期** | 2026-05-17 ~ 2026-12-31（7+月长周期，运营平台可上下线） |

### 1.2 测试目标

1. **功能正确性**：确保新老用户身份识别准确，各模块领取链路完整，奖品发放无误
2. **用户区分准确性**：4种新用户判断口径100%正确执行，新/老/不可参与用户权益不错不漏
3. **风控有效性**：自有风控+IDaaS双层风控正确并行校验，任一不通过即拦截
4. **多端一致性**：APP/小程序/浏览器/微信各端体验一致，鸿蒙系统专项适配
5. **时间逻辑正确性**：7天任务限时、7天领奖有效期、次日领奖、倒计时等时间相关逻辑准确
6. **安全性合规**：防止刷奖、薅羊毛、SQL注入、XSS、API越权等安全风险
