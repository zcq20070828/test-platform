## 二、详细功能点分析

### 模块 1：账号密码登录

| 功能点 | 描述 | 测试前置条件 | 测试数据需求 | 风险 |
|--------|------|-------------|-------------|------|
| 正常登录 | 用户名+密码正确，成功进入系统 | 用户已注册 | 注册账号：`testuser01 / Test@123456` | ⭐ |
| 用户名为空 | 用户名输入为空，提交登录 | 无 | 空白输入 | ⭐ |
| 密码为空 | 密码输入为空，提交登录 | 无 | 空白输入 | ⭐ |
| 用户名格式错误 | 输入未注册用户名 | 无 | 未注册账号：`notexist999` | ⭐ |
| 密码错误 | 用户名正确，密码错误 | 用户已注册 | 正确用户名 + 错误密码 | ⭐ |
| 密码可见性切换 | 点击眼睛图标切换密码可见/隐藏 | 用户已注册 | - | ⭐ |

## 五、风险评估汇总

> ⚠️ **以下风险等级需根据项目实际情况由人工确认填写。**

| 风险项 | 说明 | 建议风险等级 | 备注 |
|--------|------|-------------|------|
| 第三方登录回调稳定性 | OAuth回调依赖第三方服务，网络波动可能失败 | ⭐ 中-高 | 需重点关注 |
| 验证码服务可用性 | 短信/邮件网关故障导致登录阻塞 | ⭐ 高 | 建议降级方案 |
| Token安全机制 | Refresh Token泄露/滥用风险 | ⭐ 高 | 安全重点 |
| 暴力破解防护 | 验证码可绕过、IP限速失效 | ⭐ 高 | 需渗透测试配合 |
| 并发登录数据一致性 | 竞态条件下登录状态不一致 | ⭐ 中 | 需压力测试 |
| 会话超时边界 | 超时时间配置与业务场景匹配度 | ⭐ 中 | 需与产品确认 |

## 六、测试范围与边界

### ✅ 纳入测试范围
- 所有登录方式（账号密码、验证码、第三方OAuth）
- 注册与密码找回全流程
- 安全策略（密码强度、错误限制、账号锁定）
- 会话全生命周期（登录→保持→退出→失效）
- 异常场景（网络、超时、并发、跨设备）

### ❌ 明确排除范围
- 第三方平台本身的服务故障（微信/QQ服务器宕机）
- 用户手机/邮箱本身的接收延迟或拦截
- 非功能测试（性能测试、压力测试、渗透测试单独进行）
- 登录后的业务功能（不属于登录模块范围）

### 📌 测试边界说明
- 测试以 **Web 端为主**，移动端/App 测试另行覆盖
- 本次分析基于通用登录模块标准功能，具体字段名/文案以实际产品设计为准
