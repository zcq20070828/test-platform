## 关键风险提示

1. **新老用户口径**：白名单OR无APP数据OR近7天首次活跃——三个条件OR逻辑，边界用例多，建议与开发对齐判断SQL逻辑
2. **7天倒计时**：模块一激活时刻→模块二7天窗口→三选一7天领取期，三级时间嵌套，状态组合多
3. **并行风控**：自有风控+idaas任一失败即拦截，需模拟两种风控的各种返回组合
4. **纯鸿蒙兼容**：需明确区分纯血鸿蒙(HarmonyOS NEXT)与兼容安卓的鸿蒙系统
5. **次日奖励**：T+0完成→T+1到账逻辑，涉及定时任务/异步派发，需验证时效性和幂等性
6. **短信模板9条**：本网/异网各有不同模板，需逐一核对内容和变量替换
