## 二、项目概述

### 2.1 项目背景
中国移动云盘推出"517新人活动"，面向新用户和老用户提供不同的权益奖励。新用户可领取移动云盘白银会员季卡及完成限时任务获取额外奖励；老用户可领取100G云空间年卡。

### 2.2 活动基本信息

| 项目 | 内容 |
|------|------|
| 活动标题 | 云盘焕新权益免费领 |
| 活动时间 | 2026年5月17日 - 2026年12月31日 |
| 活动环境 | APP端、小程序端、浏览器环境、微信环境 |
| 目标用户 | 中国移动云盘用户（不含虚拟号、物联网卡、港澳台地区用户） |
| 需求类型 | 新活动开发 + 旧活动处理 |

### 2.3 测试范围

**包含内容：**
- 旧活动处理逻辑
- 新活动四个功能模块
- 新/老用户判断逻辑
- 奖品领取流程和状态机
- 时间边界和有效期逻辑
- 风控接入验证
- 短信通知验证（含9种短信模板完整覆盖）
- 安全测试（CSRF/SQL注入/XSS/越权访问/数据脱敏）
- 数据传输和埋点验证
- 端外环境区分测试

**不包含内容：**
- 运营平台配置功能（需运营协作）

### 4.2 模块一：升级礼/免费领权益

- **新用户**：领取"移动云盘白银会员季卡"（有效期92天）

### 4.3 模块二：新人礼/新用户专属

#### 4.3.1 功能概述
新用户激活模块一后，可参与模块二完成限时任务领取额外奖励。

**核心规则：**
1. 激活模块一后7天内完成2项任务，解锁三选一奖励
2. 解锁后7天内选择奖励组合，选择当日领取第一份奖励
3. 选择后次日0-24点内领取第二份奖励，逾期失效
4. 超过7天未完成任务，不显示限时加赠奖品，仅显示任务奖励（云朵）

#### 4.3.2 模块二状态机

**状态1：未激活模块一**
```
状态：模块二锁定
按钮：【立即解锁】（请先领取并激活会员季卡）
点击：跳转到模块一
```

**状态2：已激活模块一，7天内未完成任务**
```
状态：模块二已解锁，任务进行中
任务1：开启手机备份（+50云朵）
任务2：开启APP通知（+200云朵）
按钮：【立即解锁】（显示7天倒计时）
点击：拉起任务栏
```

**状态3：激活模块一7天内完成2项任务，7天内未选择奖励**
```
状态：已解锁三选一，待选择
按钮：【立即领取】（显示7天倒计时）
点击：弹出三选一领奖弹窗
自动弹窗：每天弹一次（前端缓存控制）
```

**状态4：已选择奖励，待领取当日奖励**
```
状态：已选择奖励组合
按钮：【领更多新人福利】
点击：定位到模块二新人礼板块
当日奖励：选择当日可领取
次日奖励：选择后次日0-24点可领取
```

**状态5：选择奖励后超过7天未领取**
```
状态：奖励已失效
按钮：【已失效】
奖品卡片：显示"已失效"
```

**状态6：激活模块一7天后完成任务**
```
状态：不显示限时加赠奖品，仅显示任务奖励
任务奖励：50云朵（备份）+ 200云朵（APP通知）
按钮：【领云朵】或【更多云朵】
```

#### 4.3.3 三选一奖励组合

| 组合编号 | 组合名称 | 当日奖励 | 次日奖励 |
|---------|---------|----------|----------|
| 组合一 | **5元支付红包组合** | 3元支付宝红包 | 2元支付宝红包 |
| 组合二 | **5元微信立减金组合** | 3元微信立减金 | 2元微信立减金 |
| 组合三 | **500云朵组合** | 300云朵 | 200云朵 |

**⚠️ 重要说明：**
- 根据原始需求文档，限时奖励的三选一为：**5元支付红包组合、5元微信立减金组合、500云朵组合**
- 原始需求原文："用户激活升级礼移动云盘白银会员季卡奖品权益后，7天内完成上述两项任务，可从5元支付红包组合、5元微信立减金组合、500云朵组合奖品中任选其一作为奖励"
- 奖品组合只能选择一次，只能下发一次，不可重复下发
- 选择后7天内有效，逾期失效
- 领取后次日内需领取第二个奖励，逾期失效

#### 4.3.4 任务详解

##### 任务一：开启手机备份

**任务奖励：** 50云朵

**完成判断：**
- 使用APP上报的备份开关状态数据判断
- 激活模块二时就查询用户的开关状态
- 如果已经打开，激活时直接显示任务完成

**任务状态：**
| 任务状态 | 按钮显示 | 操作 |
|---------|---------|------|
| 未完成 | 【去开启】 | 弹窗引导开启 |
| 已完成云朵待领取 | 【领云朵】 | 点击领取50云朵，直接到账 |
| 已完成云朵已领取 | 【已完成】 | 已完成状态 |

##### 任务二：开启APP通知

**任务奖励：** 200云朵

**完成判断：**
- 与"开启APP通知"活动任务一为同一奖励
- 仅可领取1次，领取状态同步

**任务状态：**
| 任务状态 | 按钮显示 | 操作 |
|---------|---------|------|
| 未完成 | 【去开启】 | 跳转至APP消息手机设置开关 |
| 已完成云朵待领取 | 【领云朵】 | 点击领取200云朵，直接到账 |
| 已完成云朵已领取 | 【已完成】 | 已完成状态 |

**登录事件：eventId = login**
- 前端调后端登录时，携带IP、deviceId、appVersion、activityId、userAgent等参数
- 无论返回啥，前端不做任何响应，仅后端记录数据

- 风控接口响应成功，riskLevel：REJECT且response.detail.hits.model含M002050009或M99020201，判断为风控不通过
