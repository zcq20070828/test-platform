## 1. 测试上下文（Context）

### 1.1 项目背景

139邮箱作为国内主流邮箱服务，本次需求聚焦于三类改进：

1. **用户体验优化**（需求1、2、3、10）：响应用户反馈，针对UI交互细节（复选框点击范围、列表对齐、文字截断、滚动条样式等）进行体验升级。
2. **跨端兼容性修复**（需求4、5）：火狐浏览器小屏兼容性问题修复、草稿箱角标规则统一，涉web6.0/7.0/小程序/H5/鸿蒙多端。
3. **功能对齐与补齐**（需求6、7、8、9）：会话邮件功能对标6.0版本、PC客户端关闭账户引导流程、邮件列表操作交互优化、日程提醒能力增强。

### 1.2 测试目标

- 验证全部10个需求的功能实现符合需求规格
- 确保修改不引入回归缺陷
- 覆盖全部涉及平台（web6.0、web7.0、小程序、H5、鸿蒙、PC客户端、火狐浏览器）
- 达成测试覆盖率 ≥ 95% 的目标

### 1.3 测试范围

| 涉及平台 | 需求覆盖 |
|---------|---------|
| Web 6.0 | 需求1、2、3、5、6、7、9、10 |
| Web 7.0 | 需求1、2、3、5、6、7、9、10 |
| 小程序 | 需求5 |
| H5 | 需求5 |
| 鸿蒙 | 需求5 |
| PC客户端 | 需求8 |
| 火狐浏览器（Firefox） | 需求4 |

## 3. 测试功能点拆解

### R1：多选框可点击范围扩大 + hover效果

**功能点描述：**

预览模式、列表模式、会话模式下，复选框增加可点击范围，同时鼠标hover时展示视觉反馈效果。支持勾选单个、多个邮件、全选邮件三种场景。

**测试场景：**

| # | 场景 | 操作 | 预期结果 |
|---|------|------|---------|
| T1.1 | 预览模式，单封邮件 | 鼠标移至复选框区域（扩大范围），hover时显示视觉反馈，点击勾选 | 勾选成功，复选框选中状态正确 |
| T1.2 | 列表模式，单封邮件 | 同上 | 同上 |
| T1.3 | 会话模式，单封邮件 | 同上 | 同上 |
| T1.4 | 多封邮件连续勾选 | 依次勾选多封邮件 | 所有勾选状态正确保存 |
| T1.5 | 全选操作 | 点击全选复选框 | 当前列表/会话所有邮件均被勾选 |
| T1.6 | hover状态样式 | 鼠标悬停在复选框扩大区域内 | 显示hover视觉反馈（颜色/边框/阴影等） |
| T1.7 | 取消勾选 | 再次点击已选邮件的复选框 | 取消选中，状态恢复 |

**验收标准（Given-When-Then）：**

```
AC1.1: Given 用户在邮件列表页（预览/列表/会话模式），When 鼠标hover至复选框扩大区域，Then 显示hover视觉效果（高亮/边框变化等可识别反馈）
AC1.2: Given 用户点击复选框扩大区域内任意位置，When 操作完成，Then 邮件勾选状态正确变更
AC1.3: Given 用户勾选多封邮件，When 查看勾选计数或批量操作按钮，Then 显示正确的选中数量
AC1.4: Given 用户点击全选复选框，When 当前视图有N封邮件，Then N封邮件全部处于勾选状态
AC1.5: Given 用户再次点击已勾选邮件的复选框，When 操作完成，Then 该邮件取消勾选状态
```
