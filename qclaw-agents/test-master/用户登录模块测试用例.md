# 用户登录模块测试用例

## 一、模块概述

| 项目 | 内容 |
|------|------|
| 模块名称 | 用户登录 |
| 功能描述 | 用户通过用户名/邮箱/手机号 + 密码进行身份认证并登录系统 |
| 测试类型 | 功能测试、安全测试、性能测试、兼容性测试 |
| 优先级 | P0（核心功能） |

---

## 二、测试数据准备

| 数据类型 | 示例值 | 用途 |
|---------|-------|------|
| 有效账号 | `test_user` / `Test@123456` | 正向测试 |
| 有效邮箱账号 | `user@example.com` / `Test@123456` | 邮箱登录 |
| 有效手机账号 | `13800138000` / `Test@123456` | 手机号登录 |
| 失效账号 | `locked_user` / `Test@123456` | 账号锁定测试 |
| 未注册账号 | `not_exist` / `Test@123456` | 异常测试 |
| 错误密码 | `test_user` / `Wrong@123` | 密码错误测试 |

| 级别 | 定义 | 示例 |
