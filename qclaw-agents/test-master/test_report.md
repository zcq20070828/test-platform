## 三、缺陷记录

### 缺陷1：TC-001 复选框hover无视觉反馈

| 字段 | 内容 |
|------|------|
| **缺陷ID** | DEF-001 |
| **用例编号** | TC-001 |
| **缺陷等级** | P2 |
| **缺陷描述** | 复选框hover时无CSS或JS视觉反馈，边框/背景hover前后无变化 |
| **复现步骤** | 1. 登录139邮箱<br>2. 进入邮件列表预览模式<br>3. 鼠标移至任意邮件左侧复选框 |
| **预期结果** | hover时复选框显示背景色变化或边框高亮 |
| **实际结果** | hover前后复选框样式完全一致（border: 1px solid rgb(18,33,51)，无:hover规则） |
| **影响范围** | 所有邮件列表视图（预览/列表模式） |
| **建议修复** | 为`.list_check input[type=checkbox]`添加:hover样式规则 |
