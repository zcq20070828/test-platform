# 中国移动云盘"517新人活动"测试需求分析报告

**文档版本**：V1.0  
**编写日期**：2026-05-18  
**活动周期**：2026-05-17 ~ 2026-12-31  
**分析依据**：开发需求文档概要

---

## 一、测试范围与目标

### 1.1 测试范围

| 维度 | 范围说明 |
|------|---------|
| **活动模块** | 模块一（免费领权益）、模块二（新人礼）、模块三（用户回馈礼）、模块四（更多精彩活动） |
| **终端覆盖** | iOS、Android、鸿蒙系统、Web端、小程序 |
| **用户类型** | 新用户（含首次注册+再活跃用户）、老用户 |
| **奖品类型** | 白银会员季卡、100G云空间年卡、支付宝红包、云朵 |
| **关联系统** | 风控系统（自有+IDaaS）、短信通知系统、会员权益系统、存储空间系统 |
| **活动周期** | 2026-05-17 ~ 2026-12-31（全程覆盖） |

### 1.2 测试目标

- **功能正确性**：确保新老用户身份识别准确，权益领取链路完整，奖品发放无误
- **用户区分准确性**：100% 正确区分新用户/老用户身份，权益发放不错不漏
- **风控有效性**：自有风控 + IDaaS 双层风控正确拦截黑产/作弊行为
- **多端一致性**：iOS/Android/鸿蒙/Web/小程序各端体验一致
- **活动周期稳定性**：跨越 7+ 个月长周期活动，系统稳定运行
- **安全性合规**：防止刷奖、薅羊毛、SQL注入、XSS 等安全风险

| 指标项 | 目标值 | 说明 |

| **页面首屏加载时间** | ≤ 2s | 活动首页首次加载 |

| 长周期稳定性 | 500 QPS | 72h+ | 无连接泄漏、无超时累积 |

## 七、异常场景测试

### 7.1 系统异常

| 场景 | 测试内容 | 预期结果 | 优先级 |
|------|---------|---------|--------|
| 自有风控系统宕机 | 风控服务不可用时，用户请求处理方式 | 降级放行或拒绝（按PRD策略），活动不阻塞 | **P0** |
| IDaaS系统宕机 | IDaaS认证超时/500 | 自有风控兜底，不影响用户领取 | **P0** |
| 数据库主库宕机 | MySQL/PostgreSQL不可用 | 读写分离降级，数据不丢失 | **P0** |
| Redis缓存失效 | Redis宕机/连接满 | 降级到数据库，风控结果可短暂缓存失效 | P1 |
| 支付宝接口超时 | 红包发放回调超时 | 重试机制执行，超时给用户补发 | **P0** |
| 短信通道不可用 | 短信发送失败 | 不阻塞领取，短信异步重试 | P2 |
| 消息队列积压 | Kafka/RabbitMQ消费延迟 | 权益发放异步处理，积压时告警 | P1 |

| 活动提前结束 | 奖池耗尽或运营手动关闭 | 用户看到"活动已结束"，已领取权益保留 | **P0** |
| 权益退款/撤回 | 用户投诉/风控后置发现作弊 | 权益正确撤回，短信通知用户 | P1 |
| 奖品库存超发 | 极端并发+系统Bug导致超发 | 事后审计发现，回滚或补差价处理 | **P0** |

### 7.3 用户操作异常

| 场景 | 测试内容 | 优先级 |
|------|---------|--------|
| 点击领取后立即返回上一页 | 异步领取结果正确同步 | P1 |
| 弱网下反复点击领取 | 防重复提交，状态正确 | P1 |
| 截图分享虚假领取成功 | 无实际影响（前端展示） | P2 |
| 用户清缓存后重新进入 | 领取状态从服务端拉取，不依赖本地缓存 | P1 |
