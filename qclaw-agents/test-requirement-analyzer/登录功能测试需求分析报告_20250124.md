## 二、功能点拆解与测试场景

### 2.1 用户名密码登录（RQ-01）

#### US-01: 正常登录流程

| 测试场景 | 等价类 | 测试数据 | 优先级 |
|---------|--------|---------|--------|
| TC-01-001: 正确用户名+正确密码登录成功 | 有效等价类 | user=有效用户, pwd=正确密码 | P0 |
| TC-01-002: 大小写敏感验证 | 边界条件 | user=Admin, pwd=PASS123 vs admin, pass123 | P1 |
| TC-01-003: 密码前后空格处理 | 边界条件 | pwd=" 123456 " vs "123456" | P1 |
| TC-01-004: 用户名特殊字符支持 | 有效等价类 | user=张三, user=john.doe | P2 |

**Given-When-Then 验收标准：**
```
Given 用户输入正确的用户名和密码
When 点击登录按钮或按回车键
Then 返回HTTP 200，页面跳转至目标页，用户Session有效
```

#### US-02: 边界条件登录

| 测试场景 | 等价类 | 测试数据 | 优先级 |
|---------|--------|---------|--------|
| TC-01-005: 用户名为空 | 无效等价类 | user="", pwd=任意 | P0 |
| TC-01-006: 密码为空 | 无效等价类 | user=任意, pwd="" | P0 |
| TC-01-007: 用户名密码均为空 | 无效等价类 | user="", pwd="" | P0 |
| TC-01-008: 用户名超长 | 边界值 | user=256字符字符串 | P1 |
| TC-01-009: 密码超长 | 边界值 | pwd=256字符字符串 | P1 |
| TC-01-010: 用户名包含SQL注入 | 安全边界 | user=' OR 1=1 -- | P0 |
| TC-01-011: 密码包含XSS脚本 | 安全边界 | pwd=<script>alert(1)</script> | P0 |
| TC-01-012: 空格账号（仅空格） | 边界条件 | user="   ", pwd="" | P1 |

**等价类划分：**
| 输入字段 | 有效等价类 | 无效等价类 |
|---------|-----------|-----------|
| 用户名 | 3-50位字母数字组合 | 空、<3位、>50位、特殊字符 |
| 密码 | 6-20位可见字符 | 空、<6位、>20位 |

**边界值分析：**
- 用户名长度：2, 3, 50, 51位
- 密码长度：5, 6, 20, 21位

| 测试场景 | 类型 | 优先级 |
|---------|------|--------|
| TC-01-013: 暴力破解防护 | 安全测试 | P0 |
| TC-01-014: 账户锁定验证 | 安全测试 | P0 |
| TC-01-015: 密码加密传输验证 | 安全测试 | P0 |
| TC-01-016: 会话Cookie安全属性 | 安全测试 | P1 |

### 2.2 记住我功能（RQ-02）

#### US-04: 记住我持久化

| 测试场景 | 验证点 | 优先级 |
|---------|--------|--------|
| TC-02-001: 勾选记住我后登录 | Cookie/LocalStorage持久化 | P0 |
| TC-02-002: 关闭浏览器重新打开 | 自动填充验证 | P0 |
| TC-02-003: 跨域名Session共享 | 多端同步 | P2 |
| TC-02-004: 记住我过期时间验证 | 超时后需重新登录 | P1 |
| TC-02-005: 清除缓存后登录状态 | 本地存储失效处理 | P1 |

**Given-When-Then 验收标准：**
```
Given 用户勾选"记住我"并成功登录
When 关闭浏览器，10分钟后重新打开
Then 用户名自动填充，可直接访问受保护页面
```

#### US-05: 记住我安全验证

| 测试场景 | 安全验证点 | 优先级 |
|---------|-----------|--------|
| TC-02-006: 记住我Token加密存储 | 敏感信息加密 | P0 |
| TC-02-007: 公共设备隐私保护 | 不保存敏感信息 | P1 |
| TC-02-008: 退出登录清除记住信息 | 彻底销毁凭证 | P0 |

### 2.3 错误处理与提示（RQ-03）

#### US-06: 错误密码场景

| 测试场景 | 输入条件 | 预期提示 | 优先级 |
|---------|---------|---------|--------|
| TC-03-001: 密码错误1次 | 正确用户+错误密码 | "用户名或密码错误" | P0 |
| TC-03-002: 密码错误3次 | 正确用户+连续错误 | 提示剩余尝试次数 | P0 |
| TC-03-003: 密码错误5次 | 正确用户+超限 | 账户锁定提示 | P0 |
| TC-03-004: 密码错误后正确登录 | 错误→正确密码 | 正常登录 | P0 |
| TC-03-005: 错误提示不暴露用户存在 | 不存在的用户 | 统一错误提示 | P1 |

**HTTP状态码验证：**
| 场景 | 预期状态码 | 错误类型 |
|------|-----------|---------|
| 用户不存在 | 200 | 前端判断 |
| 密码错误 | 200 | 前端判断 |
| 账户锁定 | 403 | 服务端返回 |

#### US-07: 错误用户名场景

| 测试场景 | 输入条件 | 预期行为 | 优先级 |
|---------|---------|---------|--------|
| TC-03-006: 用户名不存在 | 未注册用户+任意密码 | 友好提示，不暴露原因 | P0 |
| TC-03-007: 用户名格式错误 | 非法字符邮箱/手机号 | 格式校验提示 | P1 |
| TC-03-008: 未激活账户登录 | 已注册但未激活 | 激活提示 | P2 |

**错误消息安全规范：**
- ❌ 禁止："用户不存在" → 泄露用户信息
- ✅ 推荐："用户名或密码错误"
- ❌ 禁止："密码错误，还剩3次机会" → 暴露锁定策略
- ✅ 推荐：连续失败时显示，但不暴露具体策略

### 2.4 登录后跳转（RQ-04）

#### US-08: 正常跳转

| 测试场景 | 来源页面 | 目标页面 | 优先级 |
|---------|---------|---------|--------|
| TC-04-001: 从首页点击登录 | /index | /dashboard | P0 |
| TC-04-002: 从详情页登录 | /product/123 | /product/123 | P0 |
| TC-04-003: 从购物车登录 | /cart | /cart | P0 |
| TC-04-004: 直接访问登录页 | /login | /home | P1 |
| TC-04-005: URL带ReturnUrl参数 | /login?return=/order | /order | P0 |

**Given-When-Then 验收标准：**
```
Given 用户访问 /product/123 时跳转登录
When 用户成功登录
Then 页面跳转回 /product/123，而非默认首页
```

#### US-09: 跳转异常处理

| 测试场景 | 异常情况 | 预期处理 | 优先级 |
|---------|---------|---------|--------|
| TC-04-006: ReturnUrl跨域 | return=https://evil.com | 忽略，使用默认页 | P0 |
| TC-04-007: ReturnUrl为登录页 | return=/login | 使用默认页 | P1 |
| TC-04-008: ReturnUrl含特殊字符 | return=/page?id=<> | URL编码转义 | P0 |
| TC-04-009: Session过期后跳转 | 已登录但Session过期 | 跳转登录并提示 | P1 |

## 六、风险识别与评估

| 风险项 | 可能性 | 影响 | 应对策略 |
|-------|--------|------|---------|
| SQL注入漏洞 | 中 | 高 | 输入校验+参数化查询 |
| XSS攻击 | 中 | 高 | 输出转义+Content-Type |
| 暴力破解 | 高 | 中 | 限流+账户锁定 |
| Session劫持 | 低 | 高 | HttpOnly+Secure+SameSite |
| 跨站请求伪造 | 低 | 高 | CSRF Token验证 |
