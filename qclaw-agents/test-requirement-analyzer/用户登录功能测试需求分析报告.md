## 三、功能性需求分解（EPIC → 需求 → 用户故事）

### EPIC：用户登录功能测试

---

### 需求1：用户名密码登录验证

| ID | 用户故事 | 验收标准（Given-When-Then） |
|----|---------|---------------------------|
| **US-1.1** | 正常登录成功 | Given 用户输入正确的用户名和密码 When 点击登录 Then 返回200，页面跳转至首页，Session/Cookie已创建 |
| **US-1.2** | 空用户名验证 | Given 用户名为空 When 点击登录 Then 提示"用户名不能为空"，不发起请求 |
| **US-1.3** | 空密码验证 | Given 密码为空 When 点击登录 Then 提示"密码不能为空"，不发起请求 |
| **US-1.4** | SQL注入防护 | Given 用户名输入 `' OR '1'='1` When 点击登录 Then 提示登录失败，不执行SQL |
| **US-1.5** | XSS防护 | Given 用户名输入 `<script>alert(1)</script>` When 提交后页面显示用户名 Then 特殊字符被转义，不执行脚本 |

---

### 需求2：记住我功能

| ID | 用户故事 | 验收标准（Given-When-Then） |
|----|---------|---------------------------|
| **US-2.1** | 勾选记住我 | Given 用户勾选"记住我"并登录成功 When 关闭浏览器后重新打开 Then 自动填充用户名，保持登录状态7天 |
| **US-2.2** | 未勾选记住我 | Given 用户未勾选"记住我"并登录成功 When 关闭浏览器后重新打开 Then 需要重新登录，Session会话级有效 |
| **US-2.3** | Cookie安全属性 | Given "记住我"功能启用 When 检查Cookie Then HttpOnly=true, Secure=true, SameSite=Strict |
| **US-2.4** | 退出登录清除Cookie | Given 用户已登录且勾选"记住我" When 点击退出登录 Then 记住我Cookie被清除 |

**边界值分析：**
- Cookie过期时间边界：6天23小时59分（接近下限）、7天整、7天0小时1分（超过）
- Cookie大小限制：用户名最大长度校验

---

### 需求3：错误密码提示

| ID | 用户故事 | 验收标准（Given-When-Then） |
|----|---------|---------------------------|
| **US-3.1** | 错误密码提示 | Given 输入正确用户名+错误密码 When 点击登录 Then 提示"用户名或密码错误"（模糊化提示，防用户名遍历） |
| **US-3.2** | 错误次数限制 | Given 连续输入错误密码 When 第5次错误后 Then 账户锁定30分钟，提示"账户已锁定" |
| **US-3.3** | 验证码触发 | Given 连续3次登录失败 When 第4次登录时 Then 显示图形验证码，验证通过后才能继续 |
| **US-3.4** | 锁定期间登录 | Given 账户已被锁定 When 在锁定时间内尝试登录 Then 提示剩余锁定时间，拒绝登录 |

**等价类划分：**
| 输入条件 | 有效等价类 | 无效等价类 |
|---------|----------|-----------|
| 密码错误类型 | 1位错误、全部错误 | 正确密码 |
| 错误次数 | 1-4次（未触发限制） | 5次及以上（触发锁定） |

---

### 需求4：登录成功后跳转

| ID | 用户故事 | 验收标准（Given-When-Then） |
|----|---------|---------------------------|
| **US-4.1** | 跳转首页 | Given 登录成功 When 验证跳转 Then URL变更为首页，页面内容为首页 |
| **US-4.2** | 登录前URL恢复 | Given 用户访问 `/profile` 时跳转登录，登录成功后 When 验证跳转 Then URL恢复为 `/profile` |
| **US-4.3** | 会话超时跳转 | Given Session过期 When 用户操作 Then 自动跳转至登录页，登录成功后返回原页面 |
| **US-4.4** | Token传递验证 | Given 登录成功 When 检查请求头 Then Authorization包含有效Token |

## 四、非功能性需求

### 4.1 性能需求

| 指标 | 目标 | 测试标准依据 |
|------|------|-------------|
| 登录响应时间 | < 2秒 | 行业通用标准 |
| 记住我Cookie读取 | < 500ms | 性能测试要求 |
| 并发登录支持 | ≥ 1000并发 | 压力测试要求 |

### 4.2 安全需求

| 安全测试点 | 测试方法 | 验收标准 |
|-----------|---------|---------|
| 密码加密传输 | 抓包检查HTTP | 所有登录请求必须通过HTTPS |
| SQL注入防护 | 输入 `1' OR '1'='1` | 不执行SQL，返回登录失败 |
| XSS防护 | 输入 `<script>` | 特殊字符转义，不执行脚本 |
| CSRF防护 | 检查Token | 请求必须携带CSRF Token |
| 暴力破解防护 | 连续错误5次 | 触发账户锁定 |
| 会话安全 | 检查Cookie属性 | HttpOnly、Secure、SameSite |

### 4.3 可用性需求

| 检查项 | 验收标准 |
|-------|---------|
| 错误提示 | 提示信息友好，不暴露系统细节 |
| 输入验证 | 前端实时校验，无需等待服务器 |
| 键盘支持 | Tab切换焦点，Enter提交 |
| 移动端适配 | 响应式布局，触摸友好 |

### 4.4 兼容性需求

| 浏览器 | 最低版本 |
|-------|---------|
| Chrome | 90+ |
| Firefox | 88+ |
| Safari | 14+ |
| Edge | 90+ |

## 五、测试风险识别

### 5.1 风险评估矩阵

| 风险ID | 风险描述 | 可能性 | 影响 | 风险等级 | 应对策略 |
|-------|---------|-------|------|---------|---------|
| **R-1** | 用户名遍历攻击（攻击者利用统一错误提示枚举有效用户名） | 高 | 高 | 🔴高 | 验证错误提示统一为"用户名或密码错误" |
| **R-2** | 暴力破解（攻击者自动化尝试密码） | 高 | 高 | 🔴高 | 验证错误次数限制和验证码机制 |
| **R-3** | 会话劫持（Token/Cookie被窃取） | 中 | 高 | 🔴高 | 验证Cookie安全属性（HttpOnly、Secure） |
| **R-4** | SQL注入（密码字段注入） | 中 | 高 | 🔴高 | 验证参数化查询，测试注入payload |
| **R-5** | Open Redirect（登录后跳转恶意URL） | 低 | 中 | 🟡中 | 验证redirect_url白名单机制 |
| **R-6** | 记住我Cookie伪造 | 中 | 高 | 🔴高 | 验证Cookie签名机制，不可伪造 |
| **R-7** | 并发登录性能问题 | 中 | 中 | 🟡中 | 执行压力测试验证 |
