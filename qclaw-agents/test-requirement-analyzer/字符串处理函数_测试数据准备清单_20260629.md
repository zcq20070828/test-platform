## 五、数据生成脚本

### 5.1 生成超长字符串（Python）

```python
# 生成10000字符的测试字符串
import string
import random

def generate_long_string(length=10000):
    chars = string.ascii_letters + string.digits + "中文测试"
    return ''.join(random.choice(chars) for _ in range(length))

# 使用示例
long_str = generate_long_string(10000)
print(f"生成字符串长度: {len(long_str)}")
```
