## 一、功能需求清单

### 1.1 加法运算 (Addition)

| 需求项 | 规则说明 |
|--------|----------|
| **输入类型** | 两个操作数（整数/小数/负数） |
| **有效输入** | 数字字符、负号、小数点 |
| **输出规则** | 精确到参与运算的小数位数，最多显示15位有效数字 |
| **结果格式** | 自动去除末尾无效零 |
| **溢出处理** | 超出范围显示 `Error: Overflow` 或 `Infinity` |

> ⚠️ **产品规格书依赖项**：需明确整数运算上限（如是否采用IEEE 754双精度浮点，最大安全整数为 2^53-1 = **9007199254740991**）

### 1.2 减法运算 (Subtraction)

| 需求项 | 规则说明 |
|--------|----------|
| **输入类型** | 两个操作数（被减数 - 减数） |
| **有效输入** | 同加法 |
| **输出规则** | 结果可为负数，负号显示在数字前 |
| **精度规则** | 使用被减数与减数中较大的小数位数 |
| **边界情况** | 0 - 正数 = 负数，符合数学定义 |

### 1.3 乘法运算 (Multiplication)

| 需求项 | 规则说明 |
|--------|----------|
| **输入类型** | 两个操作数 |
| **输出规则** | 结果精确到所有因子小数位数之和 |
| **零乘规则** | 任何数 × 0 = 0 |
| **溢出处理** | 超大数用科学计数法表示 |
| **精度问题** | 注意浮点数精度丢失（如 0.1 × 0.2 ≠ 0.02） |

### 1.4 除法运算 (Division)

| 需求项 | 规则说明 |
|--------|----------|
| **输入类型** | 被除数 ÷ 除数 |
| **除零禁止** | 除数不能为 0，否则显示 `Error: Division by zero` |
| **整数除法** | 结果向下取整或保留小数，由设置决定 |
| **精度规则** | 默认保留8位小数，最后一位四舍五入 |
| **零除规则** | 0 ÷ 任何非零数 = 0 |

## 二、边界条件分析

### 2.1 基于等价类划分的输入域

| 操作 | 有效等价类 | 无效等价类 |
|------|-----------|------------|
| **加法** | 整数+整数、正数+负数、小数+小数 | 非数字输入、空输入、超长数字 |
| **减法** | 大数-小数、小数-大数、负数-负数 | 非数字输入、空输入 |
| **乘法** | 正×正、正×负、负×负、零×任意 | 非数字输入、空输入 |
| **除法** | 正÷正、正÷负、零÷非零 | 除数为零、非数字输入、空输入 |

### 2.2 边界值分析（需产品规格书确认）

| 参数 | 假设值 | 来源依据 | 需确认项 |
|------|--------|----------|----------|
| **安全整数上限** | 9,007,199,254,740,991 | IEEE 754双精度浮点精度上限 | 产品是否支持超过此值 |
| **显示最大位数** | 15位 | 常见计算器设计规范 | 产品规格是否一致 |
| **小数精度** | 8位小数 | 常见财务计算标准 | 产品是否支持配置 |
| **指数表示阈值** | e±308 或 e±18 | 取决于实现方式 | 需产品规格书明确 |

> 📌 **待确认边界值**（需产品规格书补充）：
> 1. 实际允许输入的最大数字位数
> 2. 运算溢出的具体阈值
> 3. 小数位数的最大允许位数
> 4. 负数最小值的绝对值上限

### 2.3 关键边界场景

| # | 场景 | 预期结果 | 优先级 | 需产品规格书 |
|---|------|---------|--------|-------------|
| 1 | 最大安全整数 + 最大安全整数 | 溢出或正确结果 | P0 | ✅ 需确认溢出阈值 |
| 2 | 最小负数 - 最大正整数 | 溢出或正确结果 | P0 | ✅ 需确认最小值 |
| 3 | 任何数 ÷ 0 | Error提示 | P0 | ❌ 无需确认 |
| 4 | 0 ÷ 0 | Error (不确定形式) | P0 | ❌ 无需确认 |
| 5 | 极大数 × 极小数 | 精度丢失风险 | P1 | ✅ 需确认精度处理 |
| 6 | 0.1 + 0.2 | 0.3 (需特殊处理) | P1 | ❌ 无需确认 |
| 7 | 1 ÷ 3 × 3 | 应接近1 (精度验证) | P1 | ❌ 无需确认 |
| 8 | 小数除法结果 | 精确到8位小数 | P1 | ✅ 需确认位数配置 |
| 9 | 连续运算括号 | 正确优先级 | P1 | ❌ 无需确认 |
| 10 | 负号位置 | -5 - (-3) = -2 | P2 | ❌ 无需确认 |

### 2.4 特殊数值测试点（基于IEEE 754标准假设）

```markdown
■ 零值测试
  - 0 + 0 = 0
  - 0 - 0 = 0  
  - 0 × N = 0
  - 0 ÷ N = 0 (N≠0)
  
■ 极值测试（基于安全整数 2^53-1 = 9,007,199,254,740,991）
  - 9,007,199,254,740,991 + 1 = 精度丢失或溢出
  - -9,007,199,254,740,991 - 1 = 精度丢失或溢出
  - 9,007,199,254,740,991 × 2 = 溢出风险
  - 9,007,199,254,740,991 ÷ 1 = 9,007,199,254,740,991
  
■ 负数边界（基于IEEE 754假设）
  - -9,007,199,254,740,991 - 1 = 溢出风险
  - -9,007,199,254,740,991 × (-1) = 溢出风险
  
⚠️ 注：以上基于IEEE 754双精度浮点标准假设，实际值需产品规格书确认
```

## 三、UI交互需求

### 3.1 按钮交互矩阵

| 元素 | 操作方式 | 响应要求 | 时限 |
|------|----------|----------|------|
| 数字按钮(0-9) | 单击 | 即时显示在输入区 | <50ms |
| 小数点按钮 | 单击 | 仅允许一个 | <50ms |
| 运算符按钮 | 单击 | 高亮选中状态 | <50ms |
| 等号按钮 | 单击 | 执行运算，显示结果 | <100ms |
| C/AC清除 | 单击 | 清空当前输入/全部重置 | <50ms |
| 退格(⌫) | 单击 | 删除最后一位 | <50ms |
| 括号按钮 | 单击 | 插入/闭合括号 | <50ms |

### 3.2 输入验证规则

```
✅ 有效输入                    ❌ 无效输入处理
─────────────────────────     ─────────────────────────
数字0-9                       同时多个小数点 → 忽略后续
单个小数点                    多余前导零 → 自动去除
负号(首个字符位置)            运算中多余负号 → 忽略
正号(首个字符位置)            连续运算符 → 替换后者
括号()                        未闭合括号 → 自动补充或提示
```

### 3.3 结果显示规范

| 结果类型 | 显示格式 | 示例 |
|----------|----------|------|
| 整数结果 | 无小数点 | `123` |
| 小数结果 | 保留有效位 | `123.45` |
| 无理数 | 保留8位小数 | `0.33333333` |
| 溢出 | 科学计数法 | `1.23e+18` |
| 错误 | 红色Error文字 | `Error: Overflow` |
| 空结果 | 显示 `0` | `0` |

### 3.4 交互状态指示

```
┌────────────────────────────────────────────┐
│  [AC]  [C]   [⌫]   [÷]   ← 操作按钮       │
│  [7]   [8]   [9]   [×]                     │
│  [4]   [5]   [6]   [−]                     │
│  [1]   [2]   [3]   [+]                     │
│  [±]   [0]   [.]   [=]                     │
└────────────────────────────────────────────┘

状态指示：
□ 输入中：数字逐字符显示
□ 运算符待输入：运算符按钮高亮
□ 计算中：等号按钮loading状态
□ 结果显示：结果区高亮1秒后恢复
□ 错误状态：显示区红色背景闪烁
```

## 四、工作流/页面上下文特殊考虑

### 4.1 多步运算链

```
场景：连续运算表达式
输入：10 + 20 × 3 - 5 ÷ 2

需求点：
┌──────────────────────────────────────────────────┐
│ 1. 运算符优先级处理                               │
│    - 乘除优先于加减                               │
│    - 10 + 20 × 3 - 5 ÷ 2                        │
│    - 应先计算: 20×3=60, 5÷2=2.5                 │
│    - 再计算: 10+60-2.5=67.5                      │
│                                                  │
│ 2. 括号优先级覆盖                                 │
│    - (10 + 20) × (3 - 5) ÷ 2 = 30 × (-2) ÷ 2  │
│    - = -60 ÷ 2 = -30                             │
│                                                  │
│ 3. 运算结果参与后续计算                            │
│    - 第一个运算结果可作为第二个运算的被操作数      │
│    - 例: 5+5=10 → +3=13 → ×2=26                 │
└──────────────────────────────────────────────────┘
```

### 4.2 页面状态持久化

| 场景 | 需求 | 测试点 |
|------|------|--------|
| 页面刷新 | 保持当前输入 | 刷新后显示刷新前内容 |
| 页面切换 | 保存运算状态 | 切换回来可继续 |
| Session超时 | 自动保存 | 超时后可恢复 |
| 多标签页 | 独立状态 | 各标签计算器独立 |

### 4.3 计算依赖场景

```
┌────────────────────────────────────────────────────────────┐
│  工作流编排中的计算器依赖场景                               │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  场景A: 金额汇总                                            │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐            │
│  │ 商品A价格 │ → │ 商品B价格 │ → │  合计金额  │            │
│  │   ¥299   │ + │   ¥199   │ = │   ¥498   │            │
│  └──────────┘    └──────────┘    └──────────┘            │
│  测试点：汇总计算结果需精确传递                              │
│                                                            │
│  场景B: 百分比计算                                          │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐            │
│  │  目标值   │ → │  百分比   │ → │   结果值   │            │
│  │  1000    │ × │   15%    │ = │   150    │            │
│  └──────────┘    └──────────┘    └──────────┘            │
│  测试点：0.15与15%需明确区分                                │
│                                                            │
│  场景C: 税费计算链                                          │
│  税前价 → 加税 → 四舍五入 → 显示                            │
│  测试点：中间步骤精度保留，最终显示取整                      │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 4.4 并发与竞态处理

| 场景 | 风险点 | 测试需求 |
|------|--------|----------|
| 快速连击运算符 | 重复触发计算 | 防抖处理，忽略500ms内重复点击 |
| 同时输入+计算 | 状态不一致 | 锁定输入区直到计算完成 |
| 异步工作流计算 | 结果返回时页面已离开 | 结果缓存+页面恢复机制 |
