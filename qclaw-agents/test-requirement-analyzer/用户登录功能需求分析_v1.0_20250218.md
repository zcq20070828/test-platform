# 用户登录功能需求分析文档
**版本号**：v1.0  
**创建日期**：2025-02-18  
**适用范围**：Web端企业级应用登录功能测试  

---

## 一、需求背景与利益相关者
### 1.1 需求背景
保障用户能够安全、快捷地访问应用系统，防止非法登录，守护用户数据安全和系统稳定。

### 1.2 利益相关者
| 角色 | 核心诉求 |
|------|----------|
| 最终用户 | 登录流程简单、错误提示清晰、账号安全 |
| 产品经理 | 登录成功率≥99.9%，支持多渠道登录 |
| 研发团队 | 登录接口性能达标，安全防护到位 |
| 测试团队 | 需求明确、可测试性强、覆盖全场景 |
| 安全合规 | 符合等保2.0要求，密码加密存储、防暴力破解 |

---

## 二、范围界定
### 2.1 包含范围
✅ 账号密码登录（含输入校验、错误提示）  
✅ 短信验证码登录（含发送、校验、有效期控制）  
✅ 企业微信第三方登录（含授权、回调、账号绑定）  
✅ 忘记密码（含身份验证、密码重置）  
✅ 登录态管理（含记住登录、过期控制、登出清除）  
✅ 安全控制（含登录失败锁定、验证码防暴力破解）

### 2.2 排除范围
❌ 用户自主注册  
❌ 账号注销/冻结/解冻  
❌ 细粒度权限管理  
❌ 跨系统单点登录（SSO）

## 四、非功能需求指标
### 4.1 性能需求
| 指标 | 要求 | 测试标准 |
|------|------|----------|
| 登录接口响应时间 | ≤200ms（95分位） | 压力测试1000并发用户，95分位响应时间≤200ms |
| 登录成功率 | ≥99.9% | 压测10万次登录请求，失败次数≤100次 |
| 验证码发送延迟 | ≤3s | 模拟100并发获取验证码，平均延迟≤3s |
| 页面加载时间 | ≤1s | Chrome DevTools测试登录页面首屏加载时间≤1s |

### 4.2 安全需求
✅ 密码采用BCrypt加密存储，不可逆  
✅ 登录失败5次锁定账号30分钟，防暴力破解  
✅ 验证码5分钟有效期，错误3次锁定15分钟  
✅ 登录态采用HttpOnly、Secure Cookie存储，防XSS攻击  
✅ 所有登录接口支持HTTPS，传输数据加密  
✅ 防CSRF攻击，登录请求携带CSRF Token

### 4.3 兼容性需求
| 浏览器/设备 | 版本要求 | 测试标准 |
|-------------|----------|----------|
| Chrome | ≥90 | 登录功能正常，样式无错位 |
| Firefox | ≥88 | 登录功能正常，样式无错位 |
| Safari | ≥14 | 登录功能正常，样式无错位 |
| Edge | ≥90 | 登录功能正常，样式无错位 |
| 移动端浏览器 | Chrome/ Safari最新版 | 登录页面自适应，点击无错位 |

### 4.4 可用性需求
✅ 错误提示清晰明确，无技术术语（如「账号或密码错误」而非「数据库查询失败」）  
✅ 加载状态明确，登录/获取验证码时显示加载动画  
✅ 记住账号功能默认关闭，用户可自主选择  
✅ 第三方登录入口明确，有对应图标标识

## 五、MoSCoW优先级排序
### 5.1 Must Have（P0，上线前必须验证）
1. 正确账号密码登录成功
2. 账号/密码为空校验
3. 错误密码登录失败提示与账号锁定

7. 登出功能
8. SQL注入防护
9. 密码加密存储
10. 登录接口性能达标

### 5.2 Should Have（P1，上线前尽量验证）
1. 密码大小写敏感校验
2. 未注册手机号验证码获取拦截

## 六、前置依赖与风险分析
### 6.1 前置依赖
1. 测试环境部署完成，登录接口可正常访问
2. 测试账号准备完成：已注册账号、未注册账号、锁定账号、绑定企业微信账号
3. 短信验证码服务、企业微信开放平台配置完成
4. 测试工具准备完成：抓包工具（Fiddler/Charles）、性能测试工具（JMeter）、浏览器兼容性测试环境

### 6.2 风险分析
| 风险描述 | 影响程度 | 应对措施 |
|----------|----------|----------|
| 第三方服务（企业微信、短信）不稳定，导致测试失败 | 中 | 提前申请测试专用AppID，服务不可用时跳过对应用例 |
| 兼容性测试设备不足，无法覆盖所有浏览器版本 | 低 | 优先覆盖95%以上用户使用的浏览器版本 |
| 性能测试环境与生产环境配置差异大，结果不准确 | 中 | 尽量模拟生产环境配置，测试结果乘以系数修正 |

## 七、可测试性分析
✅ 所有功能点均有明确的预期结果，可通过接口返回、页面跳转、Cookie状态验证  
✅ 核心登录接口支持自动化测试，可通过JMeter/Postman实现接口自动化  
✅ 异常场景（账号锁定、验证码过期）可通过测试数据模拟，无需等待真实时间  
✅ 性能指标可通过压测工具量化验证，无主观判断项
