# 用户登录功能 - 测试需求分析报告 v5.0

需求: 用户名密码登录, 验证码登录, 忘记密码
日期: 2026-06-29

## 1. 需求模块

### 1.1 用户名密码登录 (REQ-001 | P0)
14个用户故事:
- US-001: 正常登录(test_user/Pass1234) -> 成功跳转首页
- US-002: 空用户名 -> 提示请输入用户名,不发起请求
- US-003: 空密码 -> 提示请输入密码,不发起请求
- US-004: 用户名不存在 -> 提示"用户名或密码错误"(统一模糊)
- US-005: 密码错误 -> 提示"用户名或密码错误"(不暴露字段)
- US-006: 账号禁用 -> 提示"账号已被禁用,请联系管理员"
- US-007: 记住我(勾选) -> 30天免登录,Cookie安全属性
- US-008: 不勾选记住我 -> session级有效,关闭需重登
- US-009: 5次错误锁定 -> 第5次锁定30分钟
- US-010: 锁定期拒绝 -> 提示剩余锁定时间
- US-011: 登录跳转 -> URL变更为首页
- US-012: SQL注入 -> 用户名' OR '1'='1,登录失败无报错
- US-013: XSS攻击 -> 用户名<script>alert(1)</script>,被过滤
- US-014: 手机号/邮箱登录 -> 支持绑定号码登录

### 1.2 验证码登录 (REQ-002 | P0)
10个用户故事:
- US-015: 正常登录(手机号+验证码) -> 成功跳转首页
- US-016: 手机号为空 -> 提示请输入手机号
- US-017: 手机号格式错误 -> 10位/12位/含字母,提示格式错误
- US-018: 验证码为空 -> 提示请输入验证码
- US-019: 验证码错误 -> 输入000000,提示验证码错误
- US-020: 验证码过期 -> 超过5分钟,提示已过期
- US-021: 发送倒计时 -> 按钮60秒倒计时,不可重复点击
- US-022: 频率限制 -> 60秒内再次点击不发送
- US-023: 未注册手机号 -> 自动注册并登录
- US-024: 验证码重放 -> 已用验证码再次使用,提示已失效

### 1.3 忘记密码 (REQ-003 | P1)
9个用户故事:
- US-025: 正常重置 -> 身份验证+新密码+确认->重置成功跳转登录
- US-026: 手机号为空 -> 提示请输入手机号
- US-027: 未注册手机号 -> 提示该手机号未注册
- US-028: 新密码为空 -> 提示请输入新密码
- US-029: 确认密码不一致 -> 提示两次输入不一致
- US-030: 密码强度不足(纯数字6位) -> 提示强度过低
- US-031: 新旧密码相同 -> 提示不能与旧密码相同
- US-032: 重置后旧密码失效 -> 用旧密码登录失败
- US-033: 重置后新密码可用 -> 用新密码登录成功

## 2. 安全需求 (10项P0)

| 编号 | 类型 | 防护策略 | 测试数据 |
|------|------|---------|----------|
| SEC-01 | SQL注入 | 参数化查询 | ' OR '1'='1 |
| SEC-02 | XSS | 输入过滤+输出编码 | <script>alert(1)</script> |
| SEC-03 | 暴力破解 | 5次错误锁定30分钟 | 连续5次错误密码 |
| SEC-04 | 验证码防刷 | 60秒频率限制 | 60秒内重复获取 |
| SEC-05 | 验证码安全 | 5分钟有效期+单次有效 | 过期/已用验证码 |
| SEC-06 | HTTPS传输 | 请求体加密 | 抓包检查 |
| SEC-07 | bcrypt存储 | 加盐哈希 | 数据库检查 |
| SEC-08 | Cookie安全 | HttpOnly+Secure+SameSite | DevTools检查 |
| SEC-09 | 错误提示 | 统一"用户名或密码错误" | 不暴露具体原因 |
| SEC-10 | 图形验证码 | 3次失败后触发 | 连续3次错误后观察 |

## 3. 边界条件

| 输入项 | 合法范围 | 边界测试(无效/有效) |
|--------|----------|-------------------|
| 用户名长度 | 2-50字符 | 1/2,50/51 |
| 密码长度 | 6-32字符 | 5/6,32/33 |
| 手机号 | 11位数字 | 10/11,12/含字母 |
| 验证码 | 6位数字 | 5/6,7/含字母 |
| 错误次数 | 1-4次 | 4/5次(是否锁定) |
| 首尾空格 | 自动去除 | " test_user " -> test_user |

## 4. 风险矩阵

| 风险 | 等级 | 应对 |
|------|------|------|
| 用户枚举 | 高 | 统一错误提示 |
| 暴力破解 | 高 | 5次锁定+图形验证码 |
| 短信轰炸 | 高 | 60秒频率+IP限流 |
| 验证码重放 | 高 | 单次有效+5分钟过期 |
| SQL注入 | 高 | 参数化查询 |
| 会话劫持 | 中 | HttpOnly+Secure |
| 密码复用 | 中 | 新旧密码校验 |
