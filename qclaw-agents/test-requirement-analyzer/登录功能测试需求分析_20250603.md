## 1. 需求背景与范围界定

### 1.1 业务背景
用户登录是系统安全的第一道防线，也是用户进入系统的唯一入口。登录功能的稳定性和安全性直接影响用户体验和系统安全。

### 1.2 范围界定

**包含范围：**
- 账号密码登录
- 验证码登录（短信/邮箱）
- 第三方社交登录（可选）
- 登录安全保护机制
- 登录状态管理

**不包含范围：**
- 注册/忘记密码功能（独立EPIC）
- 密码找回流程
- 账号锁定解锁流程
- SSO单点登录集成

## 3. 验收标准（Given-When-Then格式）

### AC-001：正常账号密码登录成功
```
Given 用户在登录页面
And 输入正确的手机号/邮箱
And 输入正确的密码
When 点击"登录"按钮
Then 页面跳转到首页/个人中心
And 显示"登录成功"提示
And 用户信息写入session
```

### AC-002：账号不存在
```
Given 用户在登录页面
And 输入不存在的账号
And 输入任意密码
When 点击"登录"按钮
Then 显示"账号不存在，请检查或前往注册"
And 不跳转到其他页面
```

### AC-003：密码错误
```
Given 用户在登录页面
And 输入正确的账号
And 输入错误的密码
When 点击"登录"按钮
Then 显示"密码错误，剩余N次机会"
And 密码输入框清空并获得焦点
And 登录失败次数+1
```

### AC-004：账号被锁定
```
Given 用户输入正确账号密码
When 登录失败达到5次后
Then 显示"账号已被锁定，请N分钟后重试或联系客服"
And 禁止该账号登录
```

### AC-005：登录请求超时
```
Given 网络异常或服务器无响应
When 用户提交登录请求
Then 显示"网络异常，请检查网络后重试"
And 提供"重试"按钮
```

### AC-006：记住登录状态
```
Given 用户勾选"记住我"选项
And 登录成功
When 关闭浏览器后重新打开
Then 用户仍然处于登录状态
And token有效期为30天
```

### AC-007：安全提示不泄露信息
```
Given 用户输入错误账号
When 提示错误信息时
Then 提示"账号或密码错误"
And 不提示"账号不存在"或"密码错误"
```

### AC-008：短信验证码发送
```
Given 用户选择短信登录
And 输入正确的手机号
When 点击"获取验证码"
Then 显示"验证码已发送"
And 手机收到6位数字验证码
And 倒计时60秒显示
```

### AC-009：验证码格式校验
```
Given 用户输入验证码
When 验证码长度不足6位
Then 显示"验证码格式错误"
And 不允许提交
```

### AC-010：验证码过期
```
Given 用户收到验证码
When 验证码超过5分钟未使用
Then 显示"验证码已过期，请重新获取"
```

### AC-011：验证码错误
```
Given 用户输入错误的验证码
When 点击"验证登录"
Then 显示"验证码错误，请重新输入"
And 验证码输入框清空
```

### AC-012：验证码输入错误3次
```
Given 用户连续3次输入错误验证码
When 第3次提交后
Then 验证码自动失效
And 强制重新获取
```

### AC-013：验证码重新发送
```
Given 验证码倒计时未结束
When 用户点击"重新发送"
Then 提示"请N秒后重试"
When 倒计时结束
Then "重新发送"按钮可用
And 点击后重新发送验证码
```

### AC-014：暴力破解防护-账号锁定
```
Given 同一账号登录失败5次
When 第6次登录尝试
Then 账号锁定30分钟
And 提示锁定信息
```

### AC-015：暴力破解防护-IP限制
```
Given 同一IP在1分钟内登录失败10次
When 第11次登录尝试
Then 临时封禁该IP 15分钟
And 提示"操作过于频繁，请稍后再试"
```

### AC-016：锁定后自动解锁
```
Given 账号因连续失败被锁定
When 锁定满30分钟后
Then 账号自动解锁
And 失败次数清零
```

### AC-017：图形验证码触发
```
Given 用户连续登录失败2次
When 第3次登录尝试
Then 弹出图形验证码
And 必须正确输入后才能继续登录
```

### AC-018：登录日志记录
```
Given 用户登录行为发生
When 无论成功或失败
Then 记录：时间、账号、IP、设备、结果、UA
And 日志保存不少于6个月
```

### AC-019：微信登录跳转
```
Given 用户点击"微信登录"
When 授权页面加载完成
Then 跳转到微信授权页面
And 显示应用名称和权限请求
```

### AC-020：微信授权回调
```
Given 用户在微信授权页面点击"授权"
When 微信回调系统
Then 创建/关联本地账号
And 完成登录并跳转
```

### AC-021：第三方登录账号冲突
```
Given 第三方账号已关联本地账号
And 用户尝试用同一第三方账号登录
When 授权成功后
Then 跳转到已关联的本地账号
And 保持登录状态
```

## 5. 边界条件分析

### 5.1 输入边界

| 字段 | 边界值 | 测试要点 |
|------|--------|----------|
| 手机号 | 11位、10位、12位、空值、特殊字符 | 格式校验 |
| 密码 | 6位、18位、19位、空值、超长 | 长度限制 |
| 验证码 | 5位、7位、非数字、6位正确 | 格式+正确性 |

### 5.2 等价类划分

**手机号等价类：**
| 类型 | 示例 | 预期 |
|------|------|------|
| 有效 | 13800138000 | 格式正确 |
| 无效-过短 | 1380013800 | 格式错误提示 |
| 无效-过长 | 138001380001 | 格式错误提示 |
| 无效-非数字 | 13800138abc | 格式错误提示 |

**密码等价类：**
| 类型 | 示例 | 预期 |
|------|------|------|
| 有效 | aA123456 | 正常登录 |
| 无效-过短 | aA1234 | 密码强度不足提示 |
| 无效-过长 | aA1234567890123456789 | 超过最大长度提示 |

## 6. 风险评估

### 6.1 高风险项 ⚠️

| 风险点 | 描述 | 影响 | 应对措施 |
|--------|------|------|----------|
| R-001 | 暴力破解漏洞 | 账号被暴力破解 | 必须实现账号锁定+IP限制 |
| R-002 | 敏感信息泄露 | 错误提示暴露账号存在性 | 统一模糊错误提示 |
| R-003 | Session劫持 | 用户身份被冒充 | HTTPS+HttpOnly Cookie |

### 6.2 中风险项 ⚡

| 风险点 | 描述 | 影响 | 应对措施 |
|--------|------|------|----------|
| R-004 | 验证码短信轰炸 | 资源浪费/骚扰用户 | 限频+24小时上限 |
| R-005 | 并发登录冲突 | 多设备登录状态异常 | Token机制+踢人策略 |

### 6.3 低风险项 📝

| 风险点 | 描述 | 影响 | 应对措施 |
|--------|------|------|----------|
| R-006 | 第三方登录回调失败 | 用户无法完成登录 | 超时处理+降级方案 |

## 8. AI可执行范围 vs 人工必须覆盖范围

### ✅ AI可自动化执行

| 测试类型 | 具体内容 | 工具 |
|----------|----------|------|
| 功能测试 | 正常流程、边界值、等价类 | Selenium/Playwright |
| 接口测试 | 登录API、验证码API | Postman/curl |
| 自动化脚本 | 暴力破解模拟、并发测试 | JMeter/Locust |

### ⚠️ 人工必须覆盖

| 测试类型 | 原因 | 建议 |
|----------|------|------|
| 安全渗透测试 | 需要专业安全知识 | 安全团队专项测试 |
| 图形验证码识别 | AI识别存在不确定性 | 人工测试 |
| 第三方登录兼容 | 依赖外部系统 | 兼容性专项测试 |
| 边界异常场景 | 需要人工判断合理性 | 探索性测试 |
