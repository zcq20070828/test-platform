## 五、边界值分析

| 边界点 | 测试值 | 预期结果 |
|--------|--------|----------|
| 密码最小长度（6字符） | 输入5字符 | ❌ 提示"密码长度不足" |

| 账号格式（邮箱） | 输入不含@的字符串 | ❌ 提示"账号格式不正确" |
| 错误次数阈值（5次） | 第5次输入正确密码 | ✅ 登录成功，错误计数重置 |
| 验证码有效期（5分钟） | 第6分钟输入 | ❌ 提示"验证码已过期" |
| 连续输错验证码（3次） | 第4次输入 | ❌ "错误次数过多，请重新获取" |

## 六、验收标准（Given-When-Then）

### AC-001: 正常登录
```
Given 用户已注册且账号状态正常
When  用户输入正确的账号和密码，点击登录
Then  系统返回 200 状态码
And   响应包含有效 Token/SessionID
And   页面跳转至首页，显示用户信息
```

### AC-002: 密码错误
```
Given 用户已注册
When  用户输入正确账号但错误密码
Then  返回 401 状态码
And   提示"用户名或密码错误"（模糊提示，防账号枚举）
And   记录错误次数，显示剩余机会
```

### AC-003: 账号不存在
```
Given 用户输入的账号未注册
When  用户点击登录
Then  返回 401 状态码
And   提示"用户名或密码错误"（与AC-002同一文案）
And   不创建任何会话
```

### AC-004: 空输入拦截
```
Given 用户未输入账号或密码
When  用户点击登录
Then  对应输入框显示错误提示
And   前端阻止表单提交，不调后端接口
```

### AC-005: 账号锁定
```
Given 用户连续输错密码达到5次
When  用户第6次尝试登录
Then  返回 403 状态码
And   提示"账号已锁定，请30分钟后重试"
And   锁定期间正确密码也无法登录
```

### AC-006: 会话超时
```
Given 用户已登录，会话超时（30分钟无操作）
When  用户发起业务请求
Then  返回 401 状态码
And   跳转登录页，提示"登录状态已过期"
```
