## 二、需求概述

### 2.1 背景与目标

用户登录模块是系统安全的第一道防线。本分析将登录功能分解为可测试的需求单元，定义明确的验收标准，确保测试覆盖率。

### 2.2 功能范围

| 在范围内 | 不在范围内 |
|---------|-----------|
| 账号密码登录 | 第三方登录（OAuth） |
| 验证码校验（图形+短信/邮箱） | 生物特征登录 |
| 记住登录（记住我） | 注册流程 |
| 密码找回 | 权限管理（RBAC） |
| 登录态管理 | SSO单点登录 |
| 安全防护机制 | |

### 2.3 利益相关者

| 角色 | 关注点 |
|------|--------|
| 最终用户 | 登录便捷性、错误提示友好度 |
| 安全审计方 | 密码加密、防暴力破解、会话安全 |
| 开发团队 | 接口规范、边界条件、异常处理 |
| 测试团队 | 可测试性、验收标准明确性 |

## 五、验收标准（Given-When-Then格式）

### 5.1 EPIC-01：账号密码登录（8条AC）

**AC-001：正常登录成功**
- **Given** 用户已注册且账号状态正常
- **When** 用户输入正确的用户名和匹配的密码，点击登录
- **Then** 系统返回登录成功（HTTP 200），跳转首页，返回有效Token
- **关联FP：** FP-01.1.1
- **测试类型：** 功能测试

**AC-002：密码错误登录失败**
- **Given** 用户已注册
- **When** 用户输入正确的用户名和错误的密码
- **Then** 系统返回「账号或密码错误」（HTTP 401），不泄露是账号不存在还是密码错误
- **关联FP：** FP-01.2.3
- **测试类型：** 功能测试、安全测试
- **标准引用：** OWASP ASVS V2.1.1

**AC-003：用户名不存在**
- **Given** 用户未注册
- **When** 用户输入不存在的用户名
- **Then** 系统返回「账号或密码错误」（HTTP 401），与AC-002响应体完全一致
- **关联FP：** FP-01.2.3
- **测试类型：** 安全测试
- **标准引用：** OWASP ASVS V2.1.1

**AC-004：空输入校验**
- **Given** 用户位于登录页面
- **When** 用户用户名为空或密码为空时点击登录
- **Then** 前端提示「请输入用户名/密码」，请求不发送至后端
- **关联FP：** FP-01.2.1
- **测试类型：** 功能测试、边界测试

**AC-005：密码复杂度校验**
- **Given** 系统设定密码规则（≥8位，含字母+数字）
- **When** 用户输入不符合复杂度要求的密码
- **Then** 系统拒绝注册/修改，提示具体规则
- **关联FP：** FP-01.1.1
- **测试类型：** 功能测试
- **标准引用：** NIST SP 800-63B §5.1.1

**AC-006：登录频率限制**
- **Given** 某IP在5分钟内失败≥5次
- **When** 该IP再次尝试登录
- **Then** 系统返回「操作过于频繁」（HTTP 429），展示倒计时
- **关联FP：** FP-01.3.1
- **测试类型：** 安全测试、压力测试
- **标准引用：** OWASP ASVS V2.2.5

**AC-007：密码加密传输**
- **Given** 用户提交登录表单
- **When** 密码从前端传输到后端
- **Then** 密码必须经HTTPS+前端加密，传输链路不可见明文
- **关联FP：** FP-01.1.2
- **测试类型：** 安全测试
- **标准引用：** OWASP ASVS V2.1.7、V9.1.1；PCI DSS 4.0
- **⚠️ 人工必覆盖：** 需抓包工具验证

**AC-008：SQL注入防护**
- **Given** 系统使用参数化查询
- **When** 用户名输入SQL注入语句（如`' OR 1=1 --`）
- **Then** 系统返回「账号或密码错误」（HTTP 401），不泄露数据
- **关联FP：** FP-01.2.2
- **测试类型：** 安全测试
- **标准引用：** OWASP ASVS V5.3

### 5.2 EPIC-02：验证码校验（5条AC）

**AC-009：图形验证码正常展示**
- **Given** 用户访问登录页面
- **When** 登录页面加载
- **Then** 展示图形验证码图片，内容为4-6位随机字符，含干扰线/扭曲
- **关联FP：** FP-02.1.1
- **测试类型：** 功能测试
- **⚠️ 人工必覆盖：** 需主观判断可读性

**AC-010：图形验证码校验失败**
- **Given** 用户输入了正确的账号密码
- **When** 用户输入错误图形验证码并提交
- **Then** 系统返回「验证码错误」（HTTP 400），不校验密码
- **关联FP：** FP-02.1.1
- **测试类型：** 功能测试

**AC-011：短信/邮箱验证码发送成功**
- **Given** 用户已提供有效的手机号/邮箱
- **When** 用户点击「获取验证码」
- **Then** 验证码发送到绑定手机/邮箱，按钮进入60s倒计时
- **关联FP：** FP-02.2.1
- **测试类型：** 集成测试
- **标准引用：** OWASP ASVS V2.3
- **⚠️ 人工必覆盖：** 依赖第三方网关，需验证送达率

**AC-012：验证码有效期校验**
- **Given** 验证码有效期为5分钟
- **When** 用户在有效期后提交验证码
- **Then** 系统返回「验证码已过期」（HTTP 400）
- **关联FP：** FP-02.3.1
- **测试类型：** 功能测试、时序测试
- **标准引用：** NIST SP 800-63B §5.1.4

**AC-013：验证码重发间隔限制**
- **Given** 用户已点击「获取验证码」
- **When** 用户在60s倒计时内再次点击
- **Then** 按钮不可点击，提示「请N秒后再试」
- **关联FP：** FP-02.3.2
- **测试类型：** 功能测试

### 5.3 EPIC-03：记住登录（4条AC）

**AC-014：记住登录状态生效**
- **Given** 用户勾选「记住我」并登录成功
- **When** 用户关闭浏览器重新访问
- **Then** 系统自动恢复登录态，无需重新输入密码
- **关联FP：** FP-03.1.1
- **测试类型：** 功能测试
- **⚠️ 人工必覆盖：** 需浏览器验证Cookie/Token持久化

**AC-015：未勾选记住我—会话级登录**
- **Given** 用户未勾选「记住我」并登录成功
- **When** 用户关闭浏览器重新访问
- **Then** 系统要求重新登录
- **关联FP：** FP-03.1.1
- **测试类型：** 功能测试

**AC-016：Token被篡改安全拦截**
- **Given** 用户持有一个有效Token
- **When** Token在客户端被篡改后发起请求
- **Then** 系统返回401 Unauthorized，要求重新登录
- **关联FP：** FP-03.1.2
- **测试类型：** 安全测试
- **标准引用：** OWASP ASVS V3.2.1

**AC-017：Token自动续期**
- **Given** 记住我模式Token有效期30天
- **When** Token即将过期且用户有活跃操作
- **Then** 系统静默刷新Token，维持登录态
- **关联FP：** FP-03.3.1
- **测试类型：** 功能测试、时序测试
- **标准引用：** OWASP ASVS V3.4

### 5.4 EPIC-04：密码找回（4条AC）

**AC-018：找回密码—身份验证**
- **Given** 用户点击「忘记密码」
- **When** 用户输入注册手机号/邮箱并获取验证码
- **Then** 验证码发送成功，进入密码重置步骤
- **关联FP：** FP-04.1.1
- **测试类型：** 功能测试
- **标准引用：** OWASP ASVS V2.5

**AC-019：验证码错误不允许重置**
- **Given** 用户处于密码重置流程
- **When** 用户输入错误的验证码
- **Then** 系统返回「验证码错误」（HTTP 400），不允许进入下一步
- **关联FP：** FP-04.1.1
- **测试类型：** 功能测试
- **标准引用：** OWASP ASVS V2.5

**AC-020：新密码强度校验通过**
- **Given** 用户通过身份验证进入密码重置
- **When** 用户输入符合复杂度要求的新密码并确认
- **Then** 系统返回「密码重置成功」（HTTP 200）
- **关联FP：** FP-04.2.1
- **测试类型：** 功能测试

**AC-021：重置后强制重新登录**
- **Given** 用户已成功重置密码
- **When** 重置流程结束
- **Then** 系统强制登出当前会话，跳转登录页
- **关联FP：** FP-04.3.1
- **测试类型：** 功能测试
- **标准引用：** OWASP ASVS V2.5

### 5.5 EPIC-05：登录安全防护（3条AC）

**AC-022：连续失败锁定账号**
- **Given** 同一账号连续登录失败10次
- **When** 该账号再次尝试登录
- **Then** 系统提示「账号已被临时锁定」（HTTP 429/403）
- **关联FP：** FP-05.1.1
- **测试类型：** 安全测试、压力测试
- **标准引用：** OWASP ASVS V2.2.5；NIST SP 800-63B §5.2.2

**AC-023：会话超时自动退出**
- **Given** 用户已登录但30分钟无操作
- **When** 用户发起请求
- **Then** 系统返回401 Unauthorized，要求重新登录
- **关联FP：** FP-05.2.1
- **测试类型：** 功能测试、时序测试
- **标准引用：** OWASP ASVS V3.1.1

**AC-024：异常登录告警**
- **Given** 用户登录IP与历史登录地差异超过阈值
- **When** 登录成功
- **Then** 系统向用户发送「新设备登录提醒」通知
- **关联FP：** FP-05.3.1
- **测试类型：** 集成测试
- **⚠️ 人工必覆盖：** 需真实网络环境验证
