## 五、安全需求

| 编号 | 安全类型 | 攻击方式 | 防护策略 |
|------|---------|---------|----------|
| SEC-01 | SQL注入 | 用户名输入' OR '1'='1 | 参数化查询,输入过滤,无SQL报错 |
| SEC-02 | XSS攻击 | 用户名输入<script>alert(1)</script> | 输出编码,脚本被转义不执行 |
| SEC-03 | 暴力破解 | 连续5次输入不同错误密码 | 第5次锁定30分钟 |
| SEC-04 | 验证码防刷 | 60秒内重复点击获取验证码 | 不发送请求,按钮灰态 |
| SEC-05 | 验证码安全 | 超时5分钟或已使用 | 提示过期/失效,不可用 |
| SEC-06 | 传输加密 | 抓包检查HTTP请求 | 全部请求使用HTTPS |
| SEC-07 | 存储加密 | 数据库检查密码字段 | bcrypt加盐哈希存储 |
| SEC-08 | Cookie安全 | DevTools检查Cookie | HttpOnly+Secure+SameSite |
| SEC-09 | 错误提示 | 不存在用户vs错误密码对比 | 统一提示"用户名或密码错误" |
| SEC-10 | 图形验证码 | 连续3次失败 | 第4次触发图形验证码 |

| 错误次数 | 1-4次 | 4次(不锁) | - | - | 5次(锁定) |

## 十一、执行策略

执行顺序:
1. 冒烟测试: 正常登录3种方式(US-001/014/024)
2. P0功能: 空值/错误/锁定/记住我/跳转/格式/一键注册
3. P0安全: SQL注入/XSS/暴力破解/验证码安全
4. 边界测试: 长度/格式/空格
5. P1功能: 忘记密码完整流程/倒计时/频率
6. P2扩展: 浏览器兼容/图形验证码

阻塞条件:
- 测试环境不可用: 全部阻塞
- 测试账号未创建: 功能测试阻塞
- 短信通道未开通: 验证码和忘记密码阻塞
- 存在SQL注入漏洞: 阻断上线
