## 7. 缺陷严重度定义

| 级别 | 定义 | 示例 |
|------|------|------|
| **P0** | 功能完全不可用 | 1+1=3、程序崩溃 |

## 8. 验收标准总结

### 必须通过 (Must Pass)

```
✓ 整数四则运算结果正确
✓ 小数运算精度在允许范围内（±0.0001）
✓ 除零时显示错误提示，不崩溃
✓ 运算优先级正确（先乘除后加减）
✓ 括号内运算优先
✓ 负数运算正确
✓ 零作为操作数时正确处理
```

### 应该通过 (Should Pass)

```
✓ 连续运算链正确
✓ 边界值不溢出或优雅报错
✓ 响应时间 < 100ms
```

### 可以通过 (Could Pass)

```
✓ 百分号计算
✓ 科学计数法显示
✓ 历史记录功能
```
