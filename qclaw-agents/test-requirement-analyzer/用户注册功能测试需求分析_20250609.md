# 用户注册功能测试需求分析

## 1. EPIC 定义

**EPIC：用户注册与账户创建**
- **愿景**：提供安全、便捷的用户注册流程，支持多种注册方式，确保账户安全与数据合规
- **业务目标**：降低注册门槛，提升转化率，防止恶意注册
- **成功指标**：注册成功率 ≥ 95%，注册完成时间 ≤ 30s，恶意注册拦截率 ≥ 99%

## 3. 功能性测试需求

### 3.1 邮箱注册（REG-001）

#### 用户故事
> 作为一个新用户，我想要使用邮箱注册账号，以便于记忆并接收通知

#### 验收标准

```
Given 新用户访问注册页面
When 输入有效邮箱格式（如 user@example.com）
And 输入符合规范的密码
And 点击注册按钮
Then 系统创建用户账号
And 发送激活邮件到该邮箱
And 跳转至激活页面提示"请查收邮件"
```

```
Given 用户输入已注册的邮箱
When 点击注册按钮
Then 系统提示"该邮箱已注册"
And 不创建重复账号
```

#### 测试数据设计（等价类划分）

| 输入项 | 有效等价类 | 无效等价类 |
|--------|-----------|-----------|
| 邮箱 | `test@domain.com` | 空值、无@、无域名、特殊字符、超长 |
| 密码 | `Abc12345`（8位大小写数字） | 少于8位、纯数字、纯字母、无大小写混合 |

### 3.2 手机号注册（REG-002）

#### 用户故事
> 作为一个新用户，我想要使用手机号注册账号，以便于快速登录

#### 验收标准

```
Given 新用户选择手机号注册
When 输入有效手机号
And 获取并输入正确验证码（5分钟内有效）
And 点击注册按钮
Then 系统创建用户账号
And 发送注册成功短信
```

#### 测试数据设计（边界值分析）

| 输入项 | 边界值测试 |
|--------|-----------|
| 手机号 | 11位、中国大陆号段（13x-199x）、首位1、第二位3/4/5/6/7/8/9 |
| 验证码 | 4位/6位数字、过期验证（超过5分钟）、错误验证（3次后锁定） |

### 3.3 密码强度校验（REG-003）

#### 验收标准

| 密码规则 | 符合示例 | 不符合示例 |
|----------|----------|------------|
| 长度 ≥ 8位 | `Abc12345` | `Abc1234` |
| 包含大写字母 | `Abc12345` | `abc12345` |
| 包含小写字母 | `Abc12345` | `ABC12345` |
| 包含数字 | `Abc12345` | `Abcdefgh` |
| 不包含空格 | 不允许 | 不允许 |

```
Given 用户输入弱密码（如"123456"）
When 尝试注册
Then 系统提示"密码强度不足，需包含大小写字母和数字"
And 不允许提交
```

### 3.4 验证码发送与校验（REG-004）

#### 验收标准

```
Given 用户请求发送验证码
When 1分钟内重复请求
Then 系统提示"操作过于频繁，请稍后再试"

Given 用户输入正确验证码
When 在5分钟有效期内提交
Then 验证通过

Given 用户输入错误验证码
When 连续错误3次
Then 验证码自动失效
And 提示"验证码已失效，请重新获取"
```

### 3.5 重复注册校验（REG-005）

#### 验收标准

```
Given 邮箱"test@qq.com"已被注册
When 其他用户尝试用相同邮箱注册
Then 系统提示"该邮箱已注册，请直接登录或找回密码"

Given 手机号"13800138000"已被注册
When 其他用户尝试用相同手机号注册
Then 系统提示"该手机号已注册，请直接登录或找回密码"
```

### 3.6 恶意注册防护（REG-006）

#### 验收标准

| 防护场景 | 测试要点 |
|----------|----------|
| IP频率限制 | 单IP 1分钟内最多请求3次验证码 |
| 设备频率限制 | 单设备1小时内最多注册3个账号 |
| 行为验证码 | 连续3次注册失败后触发图形验证码 |
| 黑名单校验 | 禁止使用黑名单邮箱/手机号前缀注册 |

## 4. 非功能性测试需求

### 4.1 性能要求

| 指标 | 目标值 | 测试方法 |
|------|--------|----------|
| 注册接口响应时间 | ≤ 500ms | 负载测试 |
| 验证码发送延迟 | ≤ 3s | 端到端测试 |
| 并发注册能力 | ≥ 100 TPS | 压力测试 |

### 4.2 安全要求

| 测试项 | 测试要点 |
|--------|----------|
| SQL注入 | `' OR 1=1 --` 等注入尝试 |
| XSS攻击 | `<script>alert(1)</script>` 等脚本注入 |
| 暴力破解 | 验证码穷举攻击 |
| 敏感数据 | 密码加密存储（MD5禁止），日志脱敏 |
| CSRF防护 | 注册请求携带CSRF Token |

### 4.3 兼容性要求

| 平台 | 测试版本 |
|------|----------|
| iOS | 12.0+ |
| Android | 6.0+ |
| Web | Chrome/Firefox/Safari/Edge 最新版 |

### 4.4 可用性要求

| 指标 | 目标值 |
|------|--------|
| 注册流程完成率 | ≥ 85% |
| 注册转化率 | ≥ 90%（验证码通过后） |
| 错误提示清晰度 | 100%场景有明确引导 |

## 6. 测试风险识别

| 风险项 | 风险等级 | 应对策略 |
|--------|----------|----------|
| 短信通道不稳定 | 高 | 接入多通道备选，异步重试 |
| 邮箱服务商收不到激活邮件 | 中 | 添加SPF/DKIM记录，测试主流邮箱 |
| 并发注册超限 | 中 | 前置限流+接口层限流双重保护 |
| 第三方OAuth回调失败 | 中 | 降级到本地注册方案 |
