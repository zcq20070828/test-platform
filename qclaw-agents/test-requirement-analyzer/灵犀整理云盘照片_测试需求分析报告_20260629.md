## 三、安全需求（10项P0）

| 编号 | 安全类型 | 威胁描述 | 防护策略 | 测试方法 |
|------|---------|---------|---------|---------|
| **SEC-01** | SQL注入防护 | image_ids、album_name 等参数注入 | 参数化查询 | 输入 `' OR '1'='1` 验证拦截 |
| **SEC-02** | XSS防护 | 用户输入自然语言包含脚本 | 输入过滤+输出编码 | 输入 `<script>alert(1)</script>` 验证 |
| **SEC-03** | 接口鉴权 | 未登录用户访问接口 | Token校验 | 不带Token调用接口验证被拒 |
| **SEC-04** | 越权访问 | 用户访问他人图片/相册 | 权限校验 | A用户尝试操作B用户的图片 |
| **SEC-05** | 数据泄露 | 搜索结果包含敏感图片 | 权限过滤 | 只返回用户有权限的图片 |
| **SEC-06** | 重复提交 | 用户重复点击确认 | 幂等锁校验 | 短时间内重复点击验证 |
| **SEC-07** | 接口限流 | 恶意刷接口 | 频率限制 | 短时间内大量请求验证限流 |
| **SEC-08** | 参数篡改 | 修改 image_ids 窃取图片 | 参数校验+权限校验 | 修改他人 image_ids 验证被拒 |
| **SEC-09** | LLM注入 | 用户输入影响LLM输出 | 提示词隔离 | 输入特殊构造的Query验证 |
| **SEC-10** | 敏感信息脱敏 | 日志/响应中泄露敏感信息 | 数据脱敏 | 检查日志和响应是否脱敏 |

## 四、边界条件（12项）

| 输入项 | 合法范围 | 边界测试（无效→有效→无效） |
|--------|---------|---------------------------|
| 搜索结果数量 | 0-2000张 | 0张(终止) → 1张(正常) → 2000张(截断) → 2001张(截断提示) |
| 聚类维度数 | 1-2个 | 0个(默认聚类) → 2个(正常) → 3个(建议MCLAW) |
| 图片ID有效性 | 必须在搜索结果中 | 不存在的ID(跳过) → 存在的ID(正常) |
| 相册名长度 | ≤50字符 | 0字符(不允许) → 50字符(正常) → 51字符(截断) |
| 对话ID有效期 | 存在Redis中 | 过期/不存在(提示过期) → 存在(正常) |
| 重试次数 | 最多3次 | 0次(正常) → 3次(最大) → 4次(不再重试) |
| LLM调用超时 | ≤30s | 31s(超时处理) → 29s(正常) |
| Redis锁TTL | 3s | 2s(锁过期) → 3s(正常) |
| SSE推送超时 | ≤60s | 61s(超时) → 59s(正常) |
| 图片批量大小 | 每批≤100个 | 101个(分批) → 100个(正常) |
| 用户Query长度 | ≤500字符 | 501字符(提示超长) → 500字符(正常) |
| 同时确认请求 | 仅1个 | 2个同时请求(第2个被拒) |
