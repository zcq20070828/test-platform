## 3. 业务背景
### 3.1 问题陈述
测试中台即将上线，用户登录功能存在潜在安全风险和体验问题，需全面验证功能正确性、安全性和兼容性，避免上线后出现账号泄露、登录失败等问题。
### 3.2 业务价值
1. 保障用户账号安全，降低安全事件风险
2. 提升用户登录体验，减少登录失败率
3. 符合等保2.0安全要求，通过安全审计
### 3.3 成功指标
1. 登录功能测试用例通过率100%
2. 安全测试无高危/中危漏洞
3. 登录响应时间P95≤3s，500并发错误率≤0.1%
4. 主流浏览器兼容无功能异常

## 4. 范围界定
### 4.1 包含范围
| 模块 | 说明 |
|------|------|
| 登录表单交互 | 输入框、按钮、记住密码复选框的展示与交互 |
| 输入项校验 | 用户名/密码的格式校验、空值校验 |
| 账号密码认证 | 正确/错误凭证的认证逻辑、错误提示 |
| 会话管理 | 登录后会话生成、续期、销毁逻辑 |
| 安全控制 | 账号锁定、验证码、会话超时、攻击防护 |
| 退出功能 | 主动退出、被动退出（超时）的逻辑 |
| 记住密码 | 密码本地存储、自动填充、过期逻辑 |
| 权限验证 | 不同角色登录后的权限校验 |
| 异常场景 | 网络异常、接口异常、浏览器兼容性问题 |
### 4.2 排除范围
| 功能 | 说明 |
|------|------|
| SSO单点登录 | 后续独立迭代实现，本次不测试 |
| 扫码登录 | 后续独立迭代实现，本次不测试 |
| 密码找回/重置 | 独立功能，单独测试 |
| 用户注册 | 独立功能，单独测试 |
### 4.3 假设条件
1. 后端登录接口已开发完成，可提供测试环境调用
2. 安全策略已明确：连续5次错误锁定15分钟、3次失败触发验证码、30分钟会话超时
3. 测试环境已部署，网络、服务、数据均可正常访问

## 5. 功能性需求与测试点
### 5.1 功能拆解与测试点矩阵
| 功能模块 | 测试场景 | 测试点 | 优先级 | 验收标准（Given-When-Then） |
|----------|----------|--------|--------|------------------------------|
| **登录表单展示** | 正向场景 | 1. 打开登录页，正确显示用户名/密码输入框、登录按钮、记住密码复选框<br>2. 密码输入框默认显示密文<br>3. 输入框placeholder提示正确 | P0 | Given 用户打开登录页面<br>When 页面加载完成<br>Then 所有表单元素正确显示，密码框默认密文 |
|  | 异常场景 | 1. CSS加载失败，页面样式错乱<br>2. JS加载失败，交互无响应 | P2 | Given 浏览器禁用CSS/JS<br>When 打开登录页面<br>Then 页面可正常提交表单（降级兼容） |
| **输入项校验** | 空值校验 | 1. 用户名为空，点击登录，提示“请输入用户名”<br>2. 密码为空，点击登录，提示“请输入密码”<br>3. 两者都为空，提示对应错误 | P0 | Given 用户名/密码为空<br>When 点击登录按钮<br>Then 弹出对应错误提示，不调用登录接口 |
|  | 格式校验 | 1. 用户名包含特殊字符（如`<>`），提示“用户名格式错误”<br>2. 密码长度小于8位，提示“密码长度至少8位”<br>3. 输入前后有空格，自动截取空格后校验 | P0 | Given 用户名/密码格式不符合要求<br>When 点击登录按钮<br>Then 弹出格式错误提示，不调用登录接口 |
| **账号密码认证** | 正向场景 | 1. 输入正确的用户名密码，点击登录，跳转至工作台<br>2. 登录后右上角显示正确用户名<br>3. 登录后Cookie存储正确 | P0 | Given 输入正确的用户名和密码<br>When 点击登录按钮<br>Then 登录成功，跳转至工作台，会话存储正确 |
|  | 反向场景 | 1. 用户名错误，提示“用户名或密码错误”<br>2. 密码错误，提示“用户名或密码错误”<br>3. 账号被禁用，提示“账号已禁用，请联系管理员”<br>4. 密码过期，提示“密码已过期，请修改密码”并跳转至修改页 | P0 | Given 输入错误的凭证或账号状态异常<br>When 点击登录按钮<br>Then 弹出对应错误提示，不跳转 |
| **会话管理** | 会话生成 | 1. 登录成功后生成会话ID，存储在Cookie中<br>2. 会话ID符合安全规范（长度、复杂度） | P0 | Given 登录成功<br>When 查看浏览器Cookie<br>Then 存在正确的会话ID，无明文敏感信息 |
|  | 会话续期 | 1. 用户操作中，会话自动续期<br>2. 续期后会话超时时间重置为30分钟 | P1 | Given 用户登录后，每隔20分钟操作一次<br>When 持续操作1小时<br>Then 会话未超时，可正常访问页面 |
|  | 会话销毁 | 1. 主动退出后，会话ID失效<br>2. 会话超时后，会话ID失效 | P0 | Given 用户主动退出/会话超时<br>When 尝试访问需要登录的页面<br>Then 跳转至登录页，提示“请重新登录” |
| **安全控制** | 账号锁定 | 1. 连续5次输入错误密码，第6次尝试时提示“账号已锁定，请15分钟后再试”<br>2. 锁定时间到期后，可正常登录 | P0 | Given 用户连续5次输入错误密码<br>When 第6次尝试登录<br>Then 账号被锁定，提示正确，锁定时间倒计时正确 |
|  | 验证码 | 1. 连续3次输入错误密码，第4次登录时显示验证码<br>2. 验证码输入错误，提示“验证码错误”<br>3. 验证码刷新功能正常 | P0 | Given 用户连续3次输入错误密码<br>When 第4次尝试登录<br>Then 显示验证码，输入错误验证码无法登录 |
|  | 攻击防护 | 1. 输入SQL注入语句（`' or 1=1 --`），提示“用户名或密码错误”，无注入成功<br>2. 输入XSS脚本（`<script>alert(1)</script>`），脚本不执行<br>3. 跨站请求伪造（CSRF）请求被拦截 | P0 | Given 输入常见攻击语句<br>When 提交登录请求<br>Then 攻击被拦截，无敏感信息泄露 |
|  | 敏感信息保护 | 1. 登录接口响应中不返回明文密码<br>2. 密码传输采用HTTPS加密<br>3. 本地存储的记住密码信息加密 | P0 | Given 抓取登录接口请求/响应<br>When 查看传输和存储的内容<br>Then 无明文密码，加密符合规范 |
| **退出功能** | 主动退出 | 1. 点击退出按钮，跳转至登录页<br>2. 退出后，会话ID失效，无法访问需要登录的页面 | P0 | Given 用户登录后点击退出按钮<br>When 尝试访问需要登录的页面<br>Then 跳转至登录页，无法访问 |
|  | 被动退出 | 1. 会话超时后，自动跳转至登录页<br>2. 多个设备登录，后登录的踢掉前登录的会话（根据产品策略） | P1 | Given 用户登录后30分钟无操作<br>When 尝试访问需要登录的页面<br>Then 跳转至登录页，提示“会话已超时” |
| **记住密码** | 正向场景 | 1. 勾选记住密码，登录成功后，关闭浏览器再打开，用户名密码自动填充<br>2. 记住密码有效期为7天，到期后自动清除 | P1 | Given 勾选记住密码并登录成功<br>When 关闭浏览器再打开<br>Then 用户名密码自动填充，可正常登录 |
|  | 反向场景 | 1. 清除浏览器缓存，记住密码失效<br>2. 勾选记住密码，登录失败后，不保存密码 | P2 | Given 清除浏览器缓存<br>When 打开登录页<br>Then 用户名密码未自动填充 |
| **权限验证** | 多角色登录 | 1. 管理员登录后，可看到系统配置菜单<br>2. 普通用户登录后，只能看到自己的测试任务<br>3. 只读用户登录后，无编辑权限 | P0 | Given 不同角色的用户登录<br>When 查看页面菜单和操作权限<br>Then 权限符合产品定义，无越权 |
| **异常场景** | 网络异常 | 1. 登录过程中断网，提示“网络异常，请稍后重试”<br>2. 网络恢复后，可重新登录 | P1 | Given 登录过程中断开网络<br>When 点击登录按钮<br>Then 提示网络异常，无页面崩溃 |
|  | 接口异常 | 1. 后端返回500错误，提示“服务异常，请稍后重试”<br>2. 接口超时（>5s），提示“请求超时，请稍后重试” | P1 | Given 后端返回500/超时<br>When 调用登录接口<br>Then 提示友好错误信息，无敏感信息泄露 |

### 5.2 非功能性需求指标
| 类型 | 指标 |
|------|------|
| **性能** | 1. 单用户登录响应时间：P50≤1s，P95≤3s，P99≤5s<br>2. 500并发用户登录：错误率≤0.1%，吞吐量≥100 TPS<br>3. 登录接口服务器资源使用率：CPU≤70%，内存≤80% |
| **兼容性** | 1. 桌面端：Windows Chrome 120+、Firefox 115+、Edge 120+；macOS Safari 16+<br>2. 移动端：iOS Safari 16+、Android Chrome 120+<br>3. 分辨率适配：1366*768、1920*1080、移动端375*667 |
| **可用性** | 1. 符合WCAG 2.1 AA级可访问性标准，支持键盘导航、屏幕阅读器识别<br>2. 错误提示清晰友好，用户可理解<br>3. 登录页加载时间≤2s |
| **安全** | 1. 符合OWASP Top 10 2023安全标准<br>2. 无高危/中危安全漏洞<br>3. 安全日志完整，包含登录IP、时间、结果 |

## 6. 优先级排序（MoSCoW）
| 级别 | 数量 | 具体项 | 理由 |
|------|------|--------|------|
| **Must（必须有）** | 10项 | 正确登录、输入校验、错误提示、账号锁定、验证码、会话超时、退出功能、攻击防护、密码加密、权限验证 | 核心功能，涉及安全和基本使用，上线前必须完成 |
| **Should（应该有）** | 6项 | 记住密码、日志审计、异常告警、兼容性覆盖、可访问性支持、多端登录控制 | 提升体验和安全性，建议上线前完成 |
| **Could（可以有）** | 4项 | 登录动画、异地登录提醒、登录历史展示、账号解锁自助服务 | 优化体验，可后续迭代实现 |
| **Won't（本次不做）** | 4项 | SSO登录、扫码登录、密码找回、用户注册 | 独立功能，后续迭代实现 |

## 8. 风险评估与缓解措施
| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 测试环境与生产环境配置不一致，导致测试结果不准确 | 高 | 测试前核对环境配置，尽量与生产环境保持一致；上线前在生产环境做 smoke 测试 |
| 安全测试触发防护策略，导致测试账号被锁定 | 中 | 使用专门的测试环境，提前和运维团队沟通，放开测试IP的限制；准备多个测试账号 |
| 需求变更，导致测试点需要更新 | 中 | 和产品团队保持每日沟通，及时更新需求文档和测试点；需求变更需走变更流程 |
| 兼容性问题难以复现 | 低 | 使用真实设备/浏览器版本测试，记录详细的复现步骤和环境信息；优先覆盖用户占比最高的浏览器 |
| 性能测试影响其他服务 | 低 | 压测前和运维团队沟通，选择低峰期执行；压测时监控服务器资源，避免压垮服务 |

## 9. 可测试性分析
| 测试点类型 | 可测试性 | 特殊要求 |
|------------|----------|----------|
| 功能测试、兼容性测试、权限验证 | 高 | 无特殊要求，可直接测试 |
| 安全测试（输入校验、攻击防护） | 高 | 需要安全测试工具，了解常见攻击手法 |
| 账号锁定、验证码测试 | 中 | 需要对接验证码识别服务，或开发提供测试接口跳过验证码；避免触发真实的安全策略 |
| 会话超时测试 | 中 | 需要开发配合，将超时时间临时改为1分钟，方便测试，测试完成后改回 |
| 多端登录测试 | 中 | 需要多个设备或浏览器同时登录，模拟多端场景 |
| 异地登录测试 | 低 | 需要模拟不同IP地址登录，可借助代理工具实现 |
