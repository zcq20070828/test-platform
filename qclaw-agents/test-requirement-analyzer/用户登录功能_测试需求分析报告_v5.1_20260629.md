# 用户登录功能 - 测试需求分析报告

## 一、需求模块分解

### REQ-001: 用户名密码登录 (P0)

用户故事(13个):
1. US-001 正常登录: test_user/Pass1234 -> 成功跳转首页,Token已生成
2. US-002 空用户名: 不输入用户名 -> 提示"请输入用户名",不发起请求
3. US-003 空密码: 不输入密码 -> 提示"请输入密码",不发起请求
4. US-004 用户名不存在: 输入不存在的用户名 -> 提示"用户名或密码错误"
5. US-005 密码错误: 输入错误密码 -> 提示"用户名或密码错误"
6. US-006 账号禁用: 禁用账号登录 -> 提示"账号已被禁用"
7. US-007 记住我: 勾选后登录 -> 30天免登录,Cookie HttpOnly+Secure
8. US-008 不勾选记住我: 不勾选 -> session级有效,关闭需重登
9. US-009 5次锁定: 连续5次错误 -> 第5次锁定30分钟
10. US-010 锁定期拒绝: 锁定期间登录 -> 提示剩余时间,拒绝
11. US-011 跳转: 登录成功URL->首页,原始URL恢复
12. US-012 SQL注入: ' OR '1'='1 -> 登录失败无报错
13. US-013 XSS: <script>alert(1)</script> -> 被过滤不执行

### REQ-002: 验证码登录 (P0)

用户故事(10个):
1. US-014 正常登录: 手机号+验证码 -> 成功跳转首页
2. US-015 手机号为空 -> 提示"请输入手机号"
3. US-016 手机号格式错误: 10位/12位/含字母 -> 提示格式错误
4. US-017 验证码为空 -> 提示"请输入验证码"
5. US-018 验证码错误: 输入000000 -> 提示"验证码错误"
6. US-019 验证码过期: 超过5分钟 -> 提示"验证码已过期"
7. US-020 倒计时: 点击获取,按钮60秒灰态不可重复点击
8. US-021 频率限制: 60秒内再次点击,不发送请求
9. US-022 一键注册: 未注册手机号自动注册并登录
10. US-023 重放: 已用验证码再次使用 -> 提示已失效

### REQ-003: 忘记密码 (P1)

用户故事(9个):
1. US-024 正常重置: 身份验证+新密码+确认 -> 重置成功跳转登录
2. US-025 手机号为空 -> 提示"请输入手机号"
3. US-026 未注册手机号 -> 提示"该手机号未注册"
4. US-027 新密码为空 -> 提示"请输入新密码"
5. US-028 确认不一致: Pass123 vs Pass456 -> 提示不一致
6. US-029 强度不足: 6位纯数字 -> 提示强度过低
7. US-030 新旧相同: 新密码=旧密码 -> 提示不能相同
8. US-031 旧密码失效: 重置后用旧密码 -> 登录失败
9. US-032 新密码可用: 重置后用新密码 -> 登录成功

### 总计: 32个用户故事

## 三、边界条件 (6项)

1. 用户名长度: 1(无效)/2(有效)/50(有效)/51(无效)
2. 密码长度: 5(无效)/6(有效)/32(有效)/33(无效)
3. 手机号位数: 10(无效)/11(有效)/12(无效)/含字母(无效)
4. 验证码位数: 5(无效)/6(有效)/7(无效)/含字母(无效)
5. 错误次数: 4次(不锁定)/5次(锁定)
6. 首尾空格: 自动去除后匹配
