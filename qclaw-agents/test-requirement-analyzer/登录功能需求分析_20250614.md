## 一、概述

### 1.1 需求描述
为测试中台前端工作流页面实现完整的用户登录功能，支持用户身份认证、会话管理、安全防护等核心能力，确保系统安全性和用户体验。

### 1.2 问题陈述
测试中台需要一套安全、可靠的用户认证机制，确保只有授权用户能够访问工作流页面和相关资源，同时防止恶意攻击和未授权访问。

### 1.3 业务价值
- **安全性保障**: 防止未授权访问，保护测试数据和系统资源
- **用户体验**: 提供流畅、友好的登录体验
- **合规要求**: 满足企业安全审计和访问控制要求
- **风险防控**: 降低数据泄露和恶意攻击风险

## 三、功能需求清单

### 3.1 登录表单验证（P0 - 必需）

#### 3.1.1 用户名输入验证
| 验证项 | 规则 | 错误提示 |
|--------|------|---------|
| 必填校验 | 不能为空 | "请输入用户名" |
| 格式校验 | 4-20位字母、数字、下划线 | "用户名格式不正确，请输入4-20位字母、数字或下划线" |
| 前后空格 | 自动去除前后空格 | - |
| 特殊字符 | 禁止特殊字符（SQL注入防护） | "用户名包含非法字符" |

#### 3.1.2 密码输入验证
| 验证项 | 规则 | 错误提示 |
|--------|------|---------|
| 必填校验 | 不能为空 | "请输入密码" |
| 长度校验 | 8-32位字符 | "密码长度应为8-32位" |
| 复杂度校验 | 至少包含大写字母、小写字母、数字、特殊字符中的3种 | "密码复杂度不足，需包含大写字母、小写字母、数字、特殊字符中的至少3种" |
| 显示切换 | 支持明文/密文切换 | - |

#### 3.1.3 表单提交验证
- **前端校验**: 提交前完成所有字段格式验证
- **实时校验**: 输入时实时反馈格式错误
- **防重复提交**: 登录过程中禁用提交按钮，显示加载状态
- **快捷操作**: 支持 Enter 键提交

### 3.2 认证流程（P0 - 必需）

#### 3.2.1 正常登录流程
```
用户输入凭据 → 前端验证 → 发送加密请求 → 后端验证 
→ 生成Token → 返回用户信息 → 建立会话 → 跳转首页
```

#### 3.2.2 登录失败处理
| 失败场景 | 错误提示 | 后续操作 |
|---------|---------|---------|
| 用户名不存在 | "用户名或密码错误"（不明确提示具体原因） | 允许重试 |
| 密码错误 | "用户名或密码错误" | 显示剩余尝试次数 |
| 账户锁定 | "账户已被锁定，请30分钟后再试或联系管理员" | 提供解锁途径 |
| 账户禁用 | "账户已被禁用，请联系管理员" | 提供联系信息 |
| Token过期 | 自动跳转登录页 | 保存原访问路径 |

#### 3.2.3 多因素认证（P1 - 应该有）
- 支持 企业微信/钉钉 二维码扫码登录
- 支持 手机验证码登录
- 支持 邮箱验证码登录

### 3.3 会话管理（P0 - 必需）

#### 3.3.1 Token管理
| 项目 | 规格 |
|------|------|
| Token类型 | JWT (JSON Web Token) |
| Token存储 | HttpOnly Cookie + LocalStorage备份 |
| Token有效期 | 2小时（可配置） |
| Refresh Token | 有效期7天，用于刷新Access Token |
| Token刷新 | 过期前10分钟自动刷新 |

#### 3.3.2 会话超时处理
| 场景 | 处理方式 |
|------|---------|
| 短时无操作（30分钟） | 提示用户，可继续操作延长会话 |
| 长时无操作（2小时） | 自动登出，跳转登录页 |
| Token过期 | 自动刷新或跳转登录页 |
| 多设备登录 | 默认允许，可选单设备登录模式 |

#### 3.3.3 登出流程
- 清除本地Token和用户信息
- 调用后端登出接口（使Token失效）
- 清除浏览器缓存中的敏感信息
- 跳转到登录页

### 3.4 安全防护（P0 - 必需）

#### 3.4.1 防暴力破解
| 防护措施 | 规则 |
|---------|------|
| 失败次数限制 | 同一账户5次失败后锁定账户30分钟 |
| IP限制 | 同一IP 1小时内失败20次触发验证码 |
| 图形验证码 | 连续失败3次后显示图形验证码 |
| 滑动验证 | 可疑行为触发滑动验证 |
| 登录日志 | 记录所有登录尝试（成功/失败） |

#### 3.4.2 XSS防护
| 防护措施 | 实现方式 |
|---------|---------|
| 输入过滤 | 对用户名进行HTML实体编码 |
| 输出编码 | 所有输出内容进行HTML编码 |
| CSP策略 | Content-Security-Policy 头部设置 |
| HttpOnly Cookie | Token存储在HttpOnly Cookie中 |
| 输入长度限制 | 前后端双重验证 |

#### 3.4.3 CSRF防护
| 防护措施 | 实现方式 |
|---------|---------|
| CSRF Token | 每次请求携带CSRF Token |
| SameSite Cookie | Cookie设置SameSite=Strict |
| Referer验证 | 验证请求来源 |
| 双重Cookie验证 | Header和Cookie中同时携带Token |

#### 3.4.4 其他安全措施
| 措施 | 说明 |
|------|------|
| HTTPS传输 | 强制HTTPS，禁止HTTP访问 |
| 密码加密传输 | 使用RSA公钥加密或HTTPS |
| 敏感信息脱敏 | 日志中不记录密码明文 |
| 安全响应头 | X-Frame-Options, X-XSS-Protection等 |
| 密码强度检测 | 前端实时检测并提示 |

### 3.5 用户界面需求（P0 - 必需）

#### 3.5.1 登录页面布局
- 居中显示登录表单
- 系统Logo和名称
- 用户名输入框（带图标）
- 密码输入框（带显示/隐藏切换）
- 记住我复选框（可选）
- 登录按钮
- 忘记密码链接
- 注册链接（如支持）
- 第三方登录入口（企业微信/钉钉）

#### 3.5.2 交互体验
| 项目 | 要求 |
|------|------|
| 响应时间 | 页面加载 < 2s，登录响应 < 1s |
| 加载状态 | 登录中显示loading动画和"登录中..."提示 |
| 错误提示 | 红色文字提示，3秒后自动消失 |
| 成功提示 | 绿色提示"登录成功"，1秒后跳转 |
| 焦点管理 | 首次加载自动聚焦用户名输入框 |
| 键盘导航 | 支持Tab键切换输入框 |

#### 3.5.3 多终端适配
- PC端：完整功能
- 平板端：响应式布局
- 移动端：简化界面，触摸优化

## 八、验收标准

### 8.1 功能验收标准

#### 8.1.1 登录表单验证
```
Given 用户在登录页面
When 用户输入格式错误的用户名（如"ab"、"abc@#$"）
Then 显示用户名格式错误提示，提交按钮禁用

Given 用户在登录页面
When 用户输入少于8位的密码
Then 显示密码长度错误提示，提交按钮禁用

Given 用户在登录页面
When 用户输入符合格式的用户名和密码
Then 提交按钮可用，点击后发送登录请求
```

#### 8.1.2 正常登录流程
```
Given 用户输入正确的用户名和密码
When 用户点击登录按钮
Then 登录成功，跳转到工作流首页，显示用户信息

Given 用户选择"记住我"
When 登录成功后关闭浏览器，再次打开
Then 自动登录，无需重新输入凭据
```

#### 8.1.3 异常登录流程
```
Given 用户输入错误的密码
When 用户点击登录按钮连续5次
Then 账户被锁定30分钟，显示锁定提示

Given 用户账户已被禁用
When 用户尝试登录
Then 显示"账户已被禁用"提示

Given 用户使用SQL注入字符串作为用户名（如"admin' OR '1'='1"）
When 用户点击登录按钮
Then 登录失败，显示"用户名或密码错误"，不执行SQL语句
```

#### 8.1.4 会话管理
```
Given 用户已登录
When 用户在2小时内无操作
Then 自动登出，跳转到登录页

Given 用户已登录
When Token即将过期（剩余10分钟）
Then 自动刷新Token，用户无感知

Given 用户点击登出按钮
When 登出成功
Then 清除本地Token，跳转到登录页
```

#### 8.1.5 安全防护
```
Given 用户连续输入错误密码3次
When 第4次尝试登录
Then 显示图形验证码

Given 用户输入包含JavaScript脚本的用户名（如"<script>alert('XSS')</script>"）
When 用户点击登录按钮
Then 脚本不执行，显示普通文本或提示非法字符

Given 攻击者尝试CSRF攻击
When 发送伪造的登录请求
Then 请求被拒绝，返回403 Forbidden
```

### 8.2 非功能验收标准

#### 8.2.1 性能验收
```
Given 登录页面在正常网络环境下
When 用户访问登录页面
Then 首屏加载时间 < 2秒

Given 100个用户同时尝试登录
When 系统处理并发登录请求
Then 所有请求在3秒内完成，无失败
```

#### 8.2.2 兼容性验收
```
Given 用户使用Chrome/Firefox/Edge浏览器
When 用户访问登录页面并登录
Then 页面显示正常，功能可用

Given 用户使用移动设备访问
When 用户访问登录页面
Then 页面自适应显示，触摸操作流畅
```

#### 8.2.3 安全验收
```
Given 安全测试人员使用OWASP ZAP扫描登录页面
When 扫描完成
Then 无高危或中危安全漏洞

Given 安全测试人员尝试SQL注入/XSS/CSRF攻击
When 攻击执行
Then 所有攻击被成功拦截，系统安全
```

- 第三方登录（企业微信、钉钉）

- 用户注册功能
