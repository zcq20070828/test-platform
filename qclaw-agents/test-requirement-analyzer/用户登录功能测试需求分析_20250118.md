## 5. 验收标准（AC）

### AC-001：账号密码登录成功
```
Given 用户在登录页面
  And 用户已注册账号 "testuser"
When 用户输入账号 "testuser"
  And 用户输入正确密码 "Test@123"
  And 用户点击"登录"按钮
Then 系统验证账号密码正确
  And 用户跳转至首页
  And 显示用户昵称
  And 记录登录日志
```

### AC-002：密码错误登录失败
```
Given 用户在登录页面
  And 用户已注册账号 "testuser"
When 用户输入账号 "testuser"
  And 用户输入错误密码 "wrongpass"
  And 用户点击"登录"按钮
Then 系统验证密码错误
  And 提示"账号或密码错误"
  And 登录失败次数+1
  And 用户仍停留在登录页面
```

### AC-003：账户锁定
```
Given 用户在登录页面
  And 用户已注册账号 "testuser"
  And 用户已连续登录失败4次
When 用户第5次输入错误密码
  And 用户点击"登录"按钮
Then 系统锁定账户15分钟
  And 提示"账户已锁定，请15分钟后重试"
  And 发送安全提醒通知
```

### AC-004：验证码登录成功
```
Given 用户在登录页面
  And 用户手机号 "13800138000" 已注册
When 用户输入手机号 "13800138000"
  And 用户点击"获取验证码"
  And 用户输入正确验证码 "123456"
  And 用户点击"登录"按钮
Then 系统验证验证码正确
  And 用户跳转至首页
  And 显示用户昵称
```

### AC-005：验证码发送频率限制
```
Given 用户在登录页面
  And 用户刚发送过验证码（间隔<60秒）
When 用户再次点击"获取验证码"
Then 按钮置灰不可点击
  And 提示"验证码已发送，请60秒后重试"
  And 显示倒计时
```

### AC-006：登录态过期处理
```
Given 用户已登录系统
  And 用户登录态已过期（超过30分钟未操作）
When 用户执行任意操作
Then 系统提示"登录已过期，请重新登录"
  And 自动跳转至登录页面
  And 保留当前页面路径（登录后返回）
```

### AC-007：SQL注入防护
```
Given 用户在登录页面
When 用户输入账号 "admin' OR '1'='1"
  And 用户输入密码 "anything"
  And 用户点击"登录"按钮
Then 系统过滤SQL注入语句
  And 提示"账号或密码错误"
  And 记录安全日志
```

### AC-008：并发登录控制
```
Given 用户A使用账号 "testuser" 在设备1登录
When 用户A使用同一账号在设备2登录
Then 系统根据配置执行以下之一：
  （方案A）设备1被踢出，提示"账号在其他设备登录"
  （方案B）设备2登录失败，提示"账号已在其他设备登录"
  And 记录多设备登录日志
```

## 6. 边界条件分析

### 6.1 输入边界

| 字段 | 有效边界 | 无效边界 | 测试策略 |
|------|----------|----------|----------|
| 账号长度 | 4-20字符 | <4 或 >20 | 边界值测试：3,4,5,19,20,21 |
| 密码长度 | 8-20字符 | <8 或 >20 | 边界值测试：7,8,9,19,20,21 |
| 验证码长度 | 6位 | ≠6 | 边界值测试：5,6,7 |
| 手机号 | 11位数字 | 非数字/位数错误 | 正则匹配测试 |
| 密码复杂度 | 包含大小写+数字+特殊字符 | 纯数字/纯字母 | 复杂度规则测试 |

### 6.2 业务边界

| 场景 | 边界值 | 测试要点 |
|------|--------|----------|
| 登录失败次数锁定 | 5次 | 4次失败后仍可登录，5次锁定 |
| 账户锁定时长 | 15分钟 | 14分59秒仍锁定，15分后解锁 |
| 验证码有效期 | 5分钟 | 4分59秒有效，5分01秒过期 |
| 验证码发送间隔 | 60秒 | 59秒不可发送，60秒可发送 |
| 每日验证码上限 | 5条 | 第5条成功，第6条失败 |
| Token有效期 | 30分钟 | 29分59秒有效，30分01秒过期 |
| 记住密码天数 | 7天 | 7天内免登录，第8天需重新登录 |

### 6.3 性能边界

| 场景 | 目标值 | 测试策略 |
|------|--------|----------|
| 登录响应时间 | < 1秒 | 压测验证 |
| 验证码发送耗时 | < 3秒 | 计时测试 |
| 并发登录用户 | 100用户 | 压测验证 |
| 登录成功率 | ≥ 99% | 压测统计 |
