## v2.0 改进内容

### 1. 新增28项安全测试用例（含详细Payload）

| 类别 | 测试项数 | 说明 |
|------|---------|------|
| SQL注入防护 | 7项 | 认证绕过、注释符绕过、UNION注入、布尔盲注、时间盲注、堆叠查询、密码字段注入 |
| XSS防护 | 6项 | 存储型脚本注入、img事件注入、SVG事件注入、onclick注入、javascript伪协议、DOM型注入、编码绕过 |

| 敏感信息泄露 | 3项 | 响应体明文密码检查、错误信息泄露检查、日志脱敏检查 |

### 2. 新增CAPTCHA验证码测试（4项P0）
- 连续失败5次后强制显示验证码
- 验证码错误后刷新
- 验证码过期后重新获取
- 验证码不区分大小写

### 3. 新增Session Fixation防护测试（P0）
- 验证登录前后Session ID是否变化

### 4. 新增错误提示枚举防护测试（3项P1）
- 用户名不存在vs密码错误提示统一
- 账号状态差异化测试
- 响应时间差异测试

### 5. 测试用例改进
- 所有测试用例包含≥3步详细操作步骤
- 预期结果为确定性描述，无模糊表述
- 明确前置条件（precondition）

### 6. 优先级调整
- **CSRF防护**: P1 → P0
- **会话超时**: P1 → P0
- **CAPTCHA验证码**: P1 → P0
- **Session Fixation**: P1 → P0
