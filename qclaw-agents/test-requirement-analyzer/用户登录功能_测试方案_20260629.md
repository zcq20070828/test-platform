```

   └─ SQL注入 → XSS → 暴力破解 → 验证码重放 → 图形验证码

Phase 4: 边界+异常测试（P0+P1）
   └─ 长度边界 → 格式边界 → 特殊字符 → 超时 → 状态异常

Phase 5: HCI+兼容性（P1+P2 可选）
   └─ 键盘操作 → 焦点 → Loading → 浏览器兼容
```
