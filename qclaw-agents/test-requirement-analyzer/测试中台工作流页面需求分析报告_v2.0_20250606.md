测试中台工作流模块是测试团队的核心作业平台，提供测试流程的编排、执行、监控全生命周期管理能力。通过可视化工作流设计器，测试人员可以快速构建自动化测试流程，降低测试技术门槛，提升测试效率。

## 三、功能需求详细分析

### 3.1 WF-EPIC-01：工作流列表展示功能

#### WF-REQ-01 工作流多维度检索

**功能描述**：
支持按工作流名称、创建人、标签、创建时间范围、执行状态等多维度组合检索。

**用户故事**：
```
As a 测试工程师
I want to 通过多个维度快速筛选工作流
So that 我能在大量工作流中快速定位目标项
```

**【数据来源】** 基于通用搜索模式推断，需确认是否支持全文检索。

**验收标准**：
| 编号 | Given（前置条件） | When（操作） | Then（预期结果） | 验证方法 |
|------|------------------|--------------|------------------|---------|
| AC-01-01 | 工作流列表已加载 | 输入名称关键字"接口测试" | 显示名称包含该关键字的所有工作流 | 接口测试+UI验证 |
| AC-01-02 | 检索面板展开 | 选择时间范围"近7天" | 仅显示该时间段创建的工作流 | 接口参数验证 |
| AC-01-03 | 多条件同时设置 | 名称="冒烟" + 状态="草稿" | 返回同时满足两个条件的工作流 | 组合查询逻辑验证 |
| AC-01-04 | 无匹配结果 | 检索条件无对应工作流 | 显示"未找到符合条件的工作流"提示 | 边界测试 |
| AC-01-05 | 清空筛选条件 | 点击"重置"按钮 | 恢复默认列表展示 | 交互测试 |

**测试要点**：
- [ ] 精确匹配与模糊匹配切换逻辑
- [ ] 时间范围选择器边界值（最早/最晚可选时间）
- [ ] 多条件组合查询逻辑（AND/OR需明确）
- [ ] 分页场景下筛选行为（总数是否重新计算）
- [ ] 检索历史保存机制（前端缓存还是后端存储）
- [ ] 特殊字符处理（SQL注入防护）

**【改进点】** 新增：查询性能指标、数据库索引要求。

**【技术依赖】** 需要数据库索引支持：`idx_name`, `idx_creator`, `idx_create_time`, `idx_status`。

#### WF-REQ-02 工作流状态展示

**功能描述**：
清晰展示工作流的生命周期状态，包括草稿、已发布、执行中、已完成、已禁用等状态及对应统计。

**【状态机定义】** 需确认完整的状态流转规则：

```
草稿 → 已发布（发布操作）
已发布 → 执行中（触发执行）
执行中 → 已完成/执行失败（执行结束）
已完成 → 已发布（可再次执行）
已发布 → 已禁用（禁用操作）
已禁用 → 已发布（启用操作）
```

**验收标准**：
| 编号 | Given | When | Then | 验证方法 |
|------|-------|------|------|---------|
| AC-02-01 | 列表页面 | 查看工作流列表 | 每行显示状态标签，颜色区分 | UI规范对比 |
| AC-02-02 | 执行中的工作流 | 查看详情 | 显示实时进度百分比 | WebSocket消息验证 |
| AC-02-03 | 执行失败的工作流 | 查看详情 | 高亮显示失败节点 | 日志解析验证 |
| AC-02-04 | 列表顶部 | 查看统计数据 | 显示各状态工作流数量 | 统计接口验证 |

**【数据支撑】** 状态颜色对照表：

| 状态 | 颜色 | 色值 |
|------|------|------|
| 草稿 | 灰色 | #999999 |
| 已发布 | 绿色 | #52C41A |
| 执行中 | 蓝色 | #1890FF |
| 已完成 | 深绿色 | #389E0D |
| 执行失败 | 红色 | #F5222D |
| 已禁用 | 深灰色 | #595959 |

**测试要点**：
- [ ] 状态流转正确性（非法状态转换拦截）
- [ ] 执行进度实时更新频率（建议1秒）
- [ ] 状态变更时间戳显示格式
- [ ] 并发执行状态展示（同一工作流多次执行）
- [ ] 状态统计实时性（延迟时间要求）

**【改进点】** 新增：状态机图、实时推送延迟要求。

| AC-03-03 | 确认删除 | 点击"确认删除" | 删除成功提示，列表刷新 | 接口+数据库验证 |

**测试要点**：
- [ ] 全选/取消全选交互
- [ ] 跨页批量选择（是否支持）
- [ ] 批量操作权限校验（批量操作需要对应权限）

- [ ] 批量操作失败处理（部分成功部分失败的场景）
- [ ] 批量操作事务性（全部成功或全部回滚）

### 3.2 WF-EPIC-02：工作流创建/编辑功能

#### WF-REQ-04 可视化流程编排

**功能描述**：
提供拖拽式可视化工作流设计器，支持顺序、分支、并行、循环等流程控制。

**用户故事**：
```
As a 测试工程师
I want to 通过拖拽组件编排测试流程
So that 无需编写代码即可完成复杂测试流程设计
```

**【技术栈】** 需确认：React Flow / AntV X6 / D3.js / 自研？

**验收标准**：
| 编号 | Given | When | Then | 验证方法 |
|------|-------|------|------|---------|
| AC-04-01 | 设计器页面 | 从组件栏拖拽"开始节点"到画布 | 节点被放置到目标位置 | E2E测试 |
| AC-04-02 | 画布有多个节点 | 拖拽连接线连接节点 | 显示带箭头的连线 | 视觉验证 |
| AC-04-03 | 创建分支节点 | 配置分支条件"A>0" | 分支节点显示条件标签 | 配置持久化验证 |
| AC-04-04 | 画布有完整流程 | 点击"保存" | 流程保存成功，提示"已保存为草稿" | 接口验证 |
| AC-04-05 | 流程节点数量>20 | 查看流程图 | 自动缩放适配视图 | 性能测试 |

**测试要点**：
- [ ] 节点拖拽放置精度（网格对齐/自由放置）
- [ ] 连线绘制与删除（连线弯曲策略）
- [ ] 节点对齐辅助线
- [ ] 画布缩放/平移操作（缩放范围：25%~400%）
- [ ] 流程图导出为图片（格式：PNG/SVG，分辨率要求）
- [ ] 撤销/重做功能（历史记录栈大小）
- [ ] 流程校验规则（必须有开始和结束节点）
- [ ] 节点数量上限（建议：200个节点）
- [ ] 流程复杂度限制（嵌套层级：最多5层）

**【改进点】** 新增：性能指标、复杂度限制。

**【性能指标】**
- 节点渲染：单节点< 50ms
- 流程加载：100节点< 1s
- 流程保存：完整流程< 2s

#### WF-REQ-05 节点配置管理

**功能描述**：
每个节点支持配置执行脚本、环境参数、超时时间、重试策略等属性。

**【节点类型】** 需明确支持的节点类型：

| 节点类型 | 用途 | 必填配置项 |
|---------|------|-----------|
| 开始节点 | 流程入口 | 无 |
| 结束节点 | 流程出口 | 无 |
| 脚本执行节点 | 执行测试脚本 | 脚本内容、执行环境 |
| HTTP请求节点 | 调用外部接口 | URL、Method、Headers、Body |
| 条件判断节点 | 分支逻辑 | 条件表达式 |
| 循环节点 | 重复执行 | 循环次数/遍历变量 |
| 审批节点 | 人工审批 | 审批人、超时时间 |
| 延时节点 | 等待执行 | 延时时长 |

**验收标准**：
| 编号 | Given | When | Then | 验证方法 |
|------|-------|------|------|---------|
| AC-05-01 | 选中任意节点 | 双击或点击配置按钮 | 弹出节点配置面板 | 交互测试 |
| AC-05-02 | 配置面板 | 填写超时时间=30秒 | 配置项显示"30s" | 数据绑定验证 |
| AC-05-03 | 配置必填项缺失 | 点击"确定"保存 | 提示"请填写必填项：XXX" | 表单校验测试 |
| AC-05-04 | 脚本配置 | 编写测试脚本并验证语法 | 显示语法检查结果 | 语法分析器集成 |
| AC-05-05 | 环境参数 | 添加键值对 {env:"test"} | 参数以表格形式展示 | 数据持久化验证 |

**测试要点**：
- [ ] 所有节点类型的配置项完整性
- [ ] 配置项类型校验（数字/字符串/JSON/正则）
- [ ] 敏感信息加密存储（密码字段展示为 ****）
- [ ] 配置项继承与覆盖（全局配置 vs 节点配置）
- [ ] 环境变量替换语法（${var} 或 {{var}}）
- [ ] 配置项校验规则（长度限制、格式限制）
- [ ] 脚本编辑器功能（语法高亮、自动补全、错误提示）

**【改进点】** 新增：节点类型清单、配置项校验规则。

- 同一工作流并发执行上限：10个实例

**验收标准**：
| 编号 | Given | When | Then | 验证方法 |
|------|-------|------|------|---------|
