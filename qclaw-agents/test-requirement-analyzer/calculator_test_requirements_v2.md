## 二、EPIC 需求分解

```
📱 EPIC: 计算器四则运算功能
│
├── R1: 基础四则运算 ⭐Must
│   ├── US1.1: 用户能进行两个数相加
│   ├── US1.2: 用户能进行两个数相减（结果可为负）
│   ├── US1.3: 用户能进行两个数相乘
│   └── US1.4: 用户能进行两个数相除
│
├── R2: 数值输入处理 ⭐Must
│   ├── US2.1: 用户能输入整数（正数、负数、零）
│   ├── US2.2: 用户能输入小数
│   └── US2.3: 用户能切换当前数的正负符号
│
├── R3: 表达式解析与优先级 ⭐Must
│   ├── US3.1: 系统按数学优先级解析表达式（乘除优先于加减）
│   └── US3.2: 用户能使用括号改变运算优先级，支持嵌套
│
├── R4: 辅助操作功能 ⭐Should
│   ├── US4.1: 用户能清除当前输入（CE）
│   ├── US4.2: 用户能清除所有内容（C）
│   └── US4.3: 用户能删除最后一个输入字符（退格）
│
└── R5: 错误与边界处理 ⭐Must
    ├── US5.1: 系统检测并提示除数为零的错误
    └── US5.2: 系统处理数值溢出场景
```

## 三、非功能性需求

| 类型 | 需求 | 说明 |
|------|------|------|
| **性能** | 响应时间 < 100ms | 任何计算操作的反馈时间 |
| **精度** | 有效数字 ≤ 15位 | 计算结果最多显示15位有效数字 |
| **范围** | 整数 ≤ 12位 | 单个整数输入不超过12位 |
| **范围** | 小数 ≤ 15位 | 单个小数输入不超过15位 |
| **嵌套** | 括号深度 ≤ 10层 | 最大支持10层括号嵌套 |
| **可用性** | 错误提示明确 | 除零/溢出等错误需友好提示 |

## 四、输入约束（需与需求提出方确认）

| 约束项 | 原文档值 | 建议确认 |

| 括号嵌套 | 10层 | 是否需要语法校验？ |
| 显示精度 | 15位有效数字 | 循环小数如何处理？ |

## 六、验收标准 (Given-When-Then)

### US1.1 加法运算
```
Given 用户在计算器输入 "123 + 456"
When  用户按下 "="
Then  屏幕显示 "579"

Given 用户输入 "0.1 + 0.2"
When  用户按下 "="
Then  屏幕显示 "0.3"（允许最后一位舍入）

Given 用户输入 "999999999999 + 1"
When  用户按下 "="
Then  系统检测溢出，显示 "溢出" 或 切换科学计数法
```

### US1.2 减法运算
```
Given 用户输入 "5 - 8"
When  用户按下 "="
Then  屏幕显示 "-3"

Given 用户输入 "100 - 50 - 30"
When  用户按下 "="
Then  屏幕显示 "20"（左结合）
```

### US1.3 乘法运算
```
Given 用户输入 "3 × 4"
When  用户按下 "="
Then  屏幕显示 "12"

Given 用户输入 "0.1 × 10"
When  用户按下 "="
Then  屏幕显示 "1"（精确结果）

Given 用户输入 "999999 × 999999"
When  用户按下 "="
Then  显示溢出或科学计数法
```

### US1.4 除法运算
```
Given 用户输入 "10 ÷ 3"
When  用户按下 "="
Then  屏幕显示 "3.3333333333333"（按精度截断）

Given 用户输入 "6 ÷ 2"
When  用户按下 "="
Then  屏幕显示 "3"

Given 用户输入 "5 ÷ 0"
When  用户按下 "="
Then  屏幕显示 "错误: 除数不能为零"
And   系统恢复待机状态，可重新输入
```

### US2.1 整数输入
```
Given 用户输入 "123456789012"
When  用户继续输入 "3"
Then  系统拒绝第13位输入，或显示溢出提示

Given 用户输入 "-999999999999"
When  用户按下 "="
Then  系统接受并处理此输入
```

### US2.2 小数输入
```
Given 用户输入 "12.34"
When  用户再输入 "."
Then  系统拒绝第二个小数点

Given 用户输入 "3.141592653589793"
When  用户继续输入 "2"
Then  系统拒绝第16位小数
```

### US2.3 正负切换
```
Given 屏幕显示 "123"
When  用户按下 "+/-"
Then  屏幕显示 "-123"

Given 屏幕显示 "-123"
When  用户按下 "+/-"
Then  屏幕显示 "123"

Given 屏幕显示 "0"
When  用户按下 "+/-"
Then  屏幕显示 "0"（零的正负无意义）
```

### US3.1 运算优先级
```
Given 用户输入 "2 + 3 × 4"
When  用户按下 "="
Then  屏幕显示 "14"（先乘后加）

Given 用户输入 "10 - 3 + 2"
When  用户按下 "="
Then  屏幕显示 "9"（左结合）

Given 用户输入 "20 ÷ 4 × 2"
When  用户按下 "="
Then  屏幕显示 "10"（左结合）
```

### US3.2 括号嵌套
```
Given 用户输入 "(2 + 3) × 4"
When  用户按下 "="
Then  屏幕显示 "20"（括号优先）

Given 用户输入 "((1 + 2) × 3) + 4"
When  用户按下 "="
Then  屏幕显示 "13"

Given 用户输入 "(((1 + 2)))"
When  用户按下 "="
Then  屏幕显示 "3"

Given 用户输入 "((1 + 2)"
When  用户按下 "="
Then  屏幕显示 "错误: 括号未闭合"

Given 用户输入 ")1 + 2("
When  用户按下 "="
Then  屏幕显示 "错误: 括号语法错误"

Given 用户输入 10层嵌套
When  用户按下 "="
Then  系统正确计算

Given 用户输入 11层嵌套
When  用户按下 "="
Then  系统提示嵌套层数超限
```

### US4.1 CE清除
```
Given 用户输入 "12345"
When  用户按下 "CE"
Then  屏幕显示 "0"，用户可重新输入当前数字
```

### US4.2 C清除
```
Given 用户输入 "123 + 456"
When  用户按下 "C"
Then  屏幕显示 "0"，所有状态重置
```

### US4.3 退格操作
```
Given 用户输入 "12345"
When  用户按下 "←" 3次
Then  屏幕显示 "12"

Given 用户输入 "0"
When  用户按下 "←"
Then  屏幕保持 "0"（已达最小值）
```

### US5.2 溢出处理
```
Given 用户输入 "-999999999999 - 1"
When  用户按下 "="
Then  屏幕显示 "溢出"
```
