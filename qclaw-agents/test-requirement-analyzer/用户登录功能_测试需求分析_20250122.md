## 1. 需求概述

### 1.1 需求描述
用户通过用户名/手机号/邮箱 + 密码的方式登录系统，验证身份后获取访问权限。

### 1.2 解决问题
- **身份验证** - 确认用户是谁
- **会话管理** - 维持登录状态
- **安全访问控制** - 防止未授权访问

### 1.3 需求提出者
产品团队 / 业务方

## 3. 详细需求规格

### 3.1 功能性测试需求

#### 3.1.1 核心功能点

| 功能点 | 测试要点 | 优先级 | 测试方法 |
|--------|----------|--------|----------|
| **账号密码登录** | 正确/错误凭证、空输入、特殊字符 | Must | 等价类划分、边界值分析 |
| **多方式登录** | 手机号/邮箱/用户名切换 | Should | 场景分析 |
| **记住登录状态** | 7天/30天免登录 | Should | 状态转换测试 |
| **忘记密码** | 验证码发送、密码重置流程 | Must | 端到端流程测试 |
| **登录失败处理** | 错误提示、次数限制、账号锁定 | Must | 异常场景测试 |
| **多设备登录** | 单点登录/多端同时在线策略 | Could | 并发测试 |
| **第三方登录** | 微信/QQ/OAuth集成 | Won't | - |

#### 3.1.2 测试场景详解

**场景1：成功登录**
```
Given 用户输入正确的用户名和密码
When 点击登录按钮
Then 登录成功，跳转到首页
And 生成有效会话token（有效期30分钟）
And 记录登录日志（IP、时间、设备信息）
And 前端存储token到Cookie/LocalStorage
```

**测试数据准备**：
- 有效用户名：testuser001
- 有效密码：Test@123456
- 预期响应：HTTP 200, token格式验证

---

**场景2：密码错误**
```
Given 用户输入正确的用户名和错误的密码
When 点击登录按钮
Then 显示错误提示"用户名或密码错误"
And 不生成会话token
And 记录失败日志
And 失败次数+1
```

**边界条件**：
- 失败次数 = 0 → 允许登录
- 失败次数 = 4 → 提示"还有1次机会"
- 失败次数 = 5 → 账号锁定30分钟

---

**场景3：账号锁定**
```
Given 用户连续5次输入错误密码
When 第6次尝试登录
Then 显示提示"账号已锁定，请30分钟后重试"
And 发送安全告警通知到用户邮箱/手机
And 记录安全事件日志
```

**解锁方式**：
- 等待30分钟自动解锁
- 通过忘记密码流程重置
- 联系客服人工解锁

---

**场景4：会话超时**
```
Given 用户已登录且会话空闲超过30分钟
When 用户尝试访问需要认证的页面
Then 重定向到登录页
And 显示提示"会话已过期，请重新登录"
```

---

**场景5：记住登录状态**
```
Given 用户勾选"记住登录状态"并成功登录
When 关闭浏览器后重新打开
Then 用户仍处于登录状态
And token有效期延长至7天
```

### 3.2 非功能性测试需求

#### 3.2.1 性能要求

| 指标 | 目标值 | 测试工具 | 通过标准 |
|------|--------|----------|----------|
| **登录接口响应时间** | < 500ms (平均) | JMeter | 95%请求达标 |
| **登录接口TPS** | 1000 TPS | JMeter | 错误率 < 0.1% |
| **页面加载时间** | < 2s | Lighthouse | 首屏渲染 < 1s |
| **数据库查询时间** | < 50ms | Slow Query Log | 无慢查询 |

**性能测试场景**：
1. **基准测试**：单用户登录，验证响应时间
2. **负载测试**：逐步增加并发用户至1000 TPS
3. **压力测试**：超过最大负载，观察系统崩溃点
4. **稳定性测试**：1000 TPS持续运行24小时

---

#### 3.2.2 安全要求

**OWASP Top 10 防护**：

| 威胁类型 | 测试要点 | 测试工具 | 通过标准 |
|----------|----------|----------|----------|
| **SQL注入** | 输入特殊字符 `' OR 1=1 --` | SQLMap | 无注入点 |
| **XSS跨站脚本** | 输入 `<script>alert('XSS')</script>` | OWASP ZAP | 输出编码 |
| **暴力破解** | 连续1000次错误登录 | Burp Suite | 触发锁定/验证码 |
| **敏感数据泄露** | 检查响应中是否包含密码 | 手动审查 | 密码加密/脱敏 |
| **会话固定** | 登录前后Session ID是否变化 | Burp Suite | Session刷新 |
| **CSRF攻击** | 检查是否存在CSRF Token | OWASP ZAP | Token验证 |

**密码策略**：
- 最小长度：8位
- 复杂度要求：大写+小写+数字+特殊字符
- 加密方式：BCrypt（盐值+迭代）
- 传输加密：HTTPS (TLS 1.2+)

**会话安全**：
- Session ID长度：≥ 128位随机值
- 会话超时：30分钟无操作
- Cookie属性：HttpOnly、Secure、SameSite=Strict

## 7. 测试策略

### 7.1 测试类型与工具

| 测试类型 | 测试工具 | 覆盖重点 | 执行时机 |
|----------|----------|----------|----------|
| **功能测试** | Postman、Selenium | 所有功能点、边界值、异常场景 | 迭代中期 |
| **接口测试** | Postman、JUnit | API正确性、错误码规范 | 开发联调 |
| **性能测试** | JMeter、Gatling | 并发、响应时间、资源占用 | 功能稳定后 |
| **安全测试** | OWASP ZAP、SQLMap | 注入攻击、XSS、暴力破解 | 上线前 |
| **兼容性测试** | BrowserStack、SauceLabs | 多浏览器、多设备 | 迭代后期 |
| **回归测试** | 自动化脚本 | 缺陷修复验证、功能回归 | 每次发版前 |

---

### 7.2 测试方法

#### 7.2.1 等价类划分

**有效等价类**：
- 用户名：已注册的邮箱/手机号/用户名
- 密码：符合复杂度要求的正确密码

**无效等价类**：
- 用户名：未注册、格式错误、特殊字符
- 密码：错误密码、空密码、超长密码

---

#### 7.2.2 边界值分析

| 测试项 | 边界值 | 测试数据 |
|--------|--------|----------|
| **密码长度** | 最小6位 | 5位、6位、7位 |
| **密码长度** | 最大20位 | 19位、20位、21位 |
| **失败次数** | 锁定阈值5次 | 4次、5次、6次 |
| **会话超时** | 30分钟 | 29分、30分、31分 |

---

#### 7.2.3 场景分析

**主成功场景**：
1. 用户访问登录页
2. 输入正确凭证
3. 点击登录
4. 登录成功，跳转首页

**扩展场景**：
- 用户忘记密码 → 跳转到找回密码流程
- 用户输入错误凭证 → 显示错误提示
- 用户账号被锁定 → 提示解锁方式
- 用户会话超时 → 重定向到登录页

---

#### 7.2.4 状态转换测试

```
[未登录] --登录成功--> [已登录]
[已登录] --会话超时--> [未登录]
[已登录] --用户登出--> [未登录]
[未登录] --连续5次失败--> [账号锁定]
[账号锁定] --等待30分钟--> [未登录]
```

---

### 8.3 缺陷报告规范
