# 灵犀整理云盘照片为自定义相册 - 测试需求分析报告

**文档版本**：V2.0（基于质量审核反馈修订）
**生成时间**：2026-06-29
**产品名称**：灵犀整理云盘照片为自定义相册
**需求来源**：技术方案文档 + TODO补充项
**功能模块**：4个大步骤（意图识别 → 搜索分类 → 确认互动 → 入库）

---

## 一、需求背景与范围

### 1.1 需求背景
灵犀（AI对话助手）新增"照片整理"能力：用户用自然语言描述整理需求，系统自动搜索云盘照片、调用大模型分类、经用户确认后将照片归入多个自定义相册。

### 1.2 需求范围（4大功能模块）

| 模块 | 技术标识 | 核心职责 |
|------|---------|---------|
| M1 意图识别 | 043-photo-organize | 命中"照片整理"意图，跳过实体抽取 |
| M2 图片搜索与AI分类 | TextToolAiCustomAlbumHandlerImpl | 问题重写→多轮语义搜图→LLM分类 |
| M3 用户确认互动 | SSE ALBUM_CUSTOM_CONFIRM(16) | 推送分类结果+确认按钮，接收确认指令 |
| M4 相册创建入库 | 相册SaaS /photo/customization/* | 逐组创建相册+批量添加图片 |

### 1.3 不在范围内
- 新增数据库表（本服务仅编排层）
- 相册SaaS内部实现（仅验证接口契约）
- 前端UI实现细节（仅验证SSE协议与指令机制）

---

## 二、业务流转（4大步骤）

```
大步骤1: 问题重写 + 多轮语义搜图（最多3轮）
  用户输入 → 意图识别(043) → 问题重写 → 语义搜图 → 空结果重试(≤3) → SSE推送中间状态

大步骤2: LLM抽取整理计划
  多轮原文 → LLM抽取计划(datetime/address，最多2维度) → 维度>3 → 建议MCLAW并终止

大步骤3: 可执行性校验 + 用户确认
  标签数据+计划 → LLM校验(可执行/不可执行/需调整) → 不可执行→调整建议→重新抽取
  可执行 → 计划写入存储 → SSE推送预览+确定按钮

大步骤4: 用户确认 + 写入相册
  点击确定 → chat/v2/add(command=043, dialogueId) → 幂等校验 → 取计划/结果
  → 遍历分组 → 创建相册 → 添加图片 → SSE推送完成(ALBUM_CUSTOM_COMPLETE=17)
```
