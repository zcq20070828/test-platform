# 测试中台工作流页面需求分析报告

**文档版本**：v1.0  
**分析日期**：2025-06-06  
**分析范围**：测试中台工作流页面全部功能模块  
**分析方法**：EPIC分解 + MoSCoW优先级 + 验收标准定义

---

## 一、需求概述

### 1.1 业务背景

测试中台工作流模块是测试团队的核心作业平台，提供测试流程的编排、执行、监控全生命周期管理能力。通过可视化工作流设计器，测试人员可以快速构建自动化测试流程，降低测试技术门槛，提升测试效率。

### 1.2 利益相关者

| 角色 | 职责 | 关注点 |
|------|------|--------|
| 测试工程师 | 工作流创建、执行、结果分析 | 操作便捷性、执行效率 |
| 测试组长/PM | 工作流审批、资源分配 | 权限管控、团队协作 |
| 运维/DevOps | 工作流执行环境维护 | 系统稳定性、资源调度 |
| 安全合规 | 权限审计、数据安全 | 权限最小化、操作可追溯 |

## 三、功能需求详细分析

### 3.1 WF-EPIC-01：工作流列表展示功能

#### WF-REQ-01 工作流多维度检索

**功能描述**：
支持按工作流名称、创建人、标签、创建时间范围、执行状态等多维度组合检索。

**用户故事**：
```
As a 测试工程师
I want to 通过多个维度快速筛选工作流
So that 我能在大量工作流中快速定位目标项
```

**验收标准**：
| 编号 | Given（前置条件） | When（操作） | Then（预期结果） |
|------|------------------|--------------|------------------|
| AC-01-01 | 工作流列表已加载 | 输入名称关键字"接口测试" | 显示名称包含该关键字的所有工作流 |
| AC-01-02 | 检索面板展开 | 选择时间范围"近7天" | 仅显示该时间段创建的工作流 |
| AC-01-03 | 多条件同时设置 | 名称="冒烟" + 状态="草稿" | 返回同时满足两个条件的工作流 |
| AC-01-04 | 无匹配结果 | 检索条件无对应工作流 | 显示"未找到符合条件的工作流"提示 |
| AC-01-05 | 清空筛选条件 | 点击"重置"按钮 | 恢复默认列表展示 |

**测试要点**：
- [ ] 精确匹配与模糊匹配切换
- [ ] 时间范围选择器交互
- [ ] 多条件组合查询逻辑 (AND/OR)
- [ ] 分页场景下筛选行为
- [ ] 检索历史保存

### 3.2 WF-EPIC-02：工作流创建/编辑功能

**功能描述**：
提供拖拽式可视化工作流设计器，支持顺序、分支、并行、循环等流程控制。

**用户故事**：
```
As a 测试工程师
I want to 通过拖拽组件编排测试流程
So that 无需编写代码即可完成复杂测试流程设计
```

**验收标准**：
| 编号 | Given | When | Then |
|------|-------|------|------|
| AC-04-01 | 设计器页面 | 从组件栏拖拽"开始节点"到画布 | 节点被放置到目标位置 |
| AC-04-02 | 画布有多个节点 | 拖拽连接线连接节点 | 显示带箭头的连线 |
| AC-04-03 | 创建分支节点 | 配置分支条件"A>0" | 分支节点显示条件标签 |
| AC-04-04 | 画布有完整流程 | 点击"保存" | 流程保存成功，提示"已保存为草稿" |
| AC-04-05 | 流程节点数量>20 | 查看流程图 | 自动缩放适配视图 |

**测试要点**：
- [ ] 节点拖拽放置精度
- [ ] 连线绘制与删除
- [ ] 节点对齐辅助线
- [ ] 画布缩放/平移操作
- [ ] 流程图导出为图片
- [ ] 撤销/重做功能

### 3.3 WF-EPIC-03：工作流执行与监控

#### WF-REQ-07 触发执行机制

**功能描述**：
支持手动触发、定时触发、API触发、事件触发等多种执行方式。

**用户故事**：
```
As a 测试组长
I want to 设置定时执行测试工作流
So that 在非工作时间自动运行冒烟测试
```

**验收标准**：
| 编号 | Given | When | Then |
|------|-------|------|------|
| AC-07-01 | 工作流已发布 | 点击"立即执行"按钮 | 弹出参数配置框 |
| AC-07-02 | 配置执行参数 | 选择环境=test，点击"执行" | 工作流进入执行队列 |
| AC-07-03 | 设置定时任务 | 配置cron="0 2 * * *" | 定时任务创建成功 |
| AC-07-04 | 配置API触发 | 开启API触发，获取webhook地址 | 显示完整的webhook URL |
| AC-07-05 | 触发执行时参数缺失 | POST请求缺少必填参数 | 返回400，提示参数缺失 |

**测试要点**：
- [ ] 手动执行参数传递
- [ ] Cron表达式解析正确性
- [ ] API触发认证与鉴权
- [ ] 触发限流（防止重复触发）
- [ ] 触发记录可查询

### 3.4 WF-EPIC-04：工作流权限控制

#### WF-REQ-10 基于角色的访问控制 (RBAC)

**功能描述**：
基于角色分配工作流的查看、编辑、执行、管理权限。

**权限矩阵**：

| 角色 | 查看 | 编辑 | 执行 | 管理 | 审批 |
|------|------|------|------|------|------|
| 访客 | ✓ | - | - | - | - |
| 开发者 | ✓ | ✓ | ✓ | - | - |
| 测试组长 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 管理员 | ✓ | ✓ | ✓ | ✓ | ✓ |

**验收标准**：
| 编号 | Given | When | Then |
|------|-------|------|------|
| AC-10-01 | 访客用户登录 | 查看工作流列表 | 仅能查看公开的工作流 |
| AC-10-02 | 开发者用户 | 编辑他人创建的工作流 | 提示"无编辑权限" |
| AC-10-03 | 管理员设置权限 | 为用户分配"执行"权限 | 用户获得执行该工作流权限 |
| AC-10-04 | 权限变更生效时 | 工作流正在执行 | 权限变更不影响当前执行 |
| AC-10-05 | 移除权限 | 撤销某用户的访问权限 | 用户立即无法访问 |

**测试要点**：
- [ ] 权限继承与覆盖
- [ ] 工作流级别权限 vs 系统级别权限
- [ ] 权限变更实时生效
- [ ] 权限验证边界 (接口级 + 页面级)
- [ ] 超级管理员权限范围
