# 用户登录功能 - 测试需求分析报告

文档版本: v4.0 | 生成时间: 2026-06-29

## 一、初始需求捕获

原始需求: 测试用户登录功能，包括用户名密码登录、验证码登录、忘记密码

## 二、利益相关者分析

1. 最终用户 - 关注登录成功率、响应速度、易用性
2. 产品经理 - 关注功能完整性和用户体验
3. 开发团队 - 关注接口规范、异常处理逻辑
4. 安全团队 - 关注SQL注入、XSS、暴力破解、密码安全
5. 测试团队 - 关注可执行性、覆盖率、边界条件

## 三、功能需求分解 (EPIC到用户故事)

### EPIC: 用户登录功能

---

### 需求1: 用户名密码登录 (REQ-001, 优先级P0)

用户故事清单:

US-001 正常登录成功
   前置条件: 已注册用户test_user，密码Pass1234
   操作: 输入用户名test_user + 密码Pass1234，点击登录
   预期结果: 登录成功，状态码200，跳转首页，Token已生成

US-002 空用户名校验
   操作: 用户名为空 + 输入密码，点击登录
   预期结果: 提示请输入用户名，输入框高亮，不发起API请求

US-003 空密码校验
   操作: 输入用户名 + 密码为空，点击登录
   预期结果: 提示请输入密码，输入框高亮，不发起API请求

US-004 用户名不存在
   操作: 输入不存在的用户名notexist + 任意密码
   预期结果: 提示用户名或密码错误 (统一模糊化，不暴露是否存在)

US-005 密码错误
   前置条件: test_user已注册
   操作: 输入test_user + 错误密码WrongPass
   预期结果: 提示用户名或密码错误 (不暴露是哪个字段错误)

US-006 账号被禁用
   前置条件: disabled_user已预置为禁用状态
   操作: 输入disabled_user + 正确密码
   预期结果: 提示账号已被禁用，请联系管理员

US-007 记住我 (30天)
   操作: 勾选记住我后登录成功，关闭浏览器重新打开
   预期结果: 保持登录状态，Cookie有效期30天，HttpOnly+Secure

US-008 不勾选记住我
   操作: 不勾选记住我登录成功，关闭浏览器重新打开
   预期结果: 需要重新登录，session级有效

US-009 5次错误锁定
   前置条件: lock_test已注册
   操作: 连续5次输入错误密码
   预期结果: 前4次提示用户名或密码错误，第5次提示账号已锁定30分钟

US-010 锁定期间拒绝登录
   前置条件: 账号已锁定
   操作: 锁定期间输入正确密码
   预期结果: 提示剩余锁定时间，拒绝登录

US-011 登录成功跳转首页
   操作: 登录成功后验证URL
   预期结果: URL变更为首页地址

US-012 登录前URL恢复
   操作: 访问受保护页面自动跳转登录，登录后验证
   预期结果: 登录成功后跳转回原始请求页面

US-013 SQL注入防护-用户名
   操作: 用户名输入' OR '1'='1 + 任意密码
   预期结果: 登录失败，无SQL报错信息暴露

US-014 XSS防护-用户名
   操作: 用户名输入<script>alert(1)</script> + 任意密码
   预期结果: 脚本被过滤或转义，不执行，登录失败

### 需求2: 验证码登录 (REQ-002, 优先级P0)

US-015 验证码登录成功
   前置条件: 手机号13800001001已注册
   操作: 输入手机号 + 获取验证码 + 输入正确验证码
   预期结果: 登录成功，跳转首页

US-016 手机号为空
   操作: 手机号为空，点击获取验证码
   预期结果: 提示请输入手机号，不发送请求

US-017 手机号格式错误
   操作: 输入10位/12位手机号或含字母手机号
   预期结果: 提示手机号格式不正确

US-018 验证码为空
   前置条件: 已获取验证码
   操作: 验证码为空，点击登录
   预期结果: 提示请输入验证码

US-019 验证码错误
   前置条件: 已获取验证码
   操作: 输入错误验证码000000
   预期结果: 提示验证码错误

US-020 验证码过期
   操作: 获取验证码后等待超过5分钟，使用该验证码登录
   预期结果: 提示验证码已过期，请重新获取

US-021 验证码发送倒计时
   操作: 点击获取验证码，观察按钮状态
   预期结果: 按钮变灰，显示60s倒计时，倒计时结束恢复可点击

US-022 验证码频率限制
   操作: 60秒内再次点击获取验证码
   预期结果: 按钮不可点击，不发送请求

US-023 未注册手机号一键注册
   操作: 使用未注册手机号验证码登录
   预期结果: 自动注册账号并登录成功

US-024 验证码重放攻击
   操作: 使用已成功登录过的验证码再次登录
   预期结果: 提示验证码已失效

### 需求3: 忘记密码 (REQ-003, 优先级P1)

US-025 正常重置密码
   前置条件: 手机号13800001001已注册
   操作: 手机号验证身份 -> 输入新密码NewPass123 -> 确认一致 -> 提交
   预期结果: 重置成功，跳转登录页

US-026 手机号为空
   操作: 手机号为空，点击获取验证码
   预期结果: 提示请输入手机号

US-027 手机号未注册
   操作: 输入未注册手机号
   预期结果: 提示该手机号未注册

US-028 新密码为空
   前置条件: 身份验证通过
   操作: 新密码为空，点击提交
   预期结果: 提示请输入新密码

US-029 确认密码不一致
   前置条件: 身份验证通过
   操作: 新密码Pass123，确认密码Pass456
   预期结果: 提示两次输入密码不一致

US-030 新密码强度不足
   前置条件: 身份验证通过
   操作: 新密码设为123456 (纯数字6位)
   预期结果: 提示密码强度过低

US-031 新密码与旧密码相同
   前置条件: 当前密码为Pass1234
   操作: 新密码设为Pass1234
   预期结果: 提示新密码不能与旧密码相同

US-032 重置后旧密码失效
   前置条件: 密码已重置
   操作: 用旧密码登录
   预期结果: 提示用户名或密码错误，旧密码不可用

US-033 重置后新密码可用
   前置条件: 密码已重置
   操作: 用新密码登录
   预期结果: 登录成功

## 四、安全需求清单 (10项P0)

SEC-01 SQL注入防护: 用户名/手机号输入框防SQL注入，采用参数化查询
SEC-02 XSS防护: 输入过滤+输出编码，防止跨站脚本攻击
SEC-03 暴力破解防护: 连续5次密码错误锁定30分钟
SEC-04 验证码防刷: 60秒倒计时+频率限制
SEC-05 验证码安全: 5分钟有效期+单次有效，防止重放
SEC-06 传输加密: 所有登录请求必须HTTPS + 请求体加密
SEC-07 存储加密: 密码bcrypt加盐哈希存储
SEC-08 会话安全: Cookie设置HttpOnly+Secure+SameSite
SEC-09 错误提示安全: 统一用户名或密码错误，防止用户枚举
SEC-10 图形验证码: 连续3次登录失败后触发图形验证码

## 五、边界条件

1. 用户名长度: 最小值2字符，最大值50字符
   - 测试数据: 1字符(无效), 2字符(有效), 50字符(有效), 51字符(无效)
2. 密码长度: 最小值6字符，最大值32字符
   - 测试数据: 5字符(无效), 6字符(有效), 32字符(有效), 33字符(无效)
3. 手机号: 11位纯数字
   - 测试数据: 10位(无效), 11位(有效), 12位(无效), 含字母(无效)
4. 验证码: 6位数字
   - 测试数据: 5位(无效), 6位(有效), 7位(无效), 含字母(无效)
5. 错误次数: 5次触发锁定
   - 测试数据: 4次(不触发), 5次(触发锁定)
6. 首尾空格: 用户名自动去除首尾空格后匹配

## 六、风险矩阵 (7项)

R-01 用户名遍历攻击 - 高风险 - 统一错误提示防枚举
R-02 暴力破解攻击 - 高风险 - 5次锁定+图形验证码
R-03 短信轰炸攻击 - 高风险 - 60秒频率+IP维度限流
R-04 验证码重放攻击 - 高风险 - 单次有效+5分钟过期
R-05 SQL注入攻击 - 高风险 - 参数化查询
R-06 会话劫持 - 中风险 - HttpOnly+Secure+短有效期
R-07 旧密码复用 - 中风险 - 重置时新旧密码不同检查
