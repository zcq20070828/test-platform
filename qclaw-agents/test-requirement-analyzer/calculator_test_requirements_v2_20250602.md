| **操作方式** | 顺序运算、连续运算 | 括号运算、记忆功能 |

## 3. 验收标准（Given-When-Then 格式）

### AC-001: 整数加法正确性
```
Given 用户输入第一个整数 "5"
When  用户点击 "+" 按钮，然后输入第二个整数 "3"，点击 "="
Then  显示结果 "8"
```

### AC-002: 小数加法精度
```
Given 用户输入第一个小数 "0.1"
When  用户点击 "+" 按钮，然后输入第二个小数 "0.2"，点击 "="
Then  显示结果 "0.30"（保留两位小数）
```

### AC-003: 负数加法
```
Given 用户输入第一个负数 "-5"
When  用户点击 "+" 按钮，然后输入第二个负数 "-3"，点击 "="
Then  显示结果 "-8"
```

### AC-004: 整数减法正确性
```
Given 用户输入第一个整数 "10"
When  用户点击 "-" 按钮，然后输入第二个整数 "4"，点击 "="
Then  显示结果 "6"
```

### AC-005: 小数减法精度
```
Given 用户输入第一个小数 "1.5"
When  用户点击 "-" 按钮，然后输入第二个小数 "0.8"，点击 "="
Then  显示结果 "0.70"（保留两位小数）
```

### AC-006: 整数乘法正确性
```
Given 用户输入第一个整数 "6"
When  用户点击 "×" 按钮，然后输入第二个整数 "7"，点击 "="
Then  显示结果 "42"
```

### AC-007: 负数乘法规则
```
Given 用户输入第一个负数 "-5"
When  用户点击 "×" 按钮，然后输入第二个负数 "-3"，点击 "="
Then  显示结果 "15"（负负得正）
```

### AC-008: 整数除法正确性
```
Given 用户输入第一个整数 "20"
When  用户点击 "÷" 按钮，然后输入第二个整数 "4"，点击 "="
Then  显示结果 "5"
```

### AC-009: 小数除法精度
```
Given 用户输入第一个小数 "1.0"
When  用户点击 "÷" 按钮，然后输入第二个小数 "3"，点击 "="
Then  显示结果 "0.33"（保留两位小数，四舍五入）
```

### AC-010: 除零异常处理
```
Given 用户输入被除数 "5"
When  用户点击 "÷" 按钮，然后输入除数 "0"，点击 "="
Then  显示错误提示 "除数不能为零"，程序不崩溃
```

### AC-011: 零值加法
```
Given 用户输入任意整数 "5"
When  用户点击 "+" 按钮，然后输入 "0"，点击 "="
Then  显示结果 "5"（加零不变）
```

### AC-012: 零值乘法
```
Given 用户输入任意整数 "5"
When  用户点击 "×" 按钮，然后输入 "0"，点击 "="
Then  显示结果 "0"（乘零得零）
```

### AC-013: 大数溢出处理
```
Given 用户输入极大整数 "9999999999999999"
When  用户点击 "×" 按钮，然后输入另一个极大整数 "9999999999999999"，点击 "="
Then  显示溢出错误提示或科学计数法表示，程序不崩溃
```

### AC-014: 连续运算稳定性
```
Given 用户完成第一次运算 "2 + 3 = 5"
When  用户继续点击 "+" 按钮，输入 "4"，点击 "="
Then  显示结果 "9"（基于上一次结果继续运算）
```

### AC-015: 负数减法（减负数等于加正数）
```
Given 用户输入被减数 "5"
When  用户点击 "-" 按钮，然后输入负数 "-3"，点击 "="
Then  显示结果 "8"（5 - (-3) = 5 + 3 = 8）
```

## 5. 边界条件分析

### 5.1 等价类划分

| 输入类型 | 有效等价类 | 无效等价类 |
|---------|-----------|-----------|
| 整数 | 正整数、负整数、零 | 超出范围的大数 |
| 小数 | 正小数、负小数 | 精度超限小数 |
| 运算符 | +、-、×、÷ | 非法字符 |
| 操作数数量 | 2个 | 1个、3个 |

### 5.2 边界值分析

| 边界点 | 测试值 | 预期结果 |
|--------|--------|---------|
| 最大整数 | 9999999999999999 | 正确显示或溢出提示 |
| 最小整数 | -9999999999999999 | 正确显示或溢出提示 |
| 零值 | 0 | 正确运算 |
| 最小正小数 | 0.01 | 正确显示 |
| 精度边界 | 0.001 ÷ 3 | 0.00（保留两位小数） |

### 5.3 边界矩阵

| 输入类型 \ 运算 | 加法 | 减法 | 乘法 | 除法 |
|----------------|------|------|------|------|
| 正整数 | ✓ | ✓ | ✓ | ✓ |
| 负整数 | ✓ | ✓ | ✓ | ✓ |
| 正小数 | ✓ | ✓ | ✓ | ✓ |
| 负小数 | ✓ | ✓ | ✓ | ✓ |
| 零 | ✓ | ✓ | ✓ | ✓ |
| 极大数 | ⚠️ | ⚠️ | ⚠️ | ⚠️ |
| 极小数 | ✓ | ✓ | ✓ | ✓ |

✓ = 正常测试  
⚠️ = 需要溢出测试
