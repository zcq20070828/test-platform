## 1. 测试上下文（Context）

### 1.1 需求背景

用户登录模块是系统的安全入口，承载用户身份认证的核心功能。该模块直接关系到系统安全性和用户体验，是所有后续业务功能的前置条件。

### 1.2 范围界定

| 维度 | 范围说明 |
|------|---------|
| **包含** | 账号密码登录、验证码登录、第三方登录、密码找回、登录状态管理 |
| **不包含** | 用户注册（独立模块）、权限管理（独立模块）、用户信息修改（独立模块） |
| **边界** | 登录成功后跳转首页，不涉及首页功能测试 |

### 1.3 利益相关者

| 角色 | 关注点 | 参与度 |
|------|--------|--------|
| 最终用户 | 登录便捷性、安全性 | 高 |
| 业务负责人 | 用户转化率、安全合规 | 高 |
| 安全团队 | 认证机制安全性、防攻击 | 高 |
| 技术团队 | 架构设计、性能指标 | 中 |

    ├── 单点登录
    └── 强制下线

## 3. EPIC → 需求 → 用户故事分解

### EPIC-001：用户认证

> 作为用户，我需要通过多种方式登录系统，以便安全便捷地访问系统功能。

---

#### REQ-001：账号密码登录

**用户故事 US-001-01**：标准登录
> 作为注册用户，我希望使用账号密码登录系统，以便快速访问我的个人中心。

**用户故事 US-001-02**：记住登录状态
> 作为频繁使用的用户，我希望系统记住我的登录状态，避免每次重复登录。

**用户故事 US-001-03**：登录失败提示
> 作为用户，我希望登录失败时获得明确的错误提示，帮助我快速定位问题。

---

#### REQ-002：验证码登录

**用户故事 US-002-01**：短信验证码登录
> 作为忘记密码的用户，我希望通过手机验证码登录系统，作为备选登录方式。

**用户故事 US-002-02**：验证码获取限制
> 作为安全意识强的用户，我希望验证码获取有频率限制，防止骚扰和恶意攻击。

---

#### REQ-003：第三方OAuth登录

**用户故事 US-003-01**：微信快捷登录
> 作为微信用户，我希望使用微信账号快速登录，减少注册和记忆密码的负担。

**用户故事 US-003-02**：第三方账号绑定
> 作为已有账号的用户，我希望绑定第三方账号，实现多种方式登录同一账户。

---

#### REQ-004：安全防护机制

**用户故事 US-004-01**：图形验证码
> 作为系统管理员，我希望在可疑登录时触发图形验证码，防止自动化攻击。

**用户故事 US-004-02**：登录失败锁定
> 作为安全管理员，我希望系统在连续失败后锁定账户，防止暴力破解。

**用户故事 US-004-03**：密码安全传输
> 作为用户，我希望密码在传输过程中加密，防止中间人攻击。

---

#### REQ-005：密码管理

**用户故事 US-005-01**：忘记密码找回
> 作为忘记密码的用户，我希望通过邮箱或手机找回密码，恢复账户访问。

**用户故事 US-005-02**：修改密码
> 作为已登录用户，我希望修改密码，保障账户安全。

## 4. 功能点详细分析

### 4.1 账号密码登录

#### 业务流程
```
开始 → 输入账号 → 输入密码 → 点击登录 → 后端验证 → 判断结果
                                                    ↓
                        ←────────────────────── 验证通过 → 生成Token → 存储会话 → 跳转首页
                                                    ↓
                        ←────────────────────── 验证失败 → 返回错误信息 → 记录失败次数 → 判断是否触发锁定
```

#### 输入验证要求

| 字段 | 数据类型 | 长度限制 | 格式要求 | 必填 | 验证规则 |
|------|---------|---------|---------|------|---------|
| 账号 | String | 4-20字符 | 手机号/邮箱/用户名 | 是 | 正则匹配：手机`^1[3-9]\d{9}$`、邮箱标准格式、用户名`^[a-zA-Z][a-zA-Z0-9_]{3,19}$` |
| 密码 | String | 8-20字符 | - | 是 | 包含大小写字母+数字，可选特殊字符 |
| 图形验证码 | String | 4-6字符 | 字母+数字 | 条件 | 不区分大小写，5分钟有效 |

#### 安全性需求

| 安全项 | 需求描述 | 实现方式 |
|--------|---------|---------|
| 密码传输加密 | 密码不得明文传输 | HTTPS + RSA公钥加密 或 HTTPS + 密码哈希 |
| 密码存储加密 | 密码不得明文存储 | bcrypt / Argon2 / PBKDF2 |
| 防暴力破解 | 限制失败次数 | 同IP同账号5次失败锁定15分钟 |
| 防重放攻击 | 防止请求重放 | 请求时间戳 + Nonce值 |
| 敏感信息脱敏 | 日志不记录密码 | 密码字段用***替代 |

#### 边界条件

| 边界场景 | 边界值 | 预期行为 |
|---------|--------|---------|
| 账号长度最小值 | 4字符 | 正常处理 |
| 账号长度最大值 | 20字符 | 正常处理 |
| 账号长度超限 | 21字符 | 提示"账号长度不能超过20字符" |
| 密码长度最小值 | 8字符 | 正常处理 |
| 密码长度最大值 | 20字符 | 正常处理 |
| 密码复杂度不足 | 纯数字 | 提示"密码必须包含字母和数字" |
| 连续失败次数 | 第5次 | 触发账户锁定15分钟 |
| 锁定时间到期 | 15分钟后 | 自动解锁，可重新尝试 |

### 4.2 短信验证码登录

#### 业务流程
```
开始 → 输入手机号 → 点击获取验证码 → 判断是否触发限制 → 发送验证码 → 输入验证码 → 点击登录 → 验证 → 判断结果
                                                    ↓
                        ←────────────────────── 60秒内重复获取 → 提示"验证码已发送，请勿重复获取"
```

#### 输入验证要求

| 字段 | 数据类型 | 长度限制 | 格式要求 | 必填 | 验证规则 |
|------|---------|---------|---------|------|---------|
| 手机号 | String | 11位 | 中国大陆手机号 | 是 | `^1[3-9]\d{9}$` |
| 验证码 | String | 6位 | 纯数字 | 是 | 5分钟有效 |

#### 安全性需求

| 安全项 | 需求描述 | 实现方式 |
|--------|---------|---------|
| 验证码有效期 | 防止验证码长期有效 | 5分钟过期 |
| 获取频率限制 | 防止短信轰炸 | 60秒间隔，单号码日上限10条 |
| 验证码错误限制 | 防止暴力猜测 | 连续3次错误失效 |
| 手机号黑名单 | 防止恶意号码 | 维护黑名单库 |

#### 边界条件

| 边界场景 | 边界值 | 预期行为 |
|---------|--------|---------|
| 手机号格式错误 | 12345678901 | 提示"手机号格式不正确" |
| 手机号为空 | - | 提示"请输入手机号" |
| 验证码为空 | - | 提示"请输入验证码" |
| 验证码错误 | 123456(实际654321) | 提示"验证码错误" |
| 验证码过期 | 6分钟后 | 提示"验证码已过期，请重新获取" |
| 60秒内重复获取 | 30秒后再次点击 | 提示"验证码已发送，请等待60秒" |
| 单日获取上限 | 第11次 | 提示"今日获取次数已达上限" |

### 4.3 第三方OAuth登录

#### 业务流程
```
开始 → 选择第三方平台 → 跳转授权页 → 用户授权 → 回调获取code → 换取access_token → 获取用户信息 → 判断是否已绑定
                                                                                            ↓
            ←─────────────────────────────────── 已绑定 → 直接登录成功
                                                                                            ↓
            ←─────────────────────────────────── 未绑定 → 引导绑定已有账号或创建新账号
```

#### 支持的第三方平台

| 平台 | OAuth版本 | 所需权限 |
|------|----------|---------|
| 微信开放平台 | OAuth 2.0 | snsapi_login |
| 支付宝 | OAuth 2.0 | auth_user |
| 微博 | OAuth 2.0 | 用户信息读取 |
| QQ | OAuth 2.0 | get_user_info |

#### 安全性需求

| 安全项 | 需求描述 | 实现方式 |
|--------|---------|---------|
| State参数防CSRF | 验证请求来源 | 生成随机state，回调时校验 |
| 授权码时效性 | 防止授权码重放 | 授权码5分钟有效，一次性使用 |
| Access Token安全 | 防止Token泄露 | 存储加密，定期刷新 |
| 用户信息最小化 | 仅获取必要信息 | 仅获取昵称、头像、openid |

---

### 4.4 密码找回

#### 业务流程
```
开始 → 输入账号/手机/邮箱 → 选择找回方式 → 发送验证码 → 验证身份 → 设置新密码 → 密码重置成功 → 跳转登录
```

#### 输入验证要求

| 字段 | 数据类型 | 长度限制 | 格式要求 | 必填 | 验证规则 |
|------|---------|---------|---------|------|---------|
| 新密码 | String | 8-20字符 | - | 是 | 包含大小写字母+数字 |
| 确认密码 | String | 8-20字符 | - | 是 | 必须与新密码一致 |

#### 安全性需求

| 安全项 | 需求描述 | 实现方式 |
|--------|---------|---------|
| 身份验证 | 确保操作者是账号所有者 | 手机/邮箱验证码双重验证 |
| 密码历史检查 | 避免使用近期密码 | 最近5次密码不可重复 |
| 重置链接安全 | 防止链接泄露 | 一次性链接，24小时有效 |
| 操作日志记录 | 审计追踪 | 记录IP、时间、设备信息 |

## 5. 验收标准（Acceptance Criteria）

### AC-001：账号密码登录成功

```gherkin
Given 用户在登录页面
  And 用户已注册账号 "testuser" 密码 "Test@123456"
When 用户输入账号 "testuser"
  And 用户输入密码 "Test@123456"
  And 用户点击登录按钮
Then 系统验证账号密码正确
  And 系统生成登录Token
  And 用户跳转至首页
  And 登录状态保持有效
```

### AC-002：账号不存在登录失败

```gherkin
Given 用户在登录页面
  And 用户未注册账号 "notexist"
When 用户输入账号 "notexist"
  And 用户输入密码 "Test@123456"
  And 用户点击登录按钮
Then 系统提示"账号或密码错误"
  And 登录失败次数+1
  And 用户仍停留在登录页面
```

### AC-003：密码错误触发锁定

```gherkin
Given 用户在登录页面
  And 用户已注册账号 "testuser"
  And 该账号已连续失败4次
When 用户输入错误密码第5次
  And 用户点击登录按钮
Then 系统提示"账号已锁定，请15分钟后重试"
  And 账号锁定15分钟
  And 锁定期间所有登录尝试被拒绝
```

### AC-004：短信验证码登录成功

```gherkin
Given 用户在登录页面选择"验证码登录"
  And 用户已注册手机号 "13800138000"
When 用户输入手机号 "13800138000"
  And 用户点击"获取验证码"
  And 用户收到验证码 "123456"
  And 用户输入验证码 "123456"
  And 用户点击登录按钮
Then 系统验证验证码正确
  And 用户登录成功
  And 用户跳转至首页
```

### AC-005：图形验证码触发

```gherkin
Given 用户在登录页面
  And 同一IP登录失败已达3次
When 用户再次访问登录页面
Then 系统显示图形验证码
  And 用户必须输入正确的图形验证码才能继续登录
```

### AC-006：密码找回成功

```gherkin
Given 用户在"忘记密码"页面
  And 用户已注册手机号 "13800138000"
When 用户输入手机号 "13800138000"
  And 用户选择"手机验证码找回"
  And 用户输入正确的验证码
  And 用户输入新密码 "NewPass@123"
  And 用户确认新密码 "NewPass@123"
  And 用户点击"确认重置"
Then 系统提示"密码重置成功"
  And 用户可使用新密码登录
  And 原密码失效
```

### AC-007：会话超时自动登出

```gherkin
Given 用户已登录系统
  And 系统会话超时时间设置为30分钟
When 用户无操作超过30分钟
  And 用户再次发起请求
Then 系统提示"登录已过期，请重新登录"
  And 用户跳转至登录页面
  And 原会话Token失效
```

### AC-008：强制下线

```gherkin
Given 用户A已登录
  And 管理员在后台执行"强制下线"操作
When 用户A再次发起请求
Then 系统提示"您的账号已在其他设备登录"
  And 用户A跳转至登录页面
  And 用户A的原Token立即失效
```

## 6. 非功能性需求

### 6.1 性能需求

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| 登录响应时间 | < 500ms（P95） | 接口压测 |
| 并发登录支持 | 1000 TPS | 并发压测 |
| 验证码发送延迟 | < 3s | 端到端测试 |
| Token验证响应 | < 50ms | 接口压测 |

### 6.2 安全需求

| 安全项 | 标准要求 | 合规依据 |
|--------|---------|---------|
| 密码强度 | 8位以上，含大小写+数字 | 等保2.0 |
| 密码加密存储 | bcrypt/Argon2 | 等保2.0 |
| 传输加密 | TLS 1.2+ | PCI-DSS |
| 会话安全 | Token带有效期+签名 | OWASP |
| 敏感日志脱敏 | 密码用***替代 | 个人信息保护法 |

### 6.3 可用性需求

| 指标 | 目标值 |
|------|--------|
| 登录功能可用性 | 99.9% |
| 错误提示可理解性 | 用户测试通过率>95% |
| 登录成功率 | > 99% |

### 6.4 兼容性需求

| 维度 | 要求 |
|------|------|
| 浏览器 | Chrome 90+、Firefox 88+、Safari 14+、Edge 90+ |
| 移动端 | iOS 13+、Android 8+ |
| 分辨率 | 320px - 4K自适应 |

## 8. 风险评估

### 8.1 风险矩阵

| 风险项 | 概率 | 影响 | 风险等级 | 缓解措施 |
|--------|------|------|---------|---------|
| 暴力破解攻击 | 高 | 高 | **严重** | 多层防护：图形验证码+失败锁定+IP限流 |
| 中间人攻击 | 中 | 高 | **高** | 强制HTTPS+证书校验 |
| 密码泄露 | 中 | 高 | **高** | 密码加密存储+定期提醒修改 |
| 短信轰炸 | 中 | 中 | **中** | 频率限制+每日上限+黑名单 |
| SQL注入 | 低 | 高 | **中** | 参数化查询+输入过滤 |
