#### 需求 R-001：手机号+验证码登录

| ID | 用户故事 | 优先级 | 验收标准 |
|----|---------|--------|---------|
| US-001.1 | 作为用户，我可以通过手机号获取验证码，以便快捷登录 | **Must** | Given 用户输入有效手机号 When 点击"获取验证码" Then 系统发送6位数字验证码至用户手机 |
| US-001.2 | 作为用户，我可以使用验证码完成登录，以便无需记忆密码 | **Must** | Given 用户输入正确验证码 When 点击"登录" Then 返回Token并跳转至首页 |
| US-001.3 | 作为用户，验证码错误时能看到明确提示，以便重新输入 | **Must** | Given 用户输入错误验证码 When 点击"登录" Then 提示"验证码错误，剩余N次机会"，HTTP 400 |
| US-001.4 | 作为用户，验证码过期时能申请重新发送，以便继续登录 | **Must** | Given 验证码已过期（10分钟）When 用户点击"重新获取" Then 收到新验证码，原验证码失效 |
| US-001.5 | 作为用户，频繁获取验证码时需要图形验证码，以防刷接口 | **Should** | Given 用户1分钟内已获取3次验证码 When 再次点击"获取" Then 弹出图形验证码，完成后才能发送 |

---

#### 需求 R-002：用户名+密码登录

| ID | 用户故事 | 优先级 | 验收标准 |
|----|---------|--------|---------|
| US-002.1 | 作为用户，我可以使用用户名和密码登录，以便使用账号密码方式访问系统 | **Must** | Given 用户输入正确的用户名+密码 When 点击"登录" Then 返回Token并跳转至首页 |
| US-002.2 | 作为用户，我登录失败时能看到错误提示，以便排查问题 | **Must** | Given 用户名或密码错误 When 点击"登录" Then 提示"用户名或密码错误"，HTTP 401 |
| US-002.3 | 作为用户，我连续失败5次后账号被锁定，以便防止暴力破解 | **Must** | Given 连续5次登录失败 When 第6次登录 Then 账号锁定30分钟，HTTP 403，返回剩余锁定时间 |
| US-002.4 | 作为用户，我可以勾选"记住我"以便在30天内免登录 | **Should** | Given 用户勾选"记住我"并登录成功 When 30天内再次访问 Then 无需重新登录 |
| US-002.5 | 作为用户，我可以查看密码是否显示，以便避免输入错误 | **Should** | Given 用户输入密码时 When 点击眼睛图标 Then 密码明文/密文切换 |

| ID | 用户故事 | 优先级 | 验收标准 |
|----|---------|--------|---------|
| US-003.1 | 作为用户，我可以使用微信扫码登录，以便快速登录无需注册 | **Must** | Given 用户使用微信扫码授权 When 授权成功 Then 返回Token并跳转至首页 |
| US-003.2 | 作为用户，我可以使用支付宝登录，以便使用支付宝账号快速登录 | **Must** | Given 用户使用支付宝授权 When 授权成功 Then 返回Token并跳转至首页 |
| US-003.3 | 作为用户，我可以使用钉钉登录，以便企业用户便捷登录 | **Should** | Given 企业用户使用钉钉授权 When 授权成功 Then 返回Token并跳转至首页 |
| US-003.4 | 作为新用户首次OAuth登录，系统应自动创建账号以便我直接使用 | **Must** | Given 用户首次OAuth授权（openid未绑定）When 授权成功 Then 自动创建本地账号并登录 |
| US-003.5 | 作为已绑定用户OAuth登录，系统应直接登录已有账号以便我快速访问 | **Must** | Given openid已绑定到现有账号 When 使用相同OAuth登录 Then 直接登录已有账号 |

## 五、非功能性需求

### 5.1 安全性要求

| 安全项 | 要求标准 | 测试要点 |
|-------|---------|---------|
| **密码存储** | 使用BCrypt加密，强度≥8位，含大小写+数字+特殊字符 | 验证加密算法、脱库防护 |
| **暴力破解防护** | 连续5次失败锁定30分钟，验证码3次错误失效 | 接口压测验证防护有效性 |
| **CSRF防护** | 所有POST请求需携带CSRF Token，OAuth使用State参数 | 安全扫描验证 |
| **敏感数据加密** | Token/密码/手机号传输必须HTTPS加密 | 抓包验证加密传输 |
| **OAuth安全** | State参数防CSRF，Code一次性使用，有效期≤10分钟 | 安全扫描验证 |
| **会话管理** | Token不可预测，会话超时自动失效 | 会话安全测试 |
| **SQL注入防护** | 所有输入参数化查询 | 安全扫描验证 |

### 5.2 接口测试标准（参考测试知识库）

| 接口场景 | HTTP方法 | 成功状态码 | 错误状态码 | 目标响应时间 | 最大响应时间 |
|---------|---------|-----------|-----------|-------------|-------------|
| 账号密码登录 | POST | 200 | 400/401/403 | ≤300ms | 500ms |
| 发送验证码 | POST | 200 | 400/429 | ≤200ms | 500ms |
| 验证码登录 | POST | 200 | 400/401 | ≤300ms | 500ms |
| OAuth授权跳转 | GET | 302 | 400/401 | ≤1s | 2s |
| OAuth回调登录 | GET→POST | 200 | 400/401 | ≤500ms | 1s |
| 登录页面加载 | GET | 200 | 500 | ≤1s | 2s |

### 5.3 响应时间标准

| 场景 | 目标时间 | 最大时间 | 测试标准来源 |
|-----|---------|---------|-------------|
| 简单查询类接口 | < 200ms | 500ms | 测试知识库标准 |
| 复杂查询类接口 | < 1s | 2s | 测试知识库标准 |
| 含外部依赖接口 | < 500ms | 1s | 含第三方延迟 |

### 5.4 并发性要求

| 指标 | 目标值 | 说明 |
|-----|-------|------|
| **最大并发登录数** | ≥1000 TPS | 支持1000用户同时登录 |
| **验证码发送并发** | ≥500 TPS | 支持500用户同时请求验证码 |
| **OAuth回调并发** | ≥200 TPS | 支持200用户同时完成OAuth回调 |

### 5.5 可用性要求

| 指标 | 要求 |
|-----|------|
| **系统可用性** | ≥99.9%（月度停机≤8.7小时） |
| **登录成功率** | ≥99.5%（成功登录/总登录请求） |
| **核心链路容灾** | 登录服务集群部署，单节点故障不影响登录 |

## 九、验收标准定义（Given-When-Then格式）

### 9.1 核心验收标准

| 编号 | Given（前置条件） | When（操作） | Then（预期结果） |
|-----|------------------|------------|-----------------|
| AC-001 | 用户输入有效手机号 | 点击"获取验证码" | 60秒内收到6位数字验证码 |
| AC-002 | 用户输入正确验证码 | 点击"登录" | 成功进入系统并获取Token，HTTP 200 |
| AC-003 | 用户输入错误验证码 | 点击"登录" | 提示"验证码错误，剩余N次"，HTTP 400 |
| AC-004 | 验证码已过期 | 用户点击登录 | 提示"验证码已过期"，HTTP 400 |
| AC-005 | 用户名密码正确 | 点击"登录" | 成功进入系统并获取Token，HTTP 200 |
| AC-006 | 用户名或密码错误 | 点击"登录" | 提示"用户名或密码错误"，HTTP 401 |
| AC-007 | 连续5次登录失败 | 第6次登录 | 账号锁定30分钟，HTTP 403 |
| AC-008 | 账号处于锁定状态 | 尝试登录 | 返回锁定剩余时间，HTTP 403 |
| AC-009 | 用户首次微信OAuth授权 | 完成授权 | 自动创建账号并登录，HTTP 200 |
| AC-010 | openid已绑定账号 | 使用相同OAuth登录 | 直接登录已有账号，HTTP 200 |
| AC-011 | OAuth回调State参数被篡改 | 回调请求 | 拒绝登录，HTTP 401 |

### 9.2 错误码规范

| 错误码 | HTTP状态码 | 错误信息 | 说明 |
|-------|-----------|---------|------|
| AUTH_CODE_EXPIRED | 400 | 验证码已过期 | 验证码超过10分钟有效期 |
| AUTH_CODE_ERROR | 400 | 验证码错误，剩余N次 | 验证码输入错误 |
| AUTH_CODE_INVALID | 400 | 验证码无效 | 验证码不存在或已使用 |
| AUTH_RATE_LIMIT | 429 | 操作过于频繁，请稍后再试 | 触发限流规则 |
| AUTH_ACCOUNT_LOCKED | 403 | 账号已锁定，剩余X分钟 | 账号被锁定 |
| AUTH_INVALID_CREDENTIALS | 401 | 用户名或密码错误 | 认证失败 |
| AUTH_OAUTH_STATE_INVALID | 401 | 授权状态无效 | State参数校验失败 |
| AUTH_OAUTH_FAILED | 401 | 第三方授权失败 | OAuth授权失败 |
