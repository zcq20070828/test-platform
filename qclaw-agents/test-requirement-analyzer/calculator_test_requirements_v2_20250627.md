## 1. 需求背景与范围界定

### 1.1 业务背景

计算器是基础工具软件，四则运算是最核心的功能。本分析旨在明确测试范围、优先级和验收标准，确保功能交付质量。

### 1.2 测试范围

| 包含范围 | 不包含范围 |
|---------|-----------|
| ✅ 加法运算 (+)、减法运算 (-)、乘法运算 (×)、除法运算 (÷) | ❌ 科学计算（三角函数、对数、幂运算等） |
| ✅ 整数运算、浮点数运算 | ❌ 进制转换 |
| ✅ 边界条件测试（除零、最大值、最小值、精度溢出） | ❌ 表达式解析（多运算符优先级） |
| ✅ 结果显示格式（精度控制、四舍五入） | ❌ 历史记录功能 |
| ✅ 连续运算支持（左到右顺序计算） | ❌ 表达式语法高亮 |

### 1.3 关键假设与前置说明

| # | 假设条件 | 依据 |
|---|---------|-----|
| 1 | 运算顺序：**左到右顺序计算**，不遵循数学运算符优先级 | 基础计算器通用设计 |
| 2 | 输入方式：数字键 + 运算符键 + 等号 | 传统计算器交互 |
| 3 | 最大显示位数：15 位有效数字 | 行业通用标准 |
| 4 | 浮点精度：IEEE 754 双精度 | 编程语言通用标准 |
| 5 | 溢出处理：显示 "E" 或 "数值溢出" | 通用计算器反馈机制 |
