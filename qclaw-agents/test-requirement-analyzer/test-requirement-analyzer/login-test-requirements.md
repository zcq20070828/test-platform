# 用户登录功能测试需求分析

> 分析时间：基于专业需求分析方法论 + 测试知识库
> 分析方法：MoSCoW优先级排序、Gherkin验收标准

---

## 一、需求概述

**功能描述**：用户登录功能是系统的身份认证入口，支持用户通过账号密码、验证码、第三方认证等方式完成身份验证并获取系统访问权限。

**业务价值**：登录是所有业务操作的入口，其安全性直接影响整个系统的数据安全和用户体验。

---

## 二、利益相关者识别

| 角色 | 关注点 |
|------|--------|
| **最终用户** | 登录便捷性、忘记密码找回、异常提示清晰 |
| **业务运营** | 登录成功率、异常登录监控、用户活跃度数据 |
| **安全合规** | 身份认证安全、密码策略、暴力破解防护、数据加密 |
| **技术团队** | 接口性能、会话管理、第三方集成复杂度 |

## 四、测试功能点拆解

### 4.1 界面层测试

| 测试类别 | 测试功能点 |
|----------|------------|
| 输入验证 | • 用户名为空校验<br>• 密码为空校验<br>• 账号格式校验（邮箱/手机号/用户名规则）<br>• 密码格式校验（长度、字符类型） |
| 交互体验 | • 输入框焦点切换<br>• 密码显示/隐藏切换<br>• 登录按钮加载状态<br>• 表单自动填充兼容性 |

### 4.2 业务逻辑测试

| 测试场景 | 输入条件 | 预期结果 |
|----------|----------|----------|
| 正确登录 | 正确账号+正确密码 | 登录成功，跳转首页，生成Token |
| 错误密码 | 正确账号+错误密码 | 提示"密码错误"，剩余N次机会 |
| 账号不存在 | 未注册账号 | 提示"账号不存在" |
| 未激活账号 | 已注册但未激活 | 提示"请先激活账号" |
| 密码过期 | 密码超过有效期 | 提示修改密码 |
| 并发登录 | 同一账号多设备登录 | 按策略处理（踢出/允许） |

### 4.3 安全测试要点

**暴力破解防护：**
- 同一IP短时间内多次失败 → 验证码/冷却
- 同一账号连续失败 → 锁定账号
- 密码字典攻击防护 → 密码强度策略

**会话安全：**
- Token有效期内盗用 → HTTPS传输
- Session fixation → 登录后刷新SessionID
- CSRF攻击 → 校验Token

**数据安全：**
- 密码传输加密 → HTTPS
- 密码存储加密 → 哈希+盐
- 日志脱敏 → 不记录明文密码

## 五、非功能性需求

### 5.1 性能指标

| 指标 | 目标值 |
|------|--------|
| 登录响应时间 | ≤ 2秒 |
| 并发登录能力 | ≥ 500/秒 |
| 接口响应时间 | ≤ 500ms |

### 5.2 兼容性要求

- **浏览器**：Chrome/Firefox/Safari/Edge 最新两个版本
- **移动端**：iOS 12+/Android 8+
- **网络**：2G/3G/4G/5G/WiFi

### 5.3 可用性要求

- 系统正常运行时登录成功率 ≥ 99.9%
- 登录页面可访问性符合 WCAG 2.1 AA 标准

## 六、验收标准（Given-When-Then）

### 场景1：正常使用账号密码登录

```
Given 用户已注册且账号处于正常状态
When 用户输入正确账号和密码
Then 系统显示登录成功，跳转至首页或上次访问页面
And 生成有效会话Token
And 记录登录时间和IP地址
```

### 场景2：密码错误被锁定

```
Given 用户账号处于正常状态
When 用户连续输入错误密码5次
Then 系统锁定该账号30分钟
And 发送账号锁定通知邮件/短信
```

### 场景3：异地异常登录

```
Given 用户上次登录地点在上海
When 用户尝试从非常用地点（如海外）登录
Then 系统发送异地登录预警通知
And 可选：要求额外验证
```

### 场景4：密码强度校验

```
Given 用户在注册或修改密码
When 密码不符合强度要求（少于8位、不含大小写字母等）
Then 系统提示密码强度不足
And 拒绝提交
```

## 八、风险识别与缓解

| 风险项 | 风险等级 | 缓解措施 |
|--------|----------|----------|
| 暴力破解 | 🔴 高 | 失败次数限制 + 验证码 + IP限流 |
| 会话劫持 | 🔴 高 | HTTPS + HttpOnly Cookie + Token轮换 |
| 密码明文传输 | 🔴 高 | 强制HTTPS + 前端加密 |
| 社会工程攻击 | 🟡 中 | 安全意识培训 + 异常检测 |
| 第三方登录泄漏 | 🟡 中 | OAuth安全配置 + 数据隔离 |
