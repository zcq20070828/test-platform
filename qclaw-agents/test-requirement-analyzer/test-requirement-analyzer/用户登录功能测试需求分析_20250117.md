## 五、关键验收标准（Given-When-Then）

### 场景1：正常登录
```gherkin
Given 用户在登录页面
And 用户已注册账号 "testuser" 密码 "Test@123"
When 用户输入账号 "testuser" 和密码 "Test@123"
And 点击登录按钮
Then 系统返回 HTTP 200
And 用户跳转至首页
And 登录状态保存成功
```

### 场景2：密码错误
```gherkin
Given 用户在登录页面
And 用户已注册账号 "testuser"
When 用户输入账号 "testuser" 和错误密码 "wrongpwd"
And 点击登录按钮
Then 系统返回提示 "账号或密码错误"
And 登录失败次数 +1
```

### 场景3：连续失败锁定
```gherkin
Given 用户在登录页面
And 用户已连续失败 5 次
When 用户再次输入错误密码
Then 系统提示 "登录失败次数过多，账号已锁定30分钟"
```

### 场景4：会话超时
```gherkin
Given 用户已登录成功
And 系统设置会话超时时间为 30 分钟
When 用户超过 30 分钟未操作
Then 系统自动退出登录
And 提示 "会话已过期，请重新登录"
```

## 六、风险识别与缓解措施

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 暴力破解攻击 | 账号被盗用 | 失败次数限制 + 验证码 + IP限制 |

| 撞库攻击 | 批量账号泄露 | 异常登录检测 + 多因素认证 |
