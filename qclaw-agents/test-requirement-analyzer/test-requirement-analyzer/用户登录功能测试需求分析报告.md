| 属性 | 内容 |
|------|------|

| **功能模块** | 用户认证系统 - 登录模块 |

## 一、需求概述

### 1.1 业务背景

用户登录是系统安全的第一道防线，也是用户使用系统的入口功能。登录功能的完整性和安全性直接影响用户体验和系统安全。

### 1.2 利益相关者

| 角色 | 关注点 |
|------|--------|
| **终端用户** | 登录便捷性、操作效率、密码找回便利性 |
| **业务负责人** | 登录转化率、用户留存、安全合规 |
| **开发团队** | 实现复杂度、技术可行性 |
| **安全团队** | 防护机制、漏洞风险、数据安全 |
| **运维团队** | 性能稳定性、日志可追溯性 |

### REQ-001：基础账号密码登录

**需求描述**：用户可通过账号（手机号/邮箱/用户名）和密码完成身份认证并登录系统。

#### 用户故事拆解

| 用户故事ID | 描述 | 优先级 |
|-----------|------|--------|
| US-001.1 | 作为普通用户，我需要输入正确的账号密码登录系统 | Must |
| US-001.2 | 作为新用户，我需要知道登录入口位置 | Must |
| US-001.3 | 作为普通用户，我需要在登录失败时看到明确的错误提示 | Must |
| US-001.4 | 作为普通用户，我需要在登录成功时跳转到指定页面 | Must |

#### 功能测试点

| 测试点ID | 测试场景 | 输入数据 | 预期结果 | 优先级 |
|----------|----------|----------|----------|--------|
| TC-001.1 | 正确的账号密码组合登录 | 有效账号 + 正确密码 | 登录成功，跳转首页/指定页 | P0 |
| TC-001.2 | 错误的密码登录 | 有效账号 + 错误密码 | 提示"用户名或密码错误"，不泄露具体是账号还是密码有误 | P0 |
| TC-001.3 | 不存在的账号登录 | 未注册账号 + 任意密码 | 提示"用户名或密码错误" | P0 |
| TC-001.4 | 账号密码均为空登录 | 空账号 + 空密码 | 提示"请输入账号"、"请输入密码" | P0 |
| TC-001.5 | 账号为空，密码正确 | 空账号 + 正确密码 | 提示"请输入账号" | P1 |
| TC-001.6 | 账号正确，密码为空 | 有效账号 + 空密码 | 提示"请输入密码" | P1 |
| TC-001.7 | 账号格式验证-手机号 | 手机号格式 | 格式正确可提交 | P1 |
| TC-001.8 | 账号格式验证-邮箱 | 邮箱格式 | 格式正确可提交 | P1 |
| TC-001.9 | 账号包含特殊字符 | 特殊字符账号 | 提示格式错误或按字符串处理 | P2 |
| TC-001.10 | 密码大小写敏感性 | 正确密码的大小写变体 | 严格区分大小写 | P0 |
| TC-001.11 | 密码前后空格处理 | 密码带前后空格 | 应严格匹配或提示格式错误 | P1 |
| TC-001.12 | 账号输入最大长度限制 | 超长字符串 | 超过限制不可输入或提示 | P1 |
| TC-001.13 | 密码输入最大长度限制 | 超长字符串 | 超过限制不可输入或提示 | P1 |
| TC-001.14 | Enter键快捷登录 | 焦点在密码框，按Enter | 触发登录操作 | P2 |
| TC-001.15 | 登录按钮点击反馈 | 快速连续点击 | 只触发一次登录请求 | P1 |

#### 验收标准（Given-When-Then）

```
场景1: 正常登录
Given 用户已注册，账号为 "test@example.com"，密码为 "Pass1234"
When 用户在登录页输入正确账号和密码并点击"登录"按钮
Then 系统验证成功，返回登录态，跳转到首页，提示"登录成功"

场景2: 密码错误
Given 用户已注册，账号为 "test@example.com"，密码为 "Pass1234"
When 用户输入正确账号但密码为 "WrongPass"
Then 系统提示"用户名或密码错误"，不跳转到首页，密码框清空

场景3: 空输入提交
Given 用户在登录页
When 用户不输入任何内容直接点击"登录"
Then 系统提示"请输入账号"和"请输入密码"，不发送登录请求
```

### REQ-002：登录状态与会话管理

**需求描述**：管理用户登录后的会话状态，包括会话创建、保持、失效和退出。

#### 功能测试点

| 测试点ID | 测试场景 | 预期结果 | 优先级 |
|----------|----------|----------|--------|
| TC-002.1 | 登录成功创建Session | 登录后生成有效Session，SessionID写入Cookie | P0 |
| TC-002.2 | Session有效期验证 | 30分钟无操作后Session过期，需重新登录 | P0 |
| TC-002.3 | Session过期后访问受保护页面 | 跳转回登录页或提示登录 | P0 |
| TC-002.4 | 正常退出登录 | Session销毁，Cookie清除，跳转登录页 | P0 |
| TC-002.5 | 浏览器关闭后重新打开 | Session保持（若勾选记住我）或失效 | P1 |
| TC-002.6 | 多标签页登录状态同步 | 一个标签退出，其他标签同步更新状态 | P2 |
| TC-002.7 | 同一账号多处登录 | 踢出旧会话或允许并发（按业务策略） | P1 |
| TC-002.8 | 登录状态Token/JWT有效性 | Token未过期可正常访问API | P0 |

#### 验收标准

```
Given 用户已成功登录并获得有效Session
When 用户在30分钟内有任意操作（点击、输入等）
Then Session有效期自动延长

Given 用户已成功登录并获得有效Session
When 用户连续30分钟无任何操作
Then Session过期，用户再次访问系统时跳转登录页

Given 用户已登录
When 用户点击"退出登录"按钮
Then 销毁服务端Session，清除客户端Cookie，跳转至登录页
```

**需求描述**：用户遗忘密码时，通过身份验证流程重置密码。

#### 功能测试点

| 测试点ID | 测试场景 | 输入数据 | 预期结果 | 优先级 |
|----------|----------|----------|----------|--------|
| TC-003.1 | 正常发送验证码-手机 | 已注册手机号 | 收到验证码短信 | P0 |
| TC-003.2 | 正常发送验证码-邮箱 | 已注册邮箱 | 收到验证码邮件 | P0 |
| TC-003.3 | 未注册账号发送验证码 | 未注册手机号/邮箱 | 提示"该账号未注册"或统一提示"验证码已发送" | P1 |
| TC-003.4 | 验证码有效期验证 | 输入过期验证码 | 提示"验证码已过期，请重新获取" | P0 |
| TC-003.5 | 验证码错误次数限制 | 连续输入错误验证码 | 提示错误次数，锁定一段时间 | P1 |
| TC-003.6 | 重置密码成功 | 新密码符合规范 | 提示"密码重置成功"，可用新密码登录 | P0 |
| TC-003.7 | 新密码与原密码相同 | 新密码=原密码 | 提示"新密码不能与原密码相同" | P1 |
| TC-003.8 | 新密码格式验证 | 弱密码（太短/太简单） | 提示密码强度不足 | P1 |
| TC-003.9 | 确认密码不匹配 | 新密码≠确认密码 | 提示两次密码输入不一致 | P0 |
| TC-003.10 | 重置链接/验证码仅可使用一次 | 使用过的链接/验证码 | 提示已使用，请重新获取 | P0 |

#### 验收标准

```
场景: 通过手机验证码重置密码
Given 用户已注册，手机号为 "13800138000"
When 用户点击"忘记密码"，输入手机号，获取验证码并填写正确的新密码
Then 系统验证通过，密码重置成功，用户可使用新密码登录

场景: 验证码过期
Given 用户获取了验证码
When 等待验证码超过5分钟有效期后提交
Then 系统提示"验证码已过期，请重新获取"

场景: 验证码错误超限
Given 用户连续3次输入错误验证码
When 用户第4次输入
Then 系统提示"验证码错误次数过多，请30分钟后重试"
```

### REQ-004：安全防护机制 ⭐核心

**需求描述**：防护登录功能免受暴力破解、注入攻击、会话劫持等安全威胁。

#### 安全测试点

##### 4.1 密码安全

| 测试点ID | 测试场景 | 测试方法 | 预期结果 | 优先级 |
|----------|----------|----------|----------|--------|
| SEC-001 | 密码传输加密 | 抓包查看登录请求 | 密码字段使用HTTPS加密传输，敏感字段加密 | P0 |
| SEC-002 | 密码存储加密 | 代码/数据库审查 | 数据库存储密码哈希值（非明文），使用bcrypt/scrypt/argon2 | P0 |
| SEC-003 | 密码复杂度校验 | 尝试弱密码 | 系统拒绝低于复杂度要求的密码 | P1 |
| SEC-004 | 密码历史记录 | 设置新密码为最近使用的密码 | 提示不能使用最近5次使用过的密码 | P2 |

##### 4.2 暴力破解防护

| 测试点ID | 测试场景 | 测试方法 | 预期结果 | 优先级 |
|----------|----------|----------|----------|--------|
| SEC-005 | 登录失败次数限制 | 连续输入错误密码5次 | 账号临时锁定，提示"登录失败次数过多，请X分钟后重试" | P0 |
| SEC-006 | 锁定时间递增 | 多次触发锁定 | 锁定时间逐次递增（5min → 30min → 永久需人工解锁） | P1 |
| SEC-007 | IP登录失败限制 | 同一IP连续失败登录 | IP临时封禁，提示"访问频率过快" | P1 |
| SEC-008 | 验证码/人机验证触发 | 连续登录失败2-3次后 | 出现图形验证码/滑动验证/人机验证 | P0 |
| SEC-009 | 验证码正确性验证 | 输入错误图形验证码 | 提示验证码错误，不允许提交登录 | P0 |
| SEC-010 | 验证码刷新功能 | 点击刷新按钮 | 生成新的验证码图片 | P2 |

##### 4.3 SQL注入防护

| 测试点ID | 测试用例 | 预期结果 | 优先级 |
|----------|----------|----------|--------|
| SEC-011 | 账号输入: `' OR '1'='1` | 查询不到结果或报错被拦截 | P0 |
| SEC-012 | 账号输入: `admin' --` | 查询不到结果 | P0 |
| SEC-013 | 密码输入: `' OR '1'='1` | 提示用户名或密码错误 | P0 |
| SEC-014 | 特殊SQL字符: `; DROP TABLE users;--` | 不执行危险操作 | P0 |

##### 4.4 XSS跨站脚本防护

| 测试点ID | 测试用例 | 预期结果 | 优先级 |
|----------|----------|----------|--------|
| SEC-015 | 账号输入: `<script>alert('xss')</script>` | 不执行脚本，特殊字符被转义或过滤 | P0 |
| SEC-016 | 账号输入: `javascript:alert('xss')` | 不执行脚本 | P0 |
| SEC-017 | 密码输入: `<img src=x onerror=alert(1)>` | 不执行脚本 | P1 |

##### 4.5 会话安全

| 测试点ID | 测试场景 | 预期结果 | 优先级 |
|----------|----------|----------|--------|
| SEC-018 | SessionID随机性 | 检查SessionID格式 | 使用足够长度和熵的随机字符串 | P0 |
| SEC-019 | Session Fixation防护 | 登录前后SessionID变化 | 登录后生成新的SessionID | P0 |
| SEC-020 | Cookie安全属性 | 检查Cookie配置 | HttpOnly、Secure、SameSite属性正确设置 | P0 |
| SEC-021 | 会话超时 | 长时间无操作 | 会话自动过期 | P0 |

##### 4.6 其他安全措施

| 测试点ID | 测试场景 | 预期结果 | 优先级 |
|----------|----------|----------|--------|
| SEC-022 | CSRF Token验证 | 登录请求携带CSRF Token | 有效Token才允许登录 | P1 |
| SEC-023 | 敏感操作日志 | 登录、退出、密码重置 | 记录操作时间、IP地址、结果 | P0 |
| SEC-024 | 异常登录告警 | 异地登录/异常时间登录 | 触发安全告警（邮件/短信通知） | P2 |

#### 安全验收标准

```
Given 攻击者尝试使用 SQL 注入Payload "admin' OR '1'='1"
When 提交登录请求
Then 系统不执行恶意SQL，返回通用的"用户名或密码错误"

Given 攻击者在5分钟内连续输入错误密码10次
When 再次尝试登录
Then 账号被锁定30分钟，显示"登录失败次数过多，请30分钟后重试"

Given 用户登录成功后
When 检查Cookie属性
Then HttpOnly=true, Secure=true, SameSite=Strict/Lax

Given 用户登录成功
When 服务端返回Session
Then SessionID为加密随机字符串，长度>=32字符
```

### REQ-007：性能需求

**需求描述**：登录功能响应及时，能承受预期并发压力。

#### 响应时间测试

| 测试点ID | 测试场景 | 性能指标 | 目标值 | 优先级 |
|----------|----------|----------|--------|--------|
| PERF-001 | 正常登录 | 接口响应时间 | ≤ 1秒 | P0 |
| PERF-002 | 登录失败（快速返回） | 接口响应时间 | ≤ 500ms | P1 |
| PERF-003 | 发送验证码 | 接口响应时间 | ≤ 3秒（含短信延迟，但接口≤1s） | P1 |
