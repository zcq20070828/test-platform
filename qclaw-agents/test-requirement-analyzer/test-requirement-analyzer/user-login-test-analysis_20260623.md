## 1. 功能概述

用户登录是系统的核心入口功能，负责验证用户身份并授予系统访问权限。登录功能的安全性和稳定性直接影响整个系统的可用性和用户信任度。

### 1.1 核心模块划分

```
┌─────────────────────────────────────────────┐
│                登录功能模块图                    │
├─────────────────────────────────────────────┤
│  ┌─────────┐ ┌──────────┐ ┌───────────┐   │
│  │认证入口  │ │身份验证   │ │会话管理   │   │
│  ├─────────┤ ├──────────┤ ├───────────┤   │
│  │·用户名   │ │·密码校验  │ │·Token生成 │   │
│  │  密码    │ │·验证码校验│ │·Session   │   │
│  │·手机号   │ │·第三方    │ │  维护     │   │
│  │  验证码  │ │  OAuth   │ │·Cookie    │   │
│  │·第三方   │ │  认证     │ │  管理     │   │
```

### 1.2 支持的登录方式

| 登录方式 | 认证要素 | 典型场景 |
|---------|---------|---------|
| 用户名+密码 | 知识要素（知道什么） | PC端、Web端 |
| 手机号+验证码 | 拥有要素（拥有什么） | 移动端、快速登录 |
| 邮箱+密码 | 知识要素 | 国际用户、管理后台 |
| 第三方OAuth（微信/QQ/微博/GitHub等） | 联合认证 | 社交登录、首次用户 |
| 生物识别（指纹/面部） | 固有要素（是什么） | 移动端、已登录设备 |
| 扫码登录 | 双设备认证 | PC端快捷登录 |
| SSO单点登录 | 统一认证 | 企业环境、多系统 |

## 2. 核心业务流程

### 2.1 正常登录流程（用户名密码）

```
[用户打开登录页] → [输入用户名/密码] → [填写验证码(可选)] 
→ [点击"登录"] → [前端校验] → [发送登录请求] 
→ [后端校验] → [生成Token/Session] → [返回登录成功]
→ [跳转至首页/目标页]
```

### 2.2 登录扩展流程

| 流程 | 路径 | 触发条件 |
|------|------|---------|
| **忘记密码** | 点击"忘记密码"→验证身份→重置密码→重新登录 | 用户遗忘密码 |
| **首次登录** | 注册后首次登录→可能需要强制修改初始密码 | 管理员创建账号 |
| **自动登录** | 保存凭证→启动应用→静默登录 | 开启"记住我" |
| **多设备登录** | 已登录设备→新设备登录→旧设备被踢(策略可选) | 安全策略决定 |
| **异地登录** | 检测IP变更→触发安全验证→验证通过才允许 | 安全风险检测 |
| **长期未登录** | 超30天未登录→身份重新验证 | 账户保护策略 |

### 2.3 登录状态生命周期

```
注册/首次登录
    │
    ▼
   ┌──────────────────────┐
   │    未登录状态          │
   │ (Anonymous/Guest)     │
   └────────┬─────────────┘
            │ 输入凭证 + 认证成功
            ▼
   ┌──────────────────────┐       ┌───────────────────┐
   │    已登录状态          │──────▶│  Token刷新延长     │
   │ (Authenticated)       │◀──────│  (Sliding Window) │
   └────────┬─────────────┘       └───────────────────┘
            │
            ├── 主动登出 ─────▶ ┌─────────────┐
            ├── Session超时 ──▶ │  已登出状态   │
            ├── 关闭浏览器 ───▶ │  (清理凭证)   │
            └── Token失效 ───▶ └─────────────┘
```

## 4. 非功能需求

### 4.1 性能需求

| 编号 | 需求项 | 目标值 | 说明 |
|------|--------|-------|------|
| N01 | 登录响应时间（P50） | ≤ 800ms | 从点击登录到返回登录成功 |
| N02 | 登录响应时间（P99） | ≤ 3s | 极端情况下的最大可接受时间 |
| N03 | 并发用户支持 | ≥ 1000 QPS | 登录接口的处理能力 |
| N04 | 验证码获取时间 | ≤ 1s | 滑块/图形验证码加载速度 |
| N05 | Token生成时间 | ≤ 200ms | JWT/自定义Token生成性能 |
| N06 | 资源消耗 | CPU ≤ 40%, 内存 ≤ 256MB | 单节点登录服务资源占用 |
| N07 | 数据库查询 | 登录查询 ≤ 50ms | 用户信息查询DB延迟 |

### 4.2 安全需求

| 编号 | 需求项 | 要求 |
|------|--------|------|
| NS01 | 密码传输加密 | 前端使用RSA/国密SM2加密密码后传输，避免明文 |
| NS02 | HTTPS强制 | 所有登录请求必须走HTTPS，禁止HTTP |
| NS03 | SQL注入防护 | 所有输入参数使用参数化查询/ORM |
| NS04 | XSS防护 | 输入输出编码，禁止反射型XSS |
| NS05 | CSRF防护 | 使用CSRF Token或SameSite Cookie |
| NS06 | 密码存储 | bcrypt/argon2/scrypt加盐哈希，禁止MD5/SHA1 |
| NS07 | Token安全 | JWT签名+过期+不在URL中传递 |
| NS08 | 敏感信息保护 | 错误信息不暴露用户是否存在、密码规则等 |
| NS09 | 暴力破解防护 | 登录失败限流+验证码+账号锁定 |
| NS10 | 日志审计 | 记录所有登录尝试（成功/失败）及元数据 |

### 4.3 可用性需求

| 编号 | 需求项 | 目标值 |
|------|--------|-------|
| NA01 | 系统可用性 | ≥ 99.9%（月停机≤43分钟） |
| NA02 | 登录服务容灾 | 多机房部署，单机房故障自动切换 |
| NA03 | 验证码服务可用性 | ≥ 99.99%（第三方验证码服务SLA） |
| NA04 | 维护窗口影响 | 维护期间提前公告，影响时间≤15分钟 |

### 4.4 兼容性需求

| 编号 | 需求项 | 要求 |
|------|--------|------|
| NC01 | 浏览器兼容 | Chrome(最新2版)、Firefox(最新2版)、Safari(最新2版)、Edge(最新2版) |
| NC02 | 移动端兼容 | iOS Safari 14+、Android Chrome 90+ |
