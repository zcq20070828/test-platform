## 二、测试功能点拆解

### 2.1 功能性测试（核心）

| 测试项 | 测试场景 | 优先级 |
|--------|---------|--------|
| **正常登录** | 正确用户名+正确密码 | P0 |
| **账号验证** | 不存在的账号、已注销账号、未激活账号 | P0 |
| **密码验证** | 错误密码、为空密码、含特殊字符密码 | P0 |
| **格式校验** | 手机号格式、邮箱格式、长度限制 | P1 |
| **验证码** | 正确验证码、错误验证码、过期验证码、重复使用 | P0 |
| **第三方登录** | 微信/支付宝/QQ登录授权、取消授权、绑定账号 | P2 |
| **记住密码** | 记住密码功能、自动填充、退出后状态 | P1 |
| **找回密码** | 通过手机/邮箱找回、重置密码流程 | P1 |
| **登录限制** | 账号锁定（多次错误）、黑名单账号 | P1 |
| **并发登录** | 同一账号多设备登录、踢出机制 | P2 |

### 2.2 安全测试

| 测试项 | 测试场景 | 优先级 |
|--------|---------|--------|
| **SQL注入** | 输入框注入SQL语句 | P0 |
| **XSS攻击** | 输入框注入JS脚本 | P0 |
| **暴力破解** | 多次尝试密码、锁定机制 | P0 |
| **会话安全** | Token有效期、登出后Token失效 | P1 |
| **数据加密** | 密码传输加密、存储加密 | P0 |
| **越权访问** | 登录后访问其他用户数据 | P1 |

### 2.3 性能测试

| 测试项 | 测试指标 | 优先级 |
|--------|---------|--------|
| **响应时间** | 登录接口 < 200ms | P1 |
| **并发能力** | 支持500并发用户登录 | P2 |
| **压力测试** | 峰值流量下的稳定性 | P2 |

### 2.4 兼容性测试

| 测试项 | 测试场景 | 优先级 |
|--------|---------|--------|
| **浏览器兼容** | Chrome、Safari、Firefox、Edge | P1 |
| **移动端兼容** | iOS、Android主流机型 | P1 |
| **分辨率适配** | 不同屏幕分辨率显示 | P2 |

### 2.5 用户体验测试

| 测试项 | 测试场景 | 优先级 |
|--------|---------|--------|
| **提示信息** | 错误提示友好、引导清晰 | P2 |
| **交互流程** | 操作流畅、无卡顿 | P2 |
| **界面展示** | 布局合理、美观度 | P3 |

## 三、优先级排序（MoSCoW方法）

### Must Have（必须有）
- ✅ 正常登录流程
- ✅ 账号密码校验
- ✅ 验证码功能
- ✅ 安全防护（SQL注入、XSS、暴力破解）

### Should Have（应该有）
- 🔹 第三方登录
- 🔹 找回密码
- 🔹 性能测试
- 🔹 记住密码

### Could Have（可以有）
- 🔸 并发登录测试
- 🔸 兼容性测试
- 🔸 用户体验优化测试

### Won't Have（暂不考虑）
- ⏸️ 界面美化测试（P3优先级，非核心功能）

## 四、验收标准（Given-When-Then）

### 4.1 正常登录
```
Given 用户在登录页面
When 输入正确的用户名和密码并点击登录
Then 登录成功，跳转到首页，Token有效
```

### 4.2 账号锁定
```
Given 用户输入错误密码3次
When 再次尝试登录
Then 账号被锁定，提示"请稍后重试"
```

### 4.3 未登录访问
```
Given 用户未登录状态
When 访问需登录的页面
Then 跳转到登录页面，登录后返回原页面
```

### 4.4 安全验证
```
Given 用户在登录页面
When 输入包含SQL注入的字符串
Then 系统拦截并提示"输入不合法"
```
