## 一、接口定义

### 1.1 接口基本信息
- **接口路径**：`POST /api/v1/auth/login`
- **接口描述**：用户登录认证接口
- **Content-Type**：`application/json`

### 1.2 请求参数

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| loginType | String | 是 | 登录方式：password/phoneCode | "password" |
| account | String | 是 | 账号（手机号/邮箱/用户名） | "13800138001" |
| password | String | 条件 | 密码（loginType=password时必填） | "Test@123456" |
| phoneCode | String | 条件 | 验证码（loginType=phoneCode时必填） | "123456" |
| countryCode | String | 否 | 国家码，默认"86" | "86" |

### 1.3 响应参数

**成功响应（200）：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expiresIn": 7200,
    "userId": "1234567890",
    "nickname": "张三"
  }
}
```

**失败响应（400/401/403/429）：**
```json
{
  "code": 401,
  "message": "账号或密码错误",
  "data": null
}
```

## 六、附录

### 6.1 HTTP状态码说明
- **200 OK**：请求成功
- **400 Bad Request**：请求参数错误
- **401 Unauthorized**：认证失败（账号或密码错误）
- **403 Forbidden**：账号被禁用或注销
- **429 Too Many Requests**：请求频率超限

### 6.2 错误码说明
| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 400 | 参数校验失败 |
| 401 | 认证失败 |
| 403 | 账号状态异常 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |
