## 五、缺陷预防与风险评估

### 5.1 高风险场景

| 风险项 | 触发用例 | 预防措施 |
|--------|---------|---------|
| SQL注入漏洞 | SEC-005 | 参数化查询 + 安全审计 |
| XSS攻击 | SEC-006 | 输入过滤 + 输出编码 |
| 暴力破解 | SEC-001, SEC-007 | 失败锁定 + 验证码 + 限流 |
| Session劫持 | SEC-008, STATE-004 | HTTPS + HttpOnly + Secure |
| 并发登录冲突 | LOGIN-012 | Session管理策略明确 |

### 5.2 测试注意事项

1. **安全测试需授权**: SQL注入、XSS等渗透测试需获得授权
2. **第三方登录依赖外部环境**: 需要真实微信/支付宝账号或Mock服务
3. **验证码测试需真实手机号**: 需准备测试手机卡或短信平台
4. **性能测试需独立环境**: 避免影响线上服务
