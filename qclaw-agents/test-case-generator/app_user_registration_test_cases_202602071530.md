### 模块一：手机号注册（P0 核心流程）

#### TC_REG_PHONE_001 正常手机号注册成功

**测试类型**: 功能测试  
**功能模块**: 用户注册  
**子功能**: 手机号注册  
**用例级别**: P0  
**预置条件**: 
1. APP 已安装且网络正常
2. 手机号未注册过
3. 短信网关可用

**测试步骤**:
1. 打开 APP，进入注册页面
2. 选择"手机号注册"方式
3. 输入未注册的手机号（如 13800138000）
4. 点击"获取验证码"按钮
5. 接收短信验证码并输入（6位数字）
6. 设置密码（符合强度要求）
7. 勾选"用户协议"和"隐私政策"
8. 点击"注册"按钮

**预期结果**:
1. 验证码倒计时 60 秒开始
2. 收到6位数字短信验证码
3. 密码强度实时显示（强）
4. 注册成功，跳转至首页/引导页
5. 数据库新增用户记录
6. 返回 token，自动登录状态

**实际结果**: 待执行

## ⚠️ 测试风险与建议

### 高风险项

1. **短信网关依赖**：短信验证码功能依赖第三方服务，需准备测试专用账号
2. **第三方登录依赖**：微信/Apple登录需要真实设备测试，模拟器可能无法完整测试

4. **安全测试深度**：SQL注入、XSS等需要专业安全测试工具扫描

### 测试建议

1. **自动化优先级**：P0+P1 用例优先实现自动化（使用 Appium/Uiautomator2）

4. **Mock 服务**：对于第三方依赖（短信网关、邮件服务），建议使用 Mock 服务加速测试

## 附录：测试用例方法论应用说明

### 等价类划分法应用

| 输入项 | 有效等价类 | 无效等价类 |
|--------|-----------|-----------|
| 手机号 | 11位合法手机号 | 少于11位、多于11位、含字母、含特殊字符 |
| 邮箱 | 包含@和域名的合法邮箱 | 缺少@、缺少域名、含特殊字符 |
| 密码 | 8-20位，含大小写+数字+特殊字符 | 少于8位、不含特殊字符、不含数字 |
| 验证码 | 6位数字 | 少于6位、多于6位、含字母、已过期 |

### 边界值分析法应用

| 输入项 | 边界值 |
|--------|--------|
| 手机号长度 | 10位、11位、12位 |
| 密码长度 | 7位、8位、20位、21位 |
| 验证码长度 | 5位、6位、7位 |
| 验证码有效期 | 4分59秒、5分钟、5分01秒 |

### 场景法应用

**主流程场景**：
1. 用户打开APP → 点击注册 → 输入手机号 → 获取验证码 → 输入验证码 → 设置密码 → 勾选协议 → 注册成功

**分支流程场景**：
1. 用户输入已注册手机号 → 提示"已注册" → 跳转登录页
2. 用户输入错误验证码 → 提示"验证码错误" → 重新输入
3. 用户未勾选协议 → 提示"请勾选协议" → 禁止提交

**异常流程场景**：
1. 网络异常 → 提示"网络连接失败" → 保留填写信息
2. 短信网关异常 → 提示"验证码发送失败" → 提供重试按钮
