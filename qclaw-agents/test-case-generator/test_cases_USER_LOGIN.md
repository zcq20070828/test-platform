## 一、功能模块概述

| 模块名称 | 用户登录（USER_LOGIN） |
|---------|----------------------|
| 功能描述 | 用户通过用户名/密码或其他方式完成身份认证，系统验证合法性后建立会话 |
| 涉及接口 | 登录接口 `/api/auth/login`，验证码接口 `/api/auth/captcha`，登出接口 `/api/auth/logout` |
| 关联模块 | 用户管理、会话管理、权限管理、验证码服务 |
