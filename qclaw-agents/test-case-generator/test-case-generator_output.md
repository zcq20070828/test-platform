## 📝 测试用例设计方法论应用

### 等价类划分应用
- **账号字段**：有效等价类（已注册账号）、无效等价类（未注册、空、格式错误、超长）
- **密码字段**：有效等价类（符合强度）、无效等价类（纯数字、纯字母、过短、过长）
- **验证码字段**：有效等价类（正确）、无效等价类（错误、过期、空）

### 边界值分析应用
- **账号长度**：20位（上点）、21位（离点）
- **密码长度**：6位（下点）、5位（离下点）、20位（上点）、21位（离上点）
- **登录失败次数**：4次（可继续）、5次（触发锁定）、6次（锁定中）
- **验证码错误次数**：3次（最后机会）、4次（锁定）

### 场景分析法应用
- **基本流**：输入正确账号密码 → 登录成功
- **备选流1**：输入错误密码 → 提示错误
- **备选流2**：连续5次失败 → 账号锁定
- **备选流3**：验证码过期 → 重新获取
