# 登录功能测试用例

## 一、接口定义

| 项目 | 内容 |
|------|------|
| **模块** | 用户认证（AUTH） |
| **接口** | `POST /api/v1/auth/login` |
| **Content-Type** | `application/json` |

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| loginType | String | 是 | 登录方式：`password` / `phoneCode` |
| account | String | 是 | 账号（手机号/邮箱/用户名） |
| password | String | 条件 | 密码（loginType=password时必填） |
| phoneCode | String | 条件 | 验证码（loginType=phoneCode时必填） |
| countryCode | String | 否 | 国家码，默认`86` |

### 响应参数

**成功：**
```json
{ "code": 0, "message": "success", "data": { "token": "string", "refreshToken": "string", "expiresIn": 7200 } }
```

**失败：**
```json
{ "code": 401, "message": "账号或密码错误", "data": null }
```
