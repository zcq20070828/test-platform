## 一、模块概述

| 项目 | 内容 |
|------|------|
| 模块名称 | USER_LOGIN - 用户登录模块 |
| 功能描述 | 用户通过用户名/密码完成身份认证，系统验证合法性后建立会话并返回 Token/Session |
| 涉及接口 | `POST /api/auth/login`（登录）、`POST /api/auth/logout`（登出）、`GET /api/auth/captcha`（验证码） |
| 关联模块 | 用户管理、会话管理、权限管理、验证码服务、密码找回模块 |
| 登录方式 | 用户名+密码、手机号+验证码、邮箱+链接（按实际启用情况） |
