# 密码重置功能测试用例

## 任务目标
根据密码重置功能需求，生成1条标准化、可执行的测试用例。

## 设计方法
采用**场景法（主成功场景）**，覆盖密码重置的核心正常流程。

## 测试用例

| 字段 | 内容 |
|---|---|
| **用例编号** | TC-RESET-001 |
| **用例标题** | 正常流程：通过邮箱链接成功重置密码 |
| **优先级** | P0（核心流程） |
| **前置条件** | 1. 用户已注册并完成邮箱验证<br>2. 用户当前已登录且知道旧密码 |
| **测试步骤** | 1. 进入「设置 → 账户安全 → 修改密码」页面<br>2. 输入正确的当前密码<br>3. 点击「发送重置链接到邮箱」按钮<br>4. 切换到邮箱客户端，找到重置邮件<br>5. 点击邮件中的重置链接<br>6. 在重置页面输入符合规则的新密码（≥8位，含大小写+数字）<br>7. 再次输入相同的新密码确认<br>8. 点击「确认重置」按钮<br>9. 使用新密码重新登录 |
| **预期结果** | 1. 步骤3后页面提示"重置链接已发送"<br>2. 步骤5后跳转至重置密码页面<br>3. 步骤8后提示"密码重置成功"<br>4. 旧密码无法登录，新密码可正常登录<br>5. 所有已登录的其他设备被强制退出 |
| **测试数据** | 当前密码：Test@123<br>新密码：NewPass@456<br>注册邮箱：已验证的有效邮箱 |

## 结论
生成1条P0级核心流程测试用例，覆盖密码重置的完整正向路径。
