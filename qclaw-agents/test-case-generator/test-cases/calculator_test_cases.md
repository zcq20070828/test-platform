# 计算器功能测试用例

## 测试范围
- 加法运算（正数+正数、正数+负数、小数相加）
- 减法运算
- 乘法运算
- 除法运算（含除数为0异常场景）
- 连续运算
- 清零功能
- 边界值测试

## 用例规格说明
- **用例ID格式**：`CALC-{序号}`
- **优先级定义**：P0(核心功能/冒烟) > P1(主要功能) > P2(次要功能) > P3(边缘场景)
- **自动化可行性**：✅ 可自动化 / ⚡ 需人工
