# 测试用例文档

## 测试项目：用户登录功能

### 测试用例 1：正常登录

| 项目 | 内容 |
|------|------|
| 用例编号 | TC-LOGIN-001 |
| 用例名称 | 用户使用正确的用户名和密码登录 |
| 前置条件 | 1. 用户已注册账号<br>2. 用户处于未登录状态 |
| 测试步骤 | 1. 打开登录页面<br>2. 输入正确的用户名<br>3. 输入正确的密码<br>4. 点击"登录"按钮 |
| 预期结果 | 1. 登录成功<br>2. 跳转到首页<br>3. 显示用户信息 |
| 优先级 | 高 |
| 测试类型 | 功能测试 |

---

| 项目 | 内容 |
|------|------|
| 用例编号 | TC-LOGIN-002 |
| 用例名称 | 用户使用错误密码登录 |

| 测试步骤 | 1. 打开登录页面<br>2. 输入正确的用户名<br>3. 输入错误的密码<br>4. 点击"登录"按钮 |

| 测试类型 | 功能测试 |

### 测试用例 3：空用户名登录

| 项目 | 内容 |
|------|------|
| 用例编号 | TC-LOGIN-003 |
| 用例名称 | 用户名为空时尝试登录 |
| 前置条件 | 用户处于未登录状态 |
| 测试步骤 | 1. 打开登录页面<br>2. 不输入用户名<br>3. 输入任意密码<br>4. 点击"登录"按钮 |
| 预期结果 | 1. 登录按钮不可点击或<br>2. 提示"请输入用户名" |
| 优先级 | 中 |
| 测试类型 | 功能测试 |

---

### 测试用例 4：账号锁定

| 项目 | 内容 |
|------|------|
| 用例编号 | TC-LOGIN-004 |
| 用例名称 | 连续多次密码错误后账号锁定 |
| 前置条件 | 1. 用户已注册账号<br>2. 系统设置了账号锁定策略（如5次错误后锁定） |
| 测试步骤 | 1. 打开登录页面<br>2. 连续5次输入错误密码尝试登录 |
| 预期结果 | 1. 第5次失败后提示"账号已被锁定，请联系管理员"<br>2. 账号在一定时间内无法登录 |
| 优先级 | 中 |
| 测试类型 | 安全测试 |

---

### 测试用例 5：退出登录

| 项目 | 内容 |
|------|------|
| 用例编号 | TC-LOGIN-005 |
| 用例名称 | 用户正常退出登录 |
| 前置条件 | 用户已登录系统 |
| 测试步骤 | 1. 点击用户头像或菜单<br>2. 点击"退出登录"按钮<br>3. 确认退出 |
| 预期结果 | 1. 退出成功<br>2. 跳转到登录页面<br>3. 无法访问需要登录的页面 |
| 优先级 | 高 |
| 测试类型 | 功能测试 |

- 操作系统：Windows 10/11、macOS、Linux
- 网络环境：正常网络连接
