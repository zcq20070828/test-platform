# 登录功能测试用例

## 测试用例信息

| 字段 | 值 |
|------|-----|
| **用例编号** | TC-LOGIN-001 |
| **测试标题** | 正确用户名+正确密码登录成功 |
| **测试模块** | 登录功能 |
| **优先级** | P0 |
| **测试类型** | 功能测试 / 冒烟测试 |
| **预置条件** | 1. 被测应用已正常部署并运行<br>2. 数据库中已存在合法用户：用户名 `testuser`，密码 `P@ssw0rd123`<br>3. 用户未被锁定/禁用/删除 |

## 测试数据

| 字段 | 值 |
|------|-----|
| **用户名** | testuser |
| **密码** | P@ssw0rd123 |
| **验证码** | 无（或自动填充正确验证码） |

## 测试步骤

| 步骤 | 操作描述 | 预期结果 |
|------|----------|----------|
| 1 | 打开登录页面 | 登录页面成功加载，显示用户名/密码输入框及登录按钮 |
| 2 | 在用户名输入框中输入 `testuser` | 输入框正常显示输入内容，无异常提示 |
| 3 | 在密码输入框中输入 `P@ssw0rd123` | 密码框以掩码形式显示输入（如 *******） |
| 4 | 勾选"记住我"（如有此选项） | 复选框被选中 |
| 5 | 点击"登录"按钮 | 1. 登录按钮应短暂变为"登录中…"或显示 loading 状态<br>2. 页面发起 POST 登录请求（可抓包验证） |
| 6 | 等待系统响应 | 1. 登录成功后自动跳转至系统首页/仪表盘<br>2. URL 由 `/login` 切换至 `/dashboard`（或对应首页路由）<br>3. 页面右上角显示当前登录用户信息（`testuser`） |

## 预期结果（汇总）

1. ✅ 系统返回 200 状态码，登录成功
2. ✅ 自动跳转至系统首页/仪表盘，无报错提示
3. ✅ 首页正常加载，页面元素完整
4. ✅ 响应头中应返回认证 Token / Session Cookie（如 Set-Cookie: session_id=xxx）
5. ✅ 退出登录后再访问首页，应被重定向至登录页（Token/Session 已服务端持久化）

## 备注

- 本用例为 P0 冒烟测试用例，每次版本发布前必须执行通过
- 如果系统有验证码/二步验证，需在预置条件中说明绕过方式（如测试环境关闭验证码）
- 建议配合接口自动化断言：校验响应状态码、返回数据结构、Token 格式
