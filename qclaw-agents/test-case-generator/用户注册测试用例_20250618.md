# 用户注册功能测试用例

## 用例信息
- **用例编号**: TC_REG_001
- **用例名称**: 用户正常注册
- **优先级**: P0（高）
- **测试类型**: 功能测试

## 前置条件
1. 用户未注册过该系统
2. 注册页面可正常访问

## 测试步骤
1. 打开用户注册页面
2. 输入有效的用户名（如：testuser001）
3. 输入有效的邮箱地址（如：testuser001@example.com）
4. 输入符合规则的密码（如：Test@123456）
5. 确认密码与密码一致
6. 点击"注册"按钮

## 预期结果
1. 系统提示"注册成功"
2. 账号创建成功，数据写入数据库
3. 自动跳转至登录页面或首页
4. 用户可使用新账号正常登录

## 测试数据
- 用户名: testuser001
- 邮箱: testuser001@example.com
- 密码: Test@123456

## 备注
验证用户注册的基本功能流程，确保核心注册功能可用。
