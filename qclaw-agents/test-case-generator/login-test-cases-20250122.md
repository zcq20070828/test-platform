## 一、等价类划分

### 1. 用户名/邮箱等价类划分

| 等价类类型 | 输入条件 | 典型值 |
|-----------|---------|--------|
| **有效等价类** | 合法用户名（字母数字组合） | testuser01 |
| **有效等价类** | 合法邮箱格式 | user@example.com |
| **有效等价类** | 手机号格式 | 13800138000 |
| **无效等价类** | 空值 | (空) |
| **无效等价类** | 特殊字符 | test@user# |
| **无效等价类** | SQL注入字符 | ' OR '1'='1 |
| **无效等价类** | 超长字符串 | 超过系统限制长度 |
| **无效等价类** | 不存在的用户名 | nonexistent_user |

### 2. 密码等价类划分

| 等价类类型 | 输入条件 | 典型值 |
|-----------|---------|--------|
| **有效等价类** | 正确密码 | 与账号匹配的密码 |
| **无效等价类** | 空值 | (空) |
| **无效等价类** | 错误密码 | 与账号不匹配的密码 |
| **无效等价类** | 超长密码 | 超过系统限制长度 |
| **无效等价类** | SQL注入字符 | ' OR '1'='1 |

## 六、测试方法总结

### 等价类划分法应用
- 将用户名输入划分为：有效等价类（合法用户名、邮箱、手机号）和无效等价类（空值、特殊字符、SQL注入、不存在用户）
- 将密码输入划分为：有效等价类（正确密码）和无效等价类（空值、错误密码、超长密码、SQL注入）

### 边界值分析法应用
- 针对用户名长度限制（6-20字符），测试：5字符、6字符、7字符、19字符、20字符、21字符
- 针对密码长度限制（8-32字符），测试：7字符、8字符、9字符、31字符、32字符、33字符

### 其他测试方法论
- **错误推测法**：基于经验预测常见错误（SQL注入、XSS攻击）
- **场景法**：模拟用户完整登录流程
- **安全测试**：验证系统对恶意输入的防护能力
