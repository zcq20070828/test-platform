## 🎯 测试覆盖要点

### 1. 等价类划分
✅ 整数运算 (正数/零)  
✅ 小数运算 (纯小数/多位小数)  
✅ 负数运算 (负±正/负±负)  
✅ 零的特殊场景 (0÷n/0×n)  

### 2. 边界值测试
✅ 最大值边界 (999999999)  
✅ 最小值边界 (-999999999)  
✅ 精度边界 (浮点精度/小数位数)  
✅ 显示位数边界 (最大显示/科学计数法)  

### 3. 优先级测试
✅ 无括号运算 (同级/混合)  
✅ 单层括号 (改变优先级)  
✅ 多层嵌套括号 (2-5层)  
✅ 混合优先级 (括号+运算符)  

### 4. 操作功能测试
✅ 正负切换 (±按钮)  
✅ 清除功能 (C/AC)  
✅ 退格功能 (⌫/DEL)  
✅ 组合操作验证  

### 5. 异常场景测试
✅ 除零错误 (n÷0/0÷0)  
✅ 溢出错误 (最大值运算)  
✅ 非法输入 (括号不匹配/连续运算符)  
✅ 其他异常 (超长表达式/错误恢复)  

## 🚀 快速使用

### 运行测试

```bash
# 进入测试目录
cd calculator-ui-tests

# 安装依赖
npm install

# 安装浏览器
npx playwright install

# 运行所有测试
npm test

# 或使用交互式脚本
./run-tests.sh
```

### 查看测试报告

```bash
npm run test:report
```

### 调试测试

```bash
# 可视化模式
npm run test:ui

# 调试模式
npm run test:debug
```

## 🔧 定制化配置

### 修改测试目标URL

编辑 `playwright.config.js`:

```javascript
use: {
  baseURL: 'http://your-calculator-url.com',
}
```

### 修改元素定位器

编辑 `pages/CalculatorPage.js`,更新定位器:

```javascript
this.digitButtons = {
  '0': page.locator('你的选择器'),
};
```
