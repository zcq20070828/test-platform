# Task Artifact: 计算器测试用例生成

## Objective
根据需求分析结果，为计算器核心功能生成完整、规范、可执行的测试用例。

## Key Reasoning
- 采用测试知识库中的标准：等价类划分法（有效/无效等价类）、边界值分析法、场景分析法、错误猜测法
- 用例ID格式遵循 `CALC-{模块缩写}-{序号}` 规范
- 所有预期结果均为可验证的具体数值或错误信息
- 优先级策略：P0(冒烟/核心) 15条，P1(主要功能) 27条，P2(次要) 22条，P3(边缘) 3条

## 覆盖的7个模块（共67条用例）
1. **加法**（15条）：正数+正数、正数+负数、小数相加、浮点精度验证
2. **减法**（8条）：大减小、小减大、负负相减、连续减法
3. **乘法**（9条）：正正相乘、正负相乘、负负相乘、含0、小数乘法
4. **除法**（11条）：整除/非整除、负数除以正/负、**3条除0异常（P0核心场景）**
5. **连续运算**（8条）：加减混合、乘除混合、优先级验证、=号重复
6. **清零功能**（6条）：运算后清零、输入中清零、错误后清零、CE/AC区别
7. **边界值**（10条）：整数溢出、科学计数法、浮点精度、循环小数、多点号防御、空输入保护

## 关键风险标记
- RISK-01: 除0操作 → 应用不应崩溃
- RISK-02: 0.1+0.2浮点精度（需确保=0.3）
- RISK-03: 运算优先级需明确说明
- RISK-04: 溢出场景
- RISK-05: 错误状态恢复

## Output File
`test-cases/calculator_test_cases.md`（共67条用例，含完整表格和覆盖率统计）
