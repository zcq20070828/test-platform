> **文档版本**: v1.1  
> **生成日期**: 2026-07-02  
> **模块**: USER_LOGIN - 用户登录模块  
> **用例总数**: 21 条（P0×5 + P1×8 + P2×5 + P3×3）  
> **优先级分布**: P0×5（核心）| P1×8（重要）| P2×5（安全）| P3×3（边缘）  
> **制定依据**: 功能需求分析 + 等价类划分 + 边界值分析 + 安全测试标准

---

## 一、模块概述

| 项目 | 内容 |
|------|------|
| **模块名称** | USER_LOGIN - 用户登录 |
| **功能描述** | 用户通过用户名/密码完成身份认证，系统验证合法性后建立会话并返回 Token/Session |
| **涉及接口** | `POST /api/auth/login`、`POST /api/auth/logout`、`GET /api/auth/captcha` |
| **登录方式** | 用户名+密码（基础） |
| **关联模块** | 用户管理、会话管理、权限管理、验证码服务、密码找回模块 |
