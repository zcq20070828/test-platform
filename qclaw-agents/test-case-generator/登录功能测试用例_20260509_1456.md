# 登录功能测试用例

## 一、接口信息
- **模块**：用户认证（AUTH）
- **接口路径**：`POST /api/v1/auth/login`
- **接口说明**：用户登录，支持账号密码登录和验证码登录

### 请求参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| loginType | String | 是 | 登录方式：password/phoneCode |
| account | String | 是 | 账号（手机号/邮箱/用户名） |
| password | String | 条件 | 密码（loginType=password时必填） |
| phoneCode | String | 条件 | 验证码（loginType=phoneCode时必填） |
| countryCode | String | 否 | 国家码，默认86 |

### 响应参数
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "string",
    "refreshToken": "string",
    "expiresIn": 7200
  }
}
```
