# 登录功能测试用例

## 一、需求分析

### 功能概述
登录功能是系统的入口，用户通过输入账号和密码进行身份验证，验证通过后进入系统主页面。

### 核心功能点
1. 账号密码登录
2. 手机验证码登录
3. 第三方登录（微信/支付宝等）
4. 记住密码 / 自动登录
5. 忘记密码
6. 登录安全策略（验证码、锁定机制）

## 四、风险点与建议

1. **账号锁定策略**需明确阈值（建议5次错误锁定30分钟）
2. **验证码有效期**建议设为5分钟，冷却时间60秒
3. **并发登录**需与业务方确认策略（互踢 or 允许多端）
4. **第三方登录**需考虑授权Token过期和刷新机制
5. **密码复杂度**建议强制要求（长度≥8，含大小写+数字+特殊字符）
