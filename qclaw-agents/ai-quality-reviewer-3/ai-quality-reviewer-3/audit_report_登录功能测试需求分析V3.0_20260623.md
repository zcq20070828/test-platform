### 3.3 疲劳强度测试5天窗口

| 问题 | 说明 |
|------|------|
| **⚠️ 措辞歧义** | "1000次（维持5天窗口）" 表述不清晰，存在两种理解：① 1000次总计在5天内完成；② 每天跑1000次，跑5天 |
| **计算合理性** | 假设每次登录+退出约3秒，1000次 ≈ 50分钟；5天窗口 = 288个1000次循环，远超1000次总数；如果是后者（每天1000次×5天），总量5000次，测试更充分但措辞应明确 |
| **性质** | 中等缺陷（建议修改为"单用户循环1000次（分散在5天内执行）"或"每日1000次×5天"） |
