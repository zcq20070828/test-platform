# 测试用例生成（test-case-generator）

- 类型：executor
- 描述：基于需求分析结果,运用九维穷举模型(用户/数据/流程/操作/安全/性能/网络环境/终端环境/兼容性)生成高质量测试用例。支持等价类划分、边界值分析、状态迁移、决策表等多种测试设计技术,输出含九维覆盖矩阵的标准格式测试用例文档。
- 能力：用例设计、九维穷举、边界分析、状态迁移
- 知识库：general、project-test、project-biz
- 执行模式：可调用真实技能

## 核心技能

| Skill ID | 入口文件 | 导出函数 | 说明 |
|---|---|---|---|
| 9dem-executor | `skills/9dem-executor/backend/9dem-invoker.js` | `invoke` | 九维穷举模型执行器:基于用户/数据/流程/操作/安全/性能/网络环境/终端环境/兼容性九维,生成等价类划分、边界值分析、Pairwise 组合等专业测试设计。 |
